# Services Catalogue Introduction

The sidebar **Services Catalogue** group covers service setup, workflows, task allocation, and the SLA matrix. **SRV** is the admin entry; employee requests use [My Services in Apps](/docs/app/services).

![Services Catalogue introduction](/img/srv/introduction.svg)

Click **Help** in the app header on the page to open the matching guide.

:::note[Admin UI status]
Admin Services and Workflows pages are not fully hosted in the portal today. Task Allocation and SLA Matrix work. Day-to-day requests use Apps.
:::
