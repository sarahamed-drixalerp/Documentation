# Project List

The Project List is your daily starting point. Use it to search, filter, compare values, create a project, open a record for editing, or access its 360 workspace.

**Path:** Sidebar ← Project Management Office ← Projects

## What You Can Do on This Screen

- View every project your permissions allow you to access
- Review summarized values, budget, planned profit, actual cost, and remaining cost
- Switch among three views: list, cards, and grouped tree
- Create, edit, open the 360 View, or delete records, subject to your permissions

## Views

Three view icons appear at the top of the page:

| View | When to use it |
|---|---|
| **List** | Daily operations, sorting, columns, and quick actions |
| **Cards** | A quick management overview with progress bars and stakeholders |
| **Tree** | Grouping by type, status, customer, agreement, portfolio, program, or manager |

### List View

Default columns:

- Name
- Project Manager
- Calculated Value
- Calculated Budget
- Planned Gross Profit
- Start Date
- End Date
- Row actions: Edit, 360 View, Delete

Select a project name to open the Standard View.

### Card View

Each card shows the customer, project manager, value, start date, and end date, together with a progress bar and stakeholder avatars when available.

### Tree View

Select **Group By**, then choose one of these fields:

- Project Type
- Project Status
- Customer
- Agreement
- Portfolio
- Program
- Project Manager
- Account Manager

Selecting a group displays analytics for that group. Selecting an individual project displays its analytics.

## Filtering and Search

You can filter by:

- Name
- Type
- Status
- Customer
- Agreement
- Portfolio
- Program
- Project Manager
- Account Manager

Combine filters to narrow the list, for example: Status = Active + Project Manager = You.

## Indicators Above the List

The screen displays totals for these fields across the current results:

- Calculated Value
- Calculated Budget
- Planned Gross Profit
- Actual Cost
- Estimate to Complete

These figures change with the filters. They summarize what you currently see, not necessarily the entire organization.

## List Actions

1. **Create New Project** — the primary button at the top, positioned according to the interface language direction
2. **Edit** — the pencil icon opens the Standard View
3. **360 View** — the chart icon opens the operational workspace
4. **Delete** — requires confirmation and cannot be undone

:::danger[Delete only incorrect draft records]
Do not delete a project that has hours, invoices, or deliverables. Use [Terminate](/docs/pmo/project-actions) if the contractual work has stopped.
:::

## Best Practices

:::tip[Use List View for daily work]
Use the list for operations, cards for management meetings, and the tree to review a specific portfolio or manager.
:::

:::note[Columns are customizable]
You can show or hide table columns according to your role. Keep the Status column in your daily view.
:::
