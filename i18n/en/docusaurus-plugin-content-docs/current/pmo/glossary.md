# Glossary

Brief definitions as they appear in a Drixal ERP project. System terms are shown in parentheses where applicable.

| Term | Definition |
|---|---|
| Project Management Office (PMO) | The application that brings together portfolios, programmes, agreements, projects, and their governance |
| Portfolio | A strategic grouping of programmes or projects |
| Programme | A group of related projects under one objective |
| Agreement | The contractual framework with the client, from which a project can be created |
| Project | The delivery record: scope, schedule, cost, team, and delivery |
| 360 View | The complete project workspace with all tabs |
| Standard View | The details, creation, and governance page |
| Post | Saves and confirms the displayed update while keeping it editable |
| Line Item | A product or service breakdown within the project value |
| Sales Order | The detailed commercial commitment linked to the project |
| Change Request | A scope change after the plan has been approved |
| Deliverable | An outcome that the client can accept |
| Work Item | An element in the breakdown structure: track, package, activity, task, or event |
| Work Breakdown Structure (WBS) | Hierarchical numbering for work items, such as 1.2.3 |
| Gantt Chart | A schedule view showing time and dependencies |
| Baseline | The original approved dates used for comparison |
| Phase | A project period with a start and end date |
| Milestone | A due date for an outcome that may be billable |
| Stakeholder | A person or entity that affects or is affected by the project |
| RACI | Responsible, Accountable, Consulted, Informed |
| Billing Plan | A schedule of claims and their statuses through collection |
| Invoice AR | A financial claim against the client |
| Invoice AP | A supplier's financial claim against the project |
| Purchase Order | A purchase commitment created before the supplier invoice |
| Delivery Note | Proof that materials or services were delivered |
| Certificate of Completion (COC) | Proof that a scope or phase was completed |
| Team Roster | The names of team members assigned to a phase or project |
| Assumption | Something considered true without complete evidence |
| Constraint | A known limit on resources, budget, or time |
| Minutes of Meeting (MOM) | Documentation of meeting decisions |
| Lesson | Knowledge to reuse after an issue or success |
| Risk | A potential future event with an impact |
| Issue | An event that has occurred and requires a solution |
| SPI | Schedule Performance Index |
| CPI | Cost Performance Index |
| Recognized Revenue | The portion that meets accounting recognition requirements |
| Remaining Cost to Complete | The estimated amount still to be spent before closure |
| Hour Increment | The smallest unit for recording time |
| Timesheet Approval | Acceptance or rejection of team hours on the project |
| PMO Auditor | The person who oversees project compliance with PMO procedures |
| Project Manager | The person operationally responsible for delivery |
| Account Manager | The person commercially responsible for the client relationship |
| Confidentiality Level | A classification that determines who can view the record |
| Project Type | A classification such as simple, large-scale, or multidisciplinary |
| Project Status | Active, Paused, Support, Completed, or Terminated |
