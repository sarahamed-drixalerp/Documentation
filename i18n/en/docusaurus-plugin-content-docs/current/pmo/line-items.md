# Project Line Items

Project line items break down the project value: what will be delivered or sold, in what quantity, at what price, and with what completion percentage. Without line items, the project remains a single financial total that is difficult to invoice or measure accurately.

**Location:** 360 View ← **Project Line Items** tab

## What Line Items Do

- Connect the project to products or services in the catalog
- Show quantity, amount, completion percentage, and recognized revenue percentage
- Provide the basis for sales orders, billing plans, and deliverables when needed

## Fields in the List

| Field | Meaning |
|---|---|
| Product | Item or service |
| Quantity | Line-item volume |
| Amount | Line-item value |
| Completion Percentage | Progress of this line item |
| Recognized Revenue Percentage | Portion of the line-item value recognized for accounting purposes |

## How to Add a Line Item

1. Open the project in the 360 View
2. Select the **Project Line Items** tab
3. Add a new record
4. Select the product, quantity, and values
5. Save, then review the effect on the project indicators at the top of the page

:::tip[Start with the line items you will invoice]
If the project is organized by phases or includes materials, licenses, and labor, create a separate line item for each group so it can later be linked to the appropriate billing-plan type.
:::

## Relationship to the Rest of the Project

- **Deliverables** can be linked to a line item and a work item
- The **Billing Plan** specifies when line-item value will be collected
- The **Schedule** can link a work item to a financial line item so progress and cost move together

## Best Practices

:::warning[Do not put a mixed scope into one line item]
A single line item named “Project Execution” prevents partial billing and accurate progress measurement. At a minimum, separate materials, licenses, and labor when that matches your business model.
:::

:::note[Update completion percentages regularly]
If a line item’s percentage remains unchanged for weeks while the team is working, analytics will report misleading progress or delay.
:::
