# Stakeholders

A stakeholder is anyone who affects or is affected by the project, including the customer, internal team, consultant, and regulator. The Stakeholders tab keeps communication knowledge from existing only in the project manager’s head.

**Location:** 360 View ← **Stakeholders**

## What This Tab Does

- Records the people and organizations associated with the project
- Clarifies responsibility through a simplified RACI model
- Assesses power, interest, support, influence, and knowledge
- Displays team avatars on project cards

## Key Fields

| Field | Description |
|---|---|
| Classification | Stakeholder type, such as internal, customer, or partner |
| Contact | Link to a contact record |
| Team Member | Link to an internal user |
| Job Title | Role visible to the customer |
| Mobile / Email | Communication channels |
| Responsible | R — performs the work |
| Accountable | A — answerable for the outcome |
| Consulted | C — asked before a decision |
| Informed | I — notified after a decision |
| Power / Interest / Support / Influence / Knowledge | Relative assessments used to guide communication |

A stakeholder can also be linked to a deal if the project originated from a sales opportunity.

## How to Add a Stakeholder

1. Open the **Stakeholders** tab
2. Add a record
3. Link an internal user or external contact
4. Define the RACI roles clearly; avoid making everyone Responsible
5. Assess power and interest to identify who needs close engagement

## Stakeholders Who Should Always Be Included

- Project Manager
- Account Manager
- Customer representative authorized to accept deliverables
- PMO Auditor, if applicable
- Leads of the primary technical workstreams

## Best Practices

:::tip[A stakeholder without a communication channel is a risk]
If the customer representative’s mobile number or email is not recorded, approval of every deliverable may be delayed.
:::

:::warning[Do not confuse Responsible with Accountable]
The Responsible person performs the work. The Accountable person answers for the outcome. If one person is both A and R for everything, the matrix provides little value.
:::
