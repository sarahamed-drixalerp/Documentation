# 360 Workspace

The 360 View is the project’s operations hub. Instead of moving among separate screens, the project manager and team work from one record containing details, scope, schedule, team, financials, risks, delivery, and governance.

**Path:** From the Project List, select the chart icon, or switch from the Standard View to the 360 View.

## What the 360 View Provides

- A fixed header with the name, number, status, type, and actions
- A tab for every work area
- A sidebar for quickly creating activities and viewing activities, attachments, logs, and analytics
- Summary financial indicators: value, budget, and planned profit
- A start-to-end timeline when the dates are populated

## Tabs

| Tab | What you will find |
|---|---|
| **Details** | General information, governance, and settings |
| **Project Line Items** | Products, quantities, amounts, and completion percentages |
| **Scope** | Sales orders, change requests, and deliverables |
| **Calendar** | Calendar view of the work plan |
| **Schedule** | Gantt chart and work breakdown structure |
| **Stakeholders** | Team, customers, and responsibility matrix |
| **Time** | Phases and milestones |
| **Financials** | Billing plan, customer and vendor invoices, and purchase orders |
| **Risks and Issues** | Proactive risks and active issues |
| **Delivery Proofs** | Delivery notes, completion certificates, and team statements |
| **Management Center** | Assumptions, constraints, plans, minutes, and lessons learned |

## Sidebar

### Quick Create

| Button | Use |
|---|---|
| Notes | Record a decision or quick piece of information |
| Calls | Log a call related to the project |
| Tasks | Create an execution task for a team member |
| Meeting | Create a meeting whose agenda can later be documented in the minutes |
| Visit | Record a site or customer visit |

These items are created as work items linked to the project and appear in the schedule when needed.

### Context Panels

- **Activities** — daily activity on the record
- **Attachments** — project files
- **Logs** — audit trail of who changed what
- **Analytics** — financial and schedule indicators, including SPI and CPI

Select **Back to Details** to leave a context panel and return to the current tab.

## Standard View vs. 360 View

| | Standard | 360 |
|---|---|---|
| Creation | Yes | After the record exists |
| Focus | Master data | Full operations |
| Tabs | No | Yes |
| Formal actions | Yes | Yes |
| Schedule and financials | No | Yes |

## Best Practices

:::tip[Make 360 the project manager’s default screen]
After creating the project, manage the work from the 360 View. Use the Standard View only for quick field reviews.
:::

:::note[Wide tab bars scroll horizontally]
If the **Management Center** tab does not appear on a small screen, scroll the tab bar.
:::
