# Marital status

**Marital status (Marital)** is a reference value for the employee’s marital status in the personal profile.

**Page:** `/Entities/HRM/Marital`

## What this screen does

- Manages marital status values (as available in your reference data)
- Is selected from the employee form

## Usage

1. Open the marital status list
2. Keep clear values without duplication
3. Use them when filling the employee’s personal information
