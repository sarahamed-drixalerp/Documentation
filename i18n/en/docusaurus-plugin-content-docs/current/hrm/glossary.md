# Glossary

Short definitions as they appear in Drixal ERP Human Resources. English system names are shown in parentheses.

| Term | Definition |
|---|---|
| Human Resources (HRM) | People operations module: employees, payroll, hiring, evaluation, structure, and reference data |
| Employee | Operational person record linked to department, job, pay, and attendance |
| 360 view | Record workspace with related tabs (for example employee or JobPost on its route) |
| Standard view / record | Details, create, and edit page |
| Payroll | Pay period that is calculated, then published and locked |
| Generate | Calculate payroll earnings and deductions before the final lock |
| Publish / Post | Fix the record status (for example publish an evaluation schema, Post a job announcement to Published, or publish a payroll) |
| Payroll Items | Tab hub for SalaryItems and CostItems, not a CRUD entity |
| Salary Item | Catalog earnings/deduction element (`sI_val` / `sI_prc`) |
| Cost Item | Employer cost catalog element (`cI_val` / `cI_prc`) |
| JobPost | Published vacancy; UI on `/Entities/HRM/JobPost` and `/Entities/HRM/Post` |
| Candidate | Hiring applicant with stage workflow |
| JobPostCandidate | Link of a candidate to a post; edit opens the candidate page |
| Evaluation | Employee evaluation against a schema; locks at Submitted |
| Evaluation Schema | Goals/KPIs structure with a score type; published after content is complete |
| Evaluation Score | min/max scale with subordinate levels |
| Score Level | Selectable value within the scale (`levelValue_dec`) |
| Goal / KPI | Schema elements; in evaluation a level is chosen for each KPI |
| Job | Job title; optionally with department and grade |
| Grade | Job ladder/level |
| Work Shift | Weekly hours schedule with time zone |
| Medical | Medical coverage linked to a supplier and dates |
| Org Chart | Tree from direct manager with search and pan |
| HRM Dashboard | Workforce indicators and charts |
| Biometric / ZKTeco | Attendance device registered in HRM settings |
| Resume Source | Candidate arrival channel |
| Relation | Dependant relationship type |
| Blood group / Gender / Marital | Personal profile reference values |
