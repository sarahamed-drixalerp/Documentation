# Grades

A **grade (Grade)** represents a job level or ladder linked to the employee or the job when needed.

**Path:** Sidebar ← Human Resources ← Grades  
**Pages:** `/Entities/HRM/Grade` · `/Entities/HRM/Grade/new` · `/Entities/HRM/Grade/{id}`

## What this screen does

- Defines grades with bilingual names plus type and status
- Offers three views: list, cards, and grouped tree

## Required fields

| Field | Why it is required |
|---|---|
| **Name (name)** | Grade identity |
| **Arabic name (nameAr)** | Arabic display |
| **Type (EntityTypeId)** | Record classification |
| **Status (EntityStatusId)** | Grade status |

## Views

| View | Use |
|---|---|
| **List** | Daily work, sorting, and actions |
| **Cards** | Quick glance |
| **Tree** | Grouping by available grouping fields in the UI |

## Best Practices

:::tip[Unify grade naming before assignment]
Conflicting grade names weaken structure and payroll reports when employees and jobs are linked.
:::
