# Resume source

A **resume source (Resume Source)** is a reference value that shows how the candidate or employee arrived (site, referral, agency, etc., per your data).

**Page:** `/Entities/HRM/ResumeSource`

## What this screen does

- Manages resume sources
- Is selected in hiring information for the candidate or employee

## Usage

1. Open the resume sources list
2. Create the sources your recruitment uses
3. Link them when creating a [candidate](/docs/hrm/candidate) or filling employee hiring data

:::tip[Stabilize sources before recruitment campaigns]
A clear source makes it easier to measure sourcing channel effectiveness with [Job post](/docs/hrm/job-post).
:::
