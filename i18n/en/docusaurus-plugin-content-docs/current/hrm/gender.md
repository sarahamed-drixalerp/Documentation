# Gender

**Gender** is a reference value selected in the employee’s personal data.

**Page:** `/Entities/HRM/Gender`

## What this screen does

- Manages the gender values approved for the organization
- Is used in employee forms and reports that rely on this classification

## Usage

1. Open the gender list
2. Create or edit the value
3. Link it from the employee file when creating or editing
