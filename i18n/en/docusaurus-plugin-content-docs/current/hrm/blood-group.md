# Blood groups

A **blood group (Blood Group)** is a reference value selected in the employee’s personal data.

**Page:** `/Entities/HRM/BloodGroup`

## What this screen does

- Manages the blood group list used in Human Resources forms
- Is used as a reference when filling the employee personal profile

## Usage

1. Open the blood groups list
2. Create or edit the reference value
3. Select it later from the blood group field in [Employee details](/docs/hrm/employee-details)

:::tip[Keep the list short and unified]
Avoid repeating the same blood group under different names so search and filtering stay clean.
:::
