# Employee evaluations tab

The evaluations tab shows evaluations linked to the employee from inside the 360 view, and complements the evaluation path in the Human Resources module.

**Location:** 360 view ← **Evaluations**  
**Parent record:** `/Entities/HRM/Employee/360/{id}`

## What this tab does

- Opens the list of evaluations linked to this employee
- Lets you review the evaluation record directly from the employee context
- Connects 360 operations to the wider evaluation path in Human Resources

This tab is the management/display interface for evaluation records belonging to the employee. For the full evaluation path in the module, see the [evaluation guide](/docs/hrm/evaluation).

## How to review an employee’s evaluations

1. Open `/Entities/HRM/Employee/360/{id}`
2. Go to the **Evaluations** tab
3. Review the records shown for the employee
4. Open or manage the record according to your permissions, or go to the evaluation path in the module when needed

:::note[The tab is not a substitute for the evaluation module]
Use the tab for quick access from the employee record. Broader policies and forms are managed via [/docs/hrm/evaluation](/docs/hrm/evaluation).
:::

## Best Practices

:::tip[Open evaluation from 360 when reviewing one employee]
For an individual audit, start from the employee record then the tab. For a full evaluation cycle across the organization, use the evaluation guide.
:::

:::warning[Do not rely on memory instead of the record]
Any performance note should appear in the evaluation linked to the employee so it remains auditable.
:::
