# Relation

A **relation (Relation)** is a reference value used when recording dependants and linking them to the employee.

**Page:** `/Entities/HRM/Relation`

## What this screen does

- Defines approved kinship/relation types
- Is selected when adding a [dependant](/docs/hrm/employee-dependants)

## Required fields

| Field | Why it is required |
|---|---|
| **Type (EntityTypeId)** | Relation record classification |
| **Status (EntityStatusId)** | Reference value status |

Name and Arabic name are used to display the option in lists.

## Best Practices

:::tip[Unify relation names before entering dependants]
Conflicting labels (for example “Son” vs “Child”) weaken dependant reports.
:::
