# Getting started

Welcome to **Drixal ERP** documentation.

Use the sidebar to open module guides. The **Project Management Office (PMO)** section is the most complete guide today. Other modules include starter pages that open from the in-app **Help** button.

## How Help works

1. Open any screen in Aspire / Drixal ERP.
2. Click the **Help** icon in the header.
3. The matching docs page opens in your current language (`ar` / `en`).
