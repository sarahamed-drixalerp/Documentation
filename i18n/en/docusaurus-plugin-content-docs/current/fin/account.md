# Chart of Accounts

An **account** is a node in the Chart of Accounts in Drixal ERP. It defines hierarchy, posting rules, currencies, and balances, and shows posted journal-line history.

## What an Account Does for Your Business

- Builds the ledger structure: parent folder / posting account
- Sets posting rules: all currencies or selected currencies, cost/profit centers, reconciliation
- Shows debit/credit/net balances with FX breakdown
- Opens posted journal transactions for the account and its children

**Navigation:** Sidebar → Finance → Accounts  
**Primary page:** `/Entities/FIN/Account` (tree workspace)  
**Classic record:** `/Entities/FIN/Account/{id}`

## Chart of Accounts Workspace

### Views

| View | Use |
|---|---|
| **Tree** (default) | Daily work on structure, balances, details, and transactions |
| **List** | Tabular search by code, name, and balances |

### In tree view

- Search, expand all, and breadcrumb
- Balance band: debit / credit / net + currency breakdown
- Two tabs: **Details** | **Transactions**
- Transactions: posted journal lines for the account (and children if a folder), period presets, balance before/after, open journal in a new tab

### In list view

Columns: code, name, base balances, edit/delete. Filter by name/code, type, status.

## Create or Edit an Account

Preferred path: in the tree, select a parent then **Add Account**, or edit the inline details.

### Core fields

| Field | Notes |
|---|---|
| **Name** | Required |
| **Arabic name** | Recommended; if empty, copied from name on save |
| **Debit / credit** | Account nature |
| **Code** | Usually generated by the system |

### Account settings

| Setting | Meaning |
|---|---|
| **Parent** | Folder account, not for direct posting |
| **Posting** | Accepts journal lines |
| **All currencies** | Otherwise specific currencies are required |
| **Cost center required** | Dimensions mandatory on journals |
| **Profit center required** | Dimensions mandatory on journals |
| **Reconciliation required** | For matching workflows |

:::warning[Parent + posting together]
Combining parent and posting may show a warning. Follow accounting policy before save.
:::

## Delete and Edit Guards

- Cannot delete an account that has children
- Parent switch locked when children exist
- Changing selection with unsaved changes asks for confirmation
- There is no “Post” on the account itself; posting is on [Journals](/docs/fin/journal)

## Best Practices

:::tip[Build the structure before large manual journals]
Create leaf accounts and dimension rules before entering heavy journal volume.
:::

:::tip[Use the Transactions tab for review]
Review posted movements from the account instead of searching every journal.
:::
