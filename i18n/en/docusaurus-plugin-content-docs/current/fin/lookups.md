# Financial Lookups

Configuration catalogs for financial categorizations, payment methods, transaction types, and fiscal rules.

## Lookups overview

- **Payment Methods**: Cash, wire transfer, credit card, cheque
- **Account Categories**: Assets, liabilities, equity, revenues, expenses
- **Tax Rules**: VAT brackets, exemptions, and withholding tax definitions
