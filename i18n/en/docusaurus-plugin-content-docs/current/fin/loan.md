# Loans

The **Loans** entity manages employee financial loans, repayment installments, and payroll integration.

## What Loans do for your business

- Sets up loan agreements with total amount, number of installments, and start date
- Automates installment deductions via monthly payroll runs
- Monitors repaid balance, pending balance, and loan completion status

**Path:** Sidebar → Finance → Loans  
**Pages:** `/Entities/FIN/Loan` · `/new` · `/{id}`
