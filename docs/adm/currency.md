# العملات

**العملة (Currency)** قيمة مرجعية لأسعار الصرف والعملة الأساسية المستخدمة عبر وحدات Drixal ERP. في مسار الإدارة تُعرض قائمة عملات التطبيق (APP Currency).

**المسار:** القائمة الجانبية ← الإدارة ← العملات  
**الصفحة:** `/Entities/ADM/Currency` (تستخدم قائمة عملات التطبيق APP Currency)

## ماذا تفعل هذه الشاشة

- تعرض العملات بالاسم والوصف بالإنجليزية والعربية
- تُظهر سعر الصرف ووقت تحديثه
- تميّز العملة الأساسية (**isBaseCurrency**)
- تعرض مفتاح **Active** في الواجهة (انظر التحذير أدناه حول الحفظ)

## الحقول الظاهرة

| الحقل | الاستخدام |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الوصف باللغتين |
| exchangeRate | سعر الصرف |
| exchangeRateTimeStamp | وقت تحديث سعر الصرف |
| isBaseCurrency | هل هذه العملة الأساسية |
| Active | مفتاح النشاط في الواجهة |

:::warning[مفتاح Active لا يُحفظ مثل الدول]
تبديل **Active** على العملة يعرض إشعارًا في الواجهة (toast) ولا يُpersist كما يفعل مفتاح النشاط في [الدول](/docs/adm/country) عبر **editCountry**. لا تعتمد على هذا المفتاح كحفظ فعلي لحالة النشاط.
:::

## كيف تستخدم الشاشة

1. افتح قائمة العملات من مسار الإدارة
2. راجع الأسماء والأوصاف وسعر الصرف ووقت التحديث
3. تعرّف على العملة الأساسية عبر **isBaseCurrency**
4. لا تفترض أن تبديل **Active** قد حُفظ في الخادم

## أفضل الممارسات

:::tip[راجع exchangeRateTimeStamp قبل الاعتماد على السعر]
اعتمد على وقت التحديث عند استخدام سعر الصرف في التقارير أو التشغيل.
:::

:::note[العملة الأساسية]
**isBaseCurrency** يحدد العملة المرجعية للمؤسسة ضمن قائمة العملات.
:::
