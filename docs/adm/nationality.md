# الجنسيات

**الجنسية (Nationality)** قيمة مرجعية تُستخدم في ملفات الأفراد والموظفين عبر وحدات Drixal ERP. سلوك الشاشة يماثل شاشة الدول: قائمة، درج للإنشاء/التعديل، وتفعيل عبر مفتاح النشاط.

**المسار:** إن ظهرت في القائمة الجانبية ← الإدارة ← الجنسيات  
**الصفحة:** `/Entities/ADM/Nationality`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة الجنسيات قد لا تظهر في الشريط الجانبي؛ المسار `/Entities/ADM/Nationality` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة الجنسيات بالاسم والوصف بالإنجليزية والعربية
- تتيح إنشاء وتعديل وحذف السجلات
- توفّر مفتاح **نشط (Active)** يُحفظ عبر التعديل (بنفس منطق الدول)

## القائمة

الأعمدة والمحتوى الظاهر يشمل:

- الاسم (إنجليزي)
- الاسم (عربي)
- الوصف (إنجليزي / عربي حسب الأعمدة الظاهرة)
- مفتاح **Active** — التغيير يُحفظ عبر التعديل

## الإنشاء والتعديل

يُفتح درج (Drawer) لتعبئة:

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم بالإنجليزية |
| **nameAr** | الاسم بالعربية |
| description | الوصف بالإنجليزية |
| descriptionAr | الوصف بالعربية |
| abbrv | الاختصار |

### كيف تستخدم الشاشة

1. افتح `/Entities/ADM/Nationality` مباشرة إن لم تظهر في القائمة
2. أنشئ جنسية جديدة أو عدّل سجلًا من القائمة
3. عبّئ الاسم باللغتين والوصف والاختصار عند الحاجة
4. احفظ من الدرج
5. استخدم مفتاح **Active** لتفعيل أو إيقاف الجنسية
6. احذف فقط القيم غير المستخدمة عند الحاجة

## أفضل الممارسات

:::tip[طابق التسمية مع الوثائق الرسمية]
سمِّ الجنسية كما تظهر في الهوية والمستندات الرسمية باللغتين.
:::

:::warning[لا تحذف جنسية مستخدمة في ملفات الأفراد]
أوقِف النشاط عبر **Active** إن لم تعد القيمة مطلوبة، بدل الحذف إن كانت مرتبطة بسجلات.
:::
