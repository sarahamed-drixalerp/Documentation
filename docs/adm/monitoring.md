# المراقبة

**المراقبة (Monitoring)** شاشة متابعة المهام الليلية (**NightlyJob**) في وحدة الإدارة. تعرض صحة التشغيل، وآخر نجاح كامل، والتشغيل التالي المجدول، وآخر فشل، مع إمكانية التحديث والتشغيل اليدوي ومراجعة التفاصيل والسجل.

**المسار:** القائمة الجانبية ← الإدارة ← المراقبة  
**الصفحة:** `/Entities/ADM/monitoring`

## ماذا تفعل هذه الشاشة

- تعرض مؤشرات صحة نظام المهام الليلية
- تجدول التشغيل اليومي وتعرض موعد التشغيل التالي
- تسمح بـ **تحديث (Refresh)** و**تشغيل الآن (Run Now)** مع تأكيد
- تفتح **التفاصيل (Details)** وسجل التنفيذ مع تصفية بالتاريخ والخطوة والحالة

## الجدول الزمني

| البند | القيمة |
|---|---|
| الجدولة | يوميًا |
| الوقت | 11:00 صباحًا |
| المنطقة الزمنية | القاهرة (Cairo) |

## مؤشرات الأداء (KPIs)

| المؤشر | المعنى |
|---|---|
| System Health | صحة نظام المهام الليلية |
| Last Full Success | آخر نجاح كامل لكل الخطوات |
| Next Scheduled Run | موعد التشغيل المجدول التالي |
| Last Failure | آخر فشل مسجّل |

## خطوات المهمة الليلية

| الخطوة | الغرض |
|---|---|
| ExchangeRates | تحديث أسعار الصرف |
| FinancialDue | المستحقات المالية |
| EntityTrend | اتجاهات الكيانات / السمات المراقبة |

## كيف تستخدم الشاشة

1. افتح `/Entities/ADM/monitoring`
2. راجع مؤشرات الصحة وآخر نجاح وآخر فشل والتشغيل التالي
3. اضغط **Refresh** لتحديث العرض
4. عند الحاجة اضغط **Run Now** وأكّد التشغيل اليدوي
5. افتح **Details** لمراجعة سجل الخطوات
6. صفِّ السجل حسب نطاق التاريخ والخطوة والحالة عند التشخيص

## سجل التنفيذ (History)

أعمدة السجل:

| العمود | المعنى |
|---|---|
| Started At | وقت البدء |
| Step Name | اسم الخطوة |
| Status | الحالة |
| Trigger | مصدر التشغيل |
| Duration | المدة |
| Metrics | المقاييس المرتبطة |

### عوامل التصفية

| عامل التصفية | القيم |
|---|---|
| نطاق التاريخ | 7 / 14 / 30 يومًا |
| الخطوة (Step) | ExchangeRates · FinancialDue · EntityTrend |
| الحالة (Status) | Success · Failed · Skipped |
| المشغّل (Trigger) | Scheduled · Manual |

## أفضل الممارسات

:::tip[شخّص من Last Failure ثم التفاصيل]
عند وجود فشل، ابدأ من مؤشر **Last Failure** ثم افتح **Details** وصفِّ بـ Failed وحدد الخطوة.
:::

:::warning[Run Now يتطلب تأكيدًا]
التشغيل اليدوي يعيد تنفيذ الخطوات. أكّد فقط عندما تحتاج تشغيلًا فوريًا خارج الجدول اليومي.
:::

:::note[الجدول بتوقيت القاهرة]
التشغيل المجدول يوميًا الساعة 11:00 صباحًا بتوقيت القاهرة.
:::
