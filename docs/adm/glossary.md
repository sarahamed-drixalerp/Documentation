# المصطلحات

تعريفات مختصرة كما تظهر في إدارة Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| الإدارة (ADM) | وحدة حوكمة الوصول والبيانات المرجعية: مستخدمون، أدوار، كيانات، دول، عملات، سرية، مراقبة |
| مستخدم التطبيق (Application User) | حساب الدخول والمقعد والتفعيل والأدوار |
| دور التطبيق (Application Role) | حزمة صلاحيات تُمنح للمستخدمين مع تبويبي Permission وUsers |
| صلاحية (Claim) | إذن على كيان مثل GetAll / GetById / Create / Edit / Delete / 360 |
| GetAll | عرض القائمة؛ يستلزم GetById |
| GetById | عرض سجل واحد |
| 360 | مساحة عمل السجل؛ يستلزم GetById |
| سرية البيانات / NCA (Data Confidentiality) | مستويات التصنيف: 1 عام، 2 داخلي، 3 سري، 4 سري للغاية |
| نوع المقعد (seatType) | ترخيص استخدام مرتبط بمستخدم التطبيق |
| تفعيل / إلغاء تفعيل | تمكين أو إيقاف الوصول دون حذف السجل |
| إدارة الكيانات (Entity) | تعريف الكيانات وحالاتها وأنواعها وسماتها عبر شجرة CAT → الكيان |
| حالة الكيان (Entity Status) | قيمة حالة باسمين ولون اختياري |
| نوع الكيان (Entity Type) | تصنيف الكيان باسمين وأوصاف |
| سمة (Attribute) | حقل معرّف بـ name / nameAr / dbFieldName / dataType وقد يُراقب اتجاهه |
| isMonitorTrend | تفعيل مراقبة اتجاه السمة ضمن المهام الليلية |
| الدولة (Country) | قيمة مرجعية للدولة؛ مفتاح Active يُحفظ عبر editCountry |
| الجنسية (Nationality) | قيمة مرجعية للجنسية؛ قد لا تظهر في الشريط الجانبي والمسار يعمل |
| العملة (Currency) | قائمة عملات التطبيق من مسار ADM؛ سعر صرف ووقت تحديث وعملة أساسية |
| isBaseCurrency | تمييز العملة الأساسية |
| المراقبة (Monitoring / NightlyJob) | متابعة المهام الليلية المجدولة يوميًا 11:00 ص بتوقيت القاهرة |
| ExchangeRates | خطوة تحديث أسعار الصرف |
| FinancialDue | خطوة المستحقات المالية |
| EntityTrend | خطوة اتجاهات الكيانات |
| Trigger | مصدر التشغيل: Scheduled أو Manual |
| سير العمل (Workflow) | واجهة غير مكتملة في ADM؛ غير موثّقة في هذا الدليل |
