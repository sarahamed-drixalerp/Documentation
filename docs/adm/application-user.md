# مستخدمو التطبيق

**مستخدم التطبيق (Application User)** هو حساب الدخول والصلاحيات في Drixal ERP. يربط الشخص بهوية الدخول، والمقعد، والتفعيل أو إلغاء التفعيل، والأدوار التي تحدد ما يراه وما يفعله في النظام.

المستخدم ليس مجرد اسم وبريد. هو السجل الذي تُعلَّق عليه اللغة والعملة والمؤسسة ونوع المقعد والأدوار، ومنه تُدار دورة حياة الوصول دون حذف السجل عند مغادرة الشخص للعمل.

**المسار:** القائمة الجانبية ← الإدارة ← مستخدمو التطبيق  
**الصفحات:** `/Entities/ADM/ApplicationUser` · `/Entities/ADM/ApplicationUser/new` · `/Entities/ADM/ApplicationUser/{رقم}`

## ماذا يفعل مستخدم التطبيق لأعمالك

- يعرّف هوية الدخول: الاسم باللغتين، البريد، اسم المستخدم، الجوال
- يضبط تفضيلات العمل: العملة، اللغة، المؤسسة، نوع المقعد
- يفعّل أو يوقف الوصول دون حذف السجل
- يمنح الأدوار من تبويب الأدوار بعد الحفظ
- يوفّر من ترويسة السجل إجراءات التفعيل وإلغاء التفعيل وتغيير نوع المقعد

## قائمة المستخدمين

قائمة مستخدمي التطبيق هي نقطة الدخول اليومية. منها تبحث، تصفّي، تنشئ مستخدمًا جديدًا، أو تفتح سجلًا للتعديل أو الإجراءات.

### عرض القائمة

الأعمدة الافتراضية:

- الاسم
- إجراءات الصف: تعديل، حذف، **تفعيل**، **إلغاء تفعيل**، **تغيير نوع المقعد**

اضغط الاسم لفتح صفحة السجل `/Entities/ADM/ApplicationUser/{رقم}`.

عرض البطاقات وعرض الشجرة غير مفعّلين عادةً؛ اعتمد عرض القائمة للعمل اليومي.

### التصفية والبحث

يمكنك التصفية حسب:

- الاسم (Name)
- النوع (EntityTypeId)
- الحالة (EntityStatusId)

### الإجراءات من القائمة

1. **إنشاء مستخدم جديد** — يفتح `/Entities/ADM/ApplicationUser/new`
2. **تعديل** — يفتح `/Entities/ADM/ApplicationUser/{رقم}`
3. **تفعيل / إلغاء تفعيل / تغيير نوع المقعد** — من إجراءات الصف مع حوار عند الحاجة
4. **حذف** — يتطلب تأكيدًا؛ فضّل إلغاء التفعيل بدل الحذف عند مغادرة المستخدم

## إنشاء وتعديل مستخدم

1. من القائمة اضغط الإنشاء، أو افتح سجلًا موجودًا
2. عبّئ الحقول الإلزامية في **التفاصيل**
3. أضف الحقول الاختيارية المعروفة (البريد، اسم المستخدم، الجوال، اللغة، العملة…)
4. اضغط **حفظ**
5. انتقل إلى تبويب **الأدوار** وعيّن الأدوار قبل تسليم الحساب
6. استخدم من الترويسة **تفعيل** أو **إلغاء تفعيل** أو **تغيير نوع المقعد** عند الحاجة

### الحقول الإلزامية (SaveDetails)

| الحقل | لماذا هو إلزامي |
|---|---|
| **الاسم (name)** | العرض والبحث في النظام |
| **الاسم بالعربية (nameAr)** | الواجهة العربية والتقارير المحلية |

### حقول اختيارية شائعة

| الحقل | الاستخدام |
|---|---|
| CurrencyId | عملة التفضيل |
| LanguageId | لغة الواجهة |
| OrganizationId | المؤسسة المرتبطة |
| seatType | نوع المقعد / ترخيص الاستخدام |
| langAbbrv | اختصار اللغة |
| firstName / lastName | الاسم الأول والأخير |
| jobTitle | المسمى الوظيفي |
| mobile / phone | التواصل |
| email / userName | تسجيل الدخول والهوية |
| isActive | هل يمكنه الدخول |

:::warning[حقول الهوية والأمان — للمسؤول / النظام فقط]
حقول مثل **passwordHash**، و**lockout**، والمصادقة الثنائية (**2FA**)، و**accessFailedCount** تخص إدارة الهوية والأمان. لا تعدّلها من الاستخدام اليومي؛ اتركها لمسؤول النظام أو أدوات الهوية المعتمدة.
:::

## تبويبات صفحة السجل

على `/Entities/ADM/ApplicationUser/{رقم}`:

| التبويب | متى تستخدمه |
|---|---|
| **التفاصيل (Details)** | الإنشاء والتعديل والحقول الأساسية |
| **الأدوار (Roles)** | تعيين أدوار التطبيق بعد الحفظ |

### ترويسة السجل

من أعلى الصفحة يمكنك:

- **تفعيل**
- **إلغاء تفعيل**
- **تغيير نوع المقعد (ChangeSeatType)**

### الشريط الجانبي والأنشطة السريعة

من صفحة السجل تتوفر عادةً:

- الأنشطة (Activities)
- المرفقات (Attachments)
- الرؤى (Insights)
- السجلات (Logs)

ومن الإجراءات السريعة: ملاحظة (Note)، مكالمة (Call)، مهمة (Task)، اجتماع (Meeting)، زيارة (Visit).

## إجراءات دورة الحياة

| الإجراء | المعنى |
|---|---|
| **تفعيل** | يعيد تمكين الوصول |
| **إلغاء تفعيل** | يوقف الوصول دون حذف السجل |
| **تغيير نوع المقعد** | يحدّث ترخيص المقعد |
| **حذف** | إزالة السجل؛ استخدمه بحذر للمسودات الخاطئة فقط |

:::danger[فضّل إلغاء التفعيل على الحذف]
عند مغادرة موظف أو إيقاف وصول، أوقف المستخدم واحتفظ بسجل التدقيق. الحذف يزيل السجل ولا يُفضَّل للحسابات التي لها تاريخ تشغيل.
:::

## بعد الحفظ مباشرة

1. راجع السجل على `/Entities/ADM/ApplicationUser/{رقم}`
2. افتح تبويب **الأدوار** واربط الأدوار المطلوبة
3. تأكد من **isActive** ونوع المقعد قبل تسليم الحساب
4. استخدم الأنشطة أو المرفقات عند الحاجة لتوثيق قرار التفعيل أو التعليق

## أفضل الممارسات

:::tip[عيّن الأدوار فور الإنشاء]
مستخدم بلا أدوار قد يدخل ولا يرى الشاشات. اربط الدور من تبويب الأدوار قبل تسليم الحساب.
:::

:::tip[ألغِ التفعيل بدل الحذف]
عند مغادرة شخص أوقف المستخدم واحتفظ بالسجل بدل الحذف النهائي.
:::

:::note[الاسم باللغتين إلزامي للحفظ]
لن يُحفظ المستخدم بدون **name** و**nameAr**. أكملهما قبل أي محاولة حفظ.
:::
