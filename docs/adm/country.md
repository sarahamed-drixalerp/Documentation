# الدول

**الدولة (Country)** قيمة مرجعية تُستخدم في عناوين وملفات النظام عبر وحدات Drixal ERP. من هذه الشاشة تنشئ وتعدّل وتحذف الدول، وتفعّل أو توقف النشاط.

**المسار:** القائمة الجانبية ← الإدارة ← الدول  
**الصفحة:** `/Entities/ADM/Country`

## ماذا تفعل هذه الشاشة

- تعرض قائمة الدول بالاسم والوصف بالإنجليزية والعربية
- تتيح إنشاء وتعديل وحذف السجلات
- توفّر مفتاح **نشط (Active)** يُحفظ عبر تعديل الدولة (**editCountry**)

## القائمة

الأعمدة والمحتوى الظاهر يشمل:

- الاسم (إنجليزي)
- الاسم (عربي)
- الوصف (إنجليزي / عربي حسب الأعمدة الظاهرة)
- مفتاح **Active** — التغيير يُحفظ عبر **editCountry**

## الإنشاء والتعديل

يُفتح درج (Drawer) لتعبئة:

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم بالإنجليزية |
| **nameAr** | الاسم بالعربية |
| description | الوصف بالإنجليزية |
| descriptionAr | الوصف بالعربية |
| abbrv | الاختصار |

### كيف تستخدم الشاشة

1. افتح `/Entities/ADM/Country`
2. أنشئ دولة جديدة أو عدّل سجلًا من القائمة
3. عبّئ الاسم باللغتين والوصف والاختصار عند الحاجة
4. احفظ من الدرج
5. استخدم مفتاح **Active** لتفعيل أو إيقاف الدولة؛ التغيير يُpersist عبر التعديل
6. احذف فقط القيم غير المستخدمة عند الحاجة

## أفضل الممارسات

:::tip[وحّد الأسماء والاختصارات]
استخدم أسماءً واضحة واختصارًا ثابتًا (abbrv) قبل ربط الدولة بسجلات أخرى.
:::

:::warning[لا تحذف دولة مستخدمة في عناوين أو ملفات]
أوقِف النشاط عبر **Active** إن لم تعد الدولة مطلوبة للتشغيل اليومي، بدل الحذف إن كانت مرتبطة بسجلات.
:::
