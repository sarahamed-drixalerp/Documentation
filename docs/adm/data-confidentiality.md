# سرية البيانات

**سرية البيانات (Data Confidentiality)** قيمة مرجعية لمستويات التصنيف التي تستخدمها الأدوار والسجلات ضمن نموذج NCA في Drixal ERP. منها تُدار الأسماء والأوصاف باللغتين لمستويات السرية.

**المسار:** القائمة الجانبية ← الإدارة ← سرية البيانات  
**الصفحة:** `/Entities/ADM/DataConfidentiality`

## ماذا تفعل هذه الشاشة

- تدير قيم سرية البيانات المعتمدة في المؤسسة
- تُستخدم من الأدوار والصلاحيات عند ضبط مستويات NCA
- تُربط بالسجلات التي تعتمد تصنيف السرية

## الحقول

| الحقل | الاستخدام |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الوصف باللغتين |

في سياق الأدوار، مستويات NCA الشائعة هي:

| المستوى | المعنى |
|---|---|
| 1 | عام (Public) |
| 2 | داخلي (Internal) |
| 3 | سري (Confidential) |
| 4 | سري للغاية (Top Secret) |

راجع ضبط المستويات على الصلاحيات في [أدوار التطبيق](/docs/adm/application-role).

## كيف تستخدم الشاشة

1. افتح `/Entities/ADM/DataConfidentiality`
2. أنشئ أو عدّل مستوى السرية بالاسمين والوصفين
3. احفظ
4. استخدم القيم عند ضبط صلاحيات الأدوار أو السجلات المعتمدة على NCA

## أفضل الممارسات

:::tip[وحّد أسماء المستويات مع سياسة المؤسسة]
اجعل **name** و**nameAr** مطابقين لسياسة التصنيف المعتمدة حتى لا يختلف فهم الأدوار بين الفرق.
:::

:::warning[تغيير المستوى يؤثر على من يرى السجلات]
راجع الأدوار المرتبطة قبل إعادة تسمية أو إعادة تفسير مستوى سرية مستخدم.
:::
