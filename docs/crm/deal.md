# الصفقات

**الصفقة (Deal)** فرصة بيع على مسار Pipeline داخل Drixal ERP. تربط العميل والعملة والمرحلة وبنود الخط وP&amp;L والعروض، وتُغلق بـ Won أو Lost.

**المسار:** القائمة الجانبية ← المبيعات ← الصفقات  
**الصفحات:** `/Entities/CRM/Deal` · `/Entities/CRM/Deal/{رقم}` · `/Entities/CRM/Deal/360/{رقم}`

## ماذا تفعل الصفقة لأعمالك

- تعرّف الفرصة: الاسم، العميل، مدير الحساب، المسار، المرحلة، المبالغ المحتسبة
- تجمع بنود الخط والعروض وبيانات اعتماد (Etimad) عند الحاجة
- توفّر إجراءات: **NextStage**، **CreatePnl**، **Won**، **Lost** (يوجد حوار ConvertToAgreement)
- تلخّص المؤشرات: المبلغ، الميزانية، الربح المخطط، المفوتر، غير المفوتر

## نوعان من صفحات الصفقة

| الصفحة | متى تستخدمها |
|---|---|
| **العرض القياسي** `/Entities/CRM/Deal/{رقم}` | التركيز على التفاصيل وبنود الخط |
| **عرض 360** `/Entities/CRM/Deal/360/{رقم}` | التشغيل اليومي: بنود الخط، التفاصيل، قوائم P&amp;L، العروض |

الإنشاء من الدرج يوجّه غالبًا إلى عرض 360 بعد الحفظ.

## قائمة الصفقات

### طرق العرض

قائمة، بطاقات، وشجرة (تجميع حسب النوع أو الحالة أو العميل أو المسار أو مدير الحساب).

### الأعمدة والمجاميع

الاسم، العميل، مدير الحساب، المسار، المرحلة، المبلغ المحتسب، مبلغ المسار.  
مجاميع: المبلغ، الميزانية، الربح الإجمالي المخطط، مبلغ المسار.

### التصفية

بحث، النوع، الحالة، العميل، المسار.

## إنشاء صفقة

### الحقول الإلزامية

| الحقل | ملاحظات |
|---|---|
| **name** / **nameAr** | تعريف الفرصة |
| **type** / **status** | حوكمة السجل |
| **customer** | ربط تجاري إلزامي |
| **currency** | أساس المبالغ |
| **pipeline** | يحدد المراحل المتاحة |
| **stage** | تُفرَّغ عند تغيير المسار؛ معطّلة حتى يُختار المسار |

### أقسام مهمة

| القسم | المحتوى |
|---|---|
| **عام** | مدير الحساب، التواريخ، العميل، العملة، المسار، المرحلة، الثقة، الوصف |
| **معلومات اعتماد** | رقم اعتماد، عروض، ضمانات، أيام الدفع |
| **ملاحظات** | فنية، مالية، حساب، خسارة |
| **الإغلاق** | تاريخ الإغلاق، المنافس، سبب الخسارة، تكلفة الإتمام |

## إجراءات دورة الحياة

| الإجراء | السلوك |
|---|---|
| **NextStage** (الانتقال للمرحلة التالية) | تعليق اختياري؛ إن كانت المرحلة الأخيرة تظهر معلومة للقراءة فقط |
| **CreatePnl** | ينشئ مسودة P&amp;L ويمكن فتحها |
| **Won** | اختر أمر شراء عميل و/أو أمر بيع و/أو كليهما؛ قد تُنشأ مستندات وتُفتح |
| **Lost** | إلزامي: سبب الخسارة، المنافس، مبلغ فوز المنافس (&gt; 0)، وتعليق |

## بنود الخط وتبويبات 360

| المنطقة | المحتوى |
|---|---|
| **LineItems** | المنتجات/البنود التي تقود المبالغ المحتسبة |
| **Details** | نموذج الصفقة |
| **Pnls** (360) | قوائم P&amp;L المرتبطة |
| **Quotations** (360) | العروض المرتبطة |

مؤشرات 360 تشمل: المبلغ، الميزانية، الربح المخطط، الإيراد المعترف، المفوتر، غير المفوتر، المستحق.

## أخطاء شائعة

- اختيار مرحلة قبل المسار («اختر المسار أولًا»)
- تاريخ نهاية أقدم من البداية
- إغلاق Lost بدون المنافس أو المبلغ أو السبب
- محاولة الحفظ وأنت لست على تبويب التفاصيل

## أفضل الممارسات

:::tip[ابنِ بنود الخط مبكرًا]
المبالغ المحتسبة تعتمد على البنود. لا تؤجلها حتى يوم الإغلاق.
:::

:::warning[راجع المسار قبل Won]
تأكد أن المرحلة النهائية والمنتجات صحيحة قبل إنشاء أمر البيع أو أمر شراء العميل.
:::

:::danger[Lost يتطلب بيانات إغلاق كاملة]
سبب الخسارة والمنافس ومبلغ فوز المنافس (&gt; 0) والتعليق كلها إلزامية.
:::
