# لوحة CRM

**لوحة CRM (Dashboard)** ملخّص تحليلي لمؤشرات قمع المبيعات والذمم المدينة. الشاشة للقراءة والتحديث — وليست لإنشاء أو تعديل أو حذف سجلات CRM.

**المسار:** القائمة الجانبية ← المبيعات ← اللوحة  
**الصفحة:** `/Entities/CRM/Dashboard`

## الفلاتر

| الفلتر | المعنى |
|---|---|
| **الفترة (Period)** | **Month** · **Quarter** · **Year** |
| **العميل (Customer)** | عميل واحد أو الكل (للمؤشرات والرسوم المقيَّدة بالعميل) |

تغيير الفلتر يعيد تحميل بيانات اللوحة. استخدم **Refresh** لإعادة التحميل دون مغادرة الصفحة.

## المؤشرات الرئيسية (شريط KPI)

| المؤشر | المعنى |
|---|---|
| **Deal Value** | إجمالي مبلغ الصفقات |
| **Weighted Pipeline** | مبلغ الصفقة × احتمال المرحلة |
| **Quote Value** | إجمالي مبلغ العروض |
| **Sales Orders** | التزام أوامر البيع |
| **Outstanding AR** | فواتير مبيعات غير مدفوعة |
| **Customer Exposure** | إجمالي مستحقات فواتير العميل |

## أقسام اللوحة

| القسم | المحتوى |
|---|---|
| **Sales Pipeline** | قمع الصفقة (Lead → Qualified → Deals → Won → Customers)؛ رسوم دائرية لحالة Lead / Deal / Quote |
| **Revenue & Accounts Receivable** | قيمة الصفقة حسب الحالة؛ توقّع المسار حسب Pipeline؛ الصفقات حسب الثقة؛ فواتير الذمم / غير المدفوع حسب الحالة؛ الإيراد حسب العميل |
| **Historical Trends** | اتجاهات مسار الصفقات وما يرتبط بها عبر الزمن |

## كيف تستخدم اللوحة

1. افتح لوحة CRM من المبيعات
2. اختر الفترة (Month أو Quarter أو Year)
3. صفِّ اختياريًا حسب العميل
4. راجع شريط المؤشرات ثم رسوم المسار والذمم
5. اضغط **Refresh** قبل اجتماع مراجعة إن كانت البيانات قد تغيّرت

## أفضل الممارسات

:::tip[صفِّ حسب العميل لمراجعات الحساب]
استخدم فلتر العميل ليطابق المؤشرات ورسوم الذمم الحساب الذي تناقشه.
:::

:::warning[لا CRUD على اللوحة]
أنشئ وعدّل العملاء المحتملين والصفقات والفواتير والمدفوعات من شاشات الكيانات — لا من بطاقات اللوحة.
:::

:::note[الأرقام تتبع صلاحياتك]
المجاميع والرسوم من البيانات المتاحة لصلاحياتك؛ ليست تقرير تدقيق خارجي محكمًا.
:::
