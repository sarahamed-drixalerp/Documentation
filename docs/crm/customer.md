# العملاء

**العميل (Customer)** هو سجل الحساب الرئيسي في CRM: الهوية التجارية، تصنيف زاتكا، التسعير، الحظر، ومحور الصفقات والمستندات والذمم المرتبطة.

**المسار:** القائمة الجانبية ← المبيعات ← العملاء  
**الصفحات:** `/Entities/CRM/Customer` · `/Entities/CRM/Customer/{رقم}` · `/Entities/CRM/Customer/360/{رقم}`

## ماذا يفعل العميل لأعمالك

- يحمل الاسم ثنائي اللغة والنوع والحالة و**zatcaCustomerType**
- يفصل احتياجات الضريبة/العنوان لـ B2B عن ملفات B2C الأخف
- يدعم Block / UnBlock وAssignPriceList وOpeningBalance وCreateInvoice وAddPayment
- يوفّر مساحة **360** لجهات الاتصال وسلسلة البيع/الذمم كاملة

## نوعان من صفحات العميل

| الصفحة | متى تستخدمها |
|---|---|
| **العرض القياسي** `/Entities/CRM/Customer/{رقم}` | التركيز على التفاصيل وإطار السجل |
| **عرض 360** `/Entities/CRM/Customer/360/{رقم}` | التشغيل اليومي عبر الكيانات المرتبطة |

## قائمة العملاء

### الأعمدة (الأهم)

الاسم، الحالة، مدير الحساب، النطاق، الصناعة، القطاع، المبلغ، المستحق.

### التصفية

بحث، النوع، الحالة، مدير الحساب، الصناعة، القطاع، الدولة.

## الحقول الإلزامية

| الحقل | ملاحظات |
|---|---|
| **name** / **nameAr** | هوية الحساب |
| **type** / **status** | حوكمة السجل |
| **zatcaCustomerType** | إلزامي لتصنيف زاتكا |

### عنوان / ضريبة B2B

لـ **B2B** أكمل حقول الضريبة والعنوان: VAT، المدينة، الولاية، الشارع، الرمز البريدي (حسب إلزام النموذج لذلك النوع).

## إجراءات دورة الحياة

| الإجراء | الوظيفة |
|---|---|
| **Block** / **UnBlock** | تقييد أو استعادة النشاط التجاري على الحساب |
| **AssignPriceList** | ربط قائمة أسعار بالعميل |
| **OpeningBalance** | تعيين أو تعديل الرصيد الافتتاحي |
| **CreateInvoice** | بدء فاتورة ذمم للعميل |
| **AddPayment** | تسجيل دفعة للعميل |

## بعد الحفظ — تبويبات 360

| التبويب | المحتوى |
|---|---|
| **Details** | نموذج العميل |
| **Contacts** | الأشخاص المرتبطون بالحساب |
| **Deal** | الفرص |
| **Pnl** | أوراق P&amp;L |
| **Quote** | عروض الأسعار |
| **CustomerPO** | أوامر شراء العميل |
| **SalesOrder** | أوامر البيع |
| **InvoiceAR** | فواتير المبيعات |
| **ReturnInvoiceAR** / **CreditNoteAR** / **DebitNoteAR** | تعديلات الذمم |
| **Agreement** | الاتفاقيات |
| **Project** | المشاريع المرتبطة |

## كيف تنشئ أو تصون عميلًا

1. افتح قائمة العملاء وأنشئ عميلًا أو افتح سجلًا موجودًا
2. عبّئ الأسماء والنوع والحالة و**zatcaCustomerType**
3. لـ B2B أكمل حقول VAT والعنوان
4. احفظ ثم استخدم Id أو 360 للإجراءات والتبويبات المرتبطة
5. استخدم Block فقط عند وقف النشاط التجاري؛ UnBlock عند الاستعادة

## أفضل الممارسات

:::tip[عيّن zatcaCustomerType قبل إصدار الفواتير]
غياب نوع زاتكا أو خطؤه يعطّل الفوترة النظيفة لاحقًا.
:::

:::warning[B2B يحتاج ضريبة وعنوانًا]
لا تترك VAT أو العنوان فارغين على حسابات B2B التي ستتلقى فواتير رسمية.
:::

:::note[360 هو محور التشغيل]
استخدم 360 عند العمل عبر جهات الاتصال والصفقات ومستندات الذمم لحساب واحد.
:::
