# العطلات

**العطلة (Holiday)** سجل فترة عطلة مع نوع وحالة وتواريخ وخيار التكرار السنوي وسرية بيانات.

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/Holiday`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة العطلات قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/Holiday` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة العطلات بالاسمين وتواريخ البداية والنهاية والأوصاف
- تتيح إنشاء وتعديل وحذف من درج
- توفّر مفتاح **Active?** يُحفظ عبر تعديل العطلة (**editHoliday**)

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| startDate | تاريخ البداية |
| endDate | تاريخ النهاية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح النشاط — يُحفظ |
| actions | تعديل / حذف |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **EntityTypeId** | نعم | نوع الكيان |
| **EntityStatusId** | نعم | حالة الكيان |
| name / nameAr | لا في التحقق الأساسي | الاسم باللغتين |
| description / descriptionAr | لا | الأوصاف |
| startDate | لا | تاريخ البداية |
| endDate | لا | تاريخ النهاية |
| isRepeatedAnnually | لا | هل تتكرر سنويًا |
| DataConfidentialityId | لا | سرية البيانات |

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/Holiday`
2. أنشئ عطلة أو عدّل سجلًا
3. عبّئ **EntityTypeId** و**EntityStatusId** ثم التواريخ والتكرار السنوي عند الحاجة
4. أضف سرية البيانات إن لزم
5. احفظ من الدرج
6. استخدم مفتاح **Active?**؛ التغيير يُpersist عبر التعديل

## أفضل الممارسات

:::tip[حدّد التواريخ قبل الاعتماد التشغيلي]
عبّئ **startDate** و**endDate** بوضوح حتى لا تُفسَّر العطلة بشكل خاطئ في الحضور أو التخطيط.
:::

:::note[التكرار السنوي]
**isRepeatedAnnually** يظهر في النموذج؛ عيّنه وفق سياسة مؤسستك للعطل المتكررة.
:::
