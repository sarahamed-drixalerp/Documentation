# الأقسام

**القسم (Department)** عقدة في الهيكل التنظيمي للمؤسسة. تُصنَّف العقد كقسم أو شعبة أو وحدة وتشكّل شجرة تُستخدم عبر المنصة.

**المسار:** القائمة الجانبية ← المؤسسة ← الأقسام  
**الصفحات:** `/Entities/ORG/Department` · `/Entities/ORG/Department/{رقم}`

## ماذا تفعل هذه الشاشة

- تمثّل الهيكل كـ قسم ← شعبة ← وحدة
- تعيّن مديرًا ومراكز تكلفة/ربح اختيارية
- تعرض الهيكل الفرعي والموظفين المرتبطين في الشجرة وصفحة السجل
- تدعم Insights والأنشطة والمرفقات والسجلات على صفحة السجل

## العروض

| العرض | افتراضي؟ | الغرض |
|---|---|---|
| **الشجرة (Tree)** | نعم | التسلسل مع شارات المستوى (قسم / شعبة / وحدة) |
| **القائمة (List)** | لا | جدول مسطّح مع تصفية |
| **السجل (Id)** | — | تفاصيل كاملة لعقدة واحدة |

### أعمدة القائمة

| العمود | المعنى |
|---|---|
| Name | اسم العقدة |
| Manager | المستخدم المدير |
| EntityType | نوع الكيان |
| Parent | العقدة الأب |
| Actions | إجراءات الصف |

### عوامل التصفية

| التصفية | الاستخدام |
|---|---|
| Name | بحث بالاسم |
| EntityTypeId | تصفية بالنوع |
| EntityStatusId | تصفية بالحالة |
| ParentId | تصفية بالأب |

## حقول نموذج الشجرة

واجهة الإنشاء/التعديل الأساسية هي نموذج الشجرة.

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | الاسم المعروض |
| nameAr | لا | الاسم بالعربية |
| description / descriptionAr | لا | أوصاف اختيارية |
| ManagerUsrId | لا | المستخدم المدير |
| ParentId | لا | العقدة الأب (فارغ للمستوى الأعلى) |
| EntityTypeId | اختياري في الشجرة* | نوع الكيان |
| EntityStatusId | اختياري في الشجرة* | حالة الكيان |
| CostCenterId | لا | مركز التكلفة |
| ProfitCenterId | لا | مركز الربح |

\*في **SaveDetails** يكون **EntityTypeId** و**EntityStatusId** إلزاميين.

## تبويبات الشجرة

| التبويب | الغرض |
|---|---|
| **Details** | هوية وروابط العقدة المحددة |
| **Structure** | العقد الفرعية |
| **Employees** | الموظفون المرتبطون بهذه العقدة (وما تحتها عند الاقتضاء) |

## صفحة السجل (Id)

**الصفحة:** `/Entities/ORG/Department/{رقم}`

| المنطقة | الغرض |
|---|---|
| **Details** | حقول العقدة |
| **Activities** | مجرى الأنشطة |
| **Attachments** | الملفات |
| **Logs** | سجل التغييرات |
| **Insights** | لوحة Insights |

## الإجراءات

| الإجراء | المعنى |
|---|---|
| إنشاء مستوى أعلى | يضيف قسمًا جذريًا |
| إضافة فرع | يضيف شعبة أو وحدة تحت الأب المحدد |
| تعديل | يحدّث العقدة المحددة |
| حذف | يحذف العقدة **فقط إن لم يكن لها أبناء** |

:::danger[لا يمكن الحذف مع وجود أبناء]
إذا وُجد أبناء، يُمنع الحذف وتظهر رسالة في الواجهة. أزل الأبناء أو انقلهم أولًا.
:::

## كيف تستخدم الشاشة

1. افتح الأقسام من المؤسسة
2. فضّل عرض **الشجرة** لعمل الهيكل
3. أنشئ قسمًا في المستوى الأعلى، أو حدّد أبًا وأضف فرعًا
4. عبّئ **name**؛ أضف الاسم العربي والمدير والنوع والحالة والروابط المالية عند الحاجة
5. في مسارات SaveDetails تأكد من تعبئة **EntityTypeId** و**EntityStatusId**
6. استخدم تبويبي **Structure** و**Employees** في الشجرة؛ وافتح `{رقم}` للأنشطة والمرفقات والسجلات وInsights
7. انتقل إلى **القائمة** عند الحاجة للتصفية بالنوع أو الحالة أو الأب

## أفضل الممارسات

:::tip[وضّح المستوى بالنوع]
استخدم EntityType حتى تبقى قسم / شعبة / وحدة مميزة في الشجرة والقائمة.
:::

:::warning[احذف من الأوراق أولًا]
احذف العقد الورقية أولًا. الأب الذي له أبناء لا يُحذف.
:::

:::note[الروابط المالية اختيارية]
CostCenterId وProfitCenterId اختياريان؛ عبئهما فقط عندما يعتمد نموذجك المالي عليهما.
:::
