# العملات

**العملة (Currency)** قيمة مرجعية لأسعار الصرف والعملة الأساسية. توجد أيضًا شاشة عملات ضمن الإدارة؛ راجع [العملات (الإدارة)](/docs/adm/currency).

**المسار:** قد لا تظهر في القائمة الجانبية تحت المؤسسة؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/Currency`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة عملات المؤسسة قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/Currency` يعمل عند توفر الصلاحية. لمسار الإدارة انظر [العملات](/docs/adm/currency).
:::

## ماذا تفعل هذه الشاشة

- تعرض العملات بالاسم والوصف بالإنجليزية والعربية
- تُظهر سعر الصرف (**exchangeRate**) ووقت تحديثه (**exchangeRateTimeStamp**)
- تميّز العملة الأساسية (**isBaseCurrency**)
- توفّر مفتاح **Active?** يُحفظ عبر تعديل العملة (**editCurrency**) في مسار ORG

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| exchangeRate | سعر الصرف |
| isBaseCurrency | هل هذه العملة الأساسية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح النشاط — يُحفظ في مسار ORG عبر التعديل |
| actions | تعديل / حذف |

## الحقول

| الحقل | الاستخدام |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الوصف باللغتين |
| exchangeRate | سعر الصرف |
| exchangeRateTimeStamp | وقت تحديث سعر الصرف |
| isBaseCurrency | هل هذه العملة الأساسية |

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/Currency` (أو مسار الإدارة عند الحاجة)
2. أنشئ أو عدّل عملة بالاسمين والأوصاف
3. عبّئ **exchangeRate** و**exchangeRateTimeStamp** و**isBaseCurrency** حسب الحاجة
4. احفظ من الدرج
5. راجع سعر الصرف ووقت التحديث قبل الاعتماد التشغيلي

## أفضل الممارسات

:::tip[راجع exchangeRateTimeStamp قبل الاعتماد على السعر]
اعتمد على وقت التحديث عند استخدام سعر الصرف في التقارير أو التشغيل.
:::

:::note[العملة الأساسية]
**isBaseCurrency** يحدد العملة المرجعية ضمن قائمة العملات.
:::

:::warning[مساران للعملة]
سلوك واجهة الإدارة قد يختلف (مثل مفتاح Active هناك toast-only). راجع [عملات الإدارة](/docs/adm/currency) عند العمل من مسار ADM.
:::
