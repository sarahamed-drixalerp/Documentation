# أنظمة تقنية المعلومات

**نظام تقنية المعلومات (IT System)** سجل مشابه للأصل مع حقل مورد إضافي (**SupplierId**).

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/ITSystem`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة أنظمة تقنية المعلومات قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/ITSystem` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة الأنظمة بالاسمين والأوصاف
- تتيح إنشاء وتعديل وحذف من درج
- تضيف ربطًا اختياريًا بالمورد عبر **SupplierId**

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح ظاهر — انظر التحذير أدناه |
| actions | تعديل / حذف |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **EntityTypeId** | نعم | نوع الكيان |
| **EntityStatusId** | نعم | حالة الكيان |
| name / nameAr | في SaveDetails: نعم | الاسم باللغتين |
| description / descriptionAr | لا | الأوصاف |
| OwnerUsrId | لا | المالك |
| serial | لا | الرقم التسلسلي |
| purchaseDate | لا | تاريخ الشراء |
| purchaseValue | لا | قيمة الشراء |
| currentValue | لا | القيمة الحالية |
| SupplierId | لا | المورد |

:::warning[مفتاح Active لا يُحفظ مثل الفرع]
تبديل **Active?** على نظام تقنية المعلومات يعرض إشعارًا في الواجهة (toast) بالمعرّف **ولا يُpersist** كما يفعل مفتاح النشاط في [الفروع](/docs/org/branch). لا تعتمد عليه كحفظ فعلي.
:::

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/ITSystem`
2. أنشئ نظامًا أو عدّل سجلًا
3. عبّئ **EntityTypeId** و**EntityStatusId** ثم الاسمين عند SaveDetails
4. أضف المالك والرقم التسلسلي والقيم و**SupplierId** عند الحاجة
5. احفظ من الدرج
6. لا تفترض أن تبديل **Active?** قد حُفظ في الخادم

## أفضل الممارسات

:::tip[اربط المورد عندما يكون معروفًا]
**SupplierId** اختياري؛ عيّنه عند تتبع العقود أو الدعم مع المورد.
:::

:::note[يشبه الأصل مع فروقات الحقول]
المنطق قريب من [الأصول](/docs/org/asset)؛ هنا تظهر **purchaseValue** و**currentValue** كحقول نصية في النموذج، مع **SupplierId** إضافي.
:::
