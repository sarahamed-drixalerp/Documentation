# الفروع

**الفرع (Branch)** سجل موقع تشغيلي للمؤسسة: اسم باللغتين، مالك اختياري، أوصاف، ومفتاح نشاط يُحفظ من القائمة.

**المسار:** القائمة الجانبية ← المؤسسة ← الفروع  
**الصفحة:** `/Entities/ORG/Branch`

## ماذا تفعل هذه الشاشة

- تعرض قائمة الفروع بالاسمين والأوصاف والمالك
- تتيح إنشاء وتعديل وحذف من درج (Drawer)
- توفّر مفتاح **Active?** يُpersist عبر تعديل الفرع (**editBranch**)

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name | الاسم بالإنجليزية |
| nameAr | الاسم بالعربية |
| ownerUsr | المالك (مستخدم) |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح النشاط — التغيير يُحفظ |
| actions | تعديل / حذف |

## الحقول (الإنشاء والتعديل)

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| name | في SaveDetails: نعم* | الاسم بالإنجليزية |
| nameAr | في SaveDetails: نعم* | الاسم بالعربية |
| description / descriptionAr | لا | الأوصاف |
| OwnerUsrId | لا | المالك |

\*في درج الحفظ اليومي الحقول اختيارية في التحقق؛ في **SaveDetails** يكون **name** و**nameAr** إلزاميين. عبّئ الاسمين قبل الاعتماد التشغيلي.

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/Branch`
2. أنشئ فرعًا أو عدّل سجلًا من القائمة
3. عبّئ الاسمين والأوصاف والمالك عند الحاجة
4. احفظ من الدرج
5. استخدم مفتاح **Active?** لتفعيل أو إيقاف الفرع؛ التغيير يُحفظ عبر التعديل
6. احذف فقط عند التأكد من عدم الحاجة للسجل

## أفضل الممارسات

:::tip[وحّد اسم الفرع باللغتين]
اجعل **name** و**nameAr** واضحين قبل ربط المواقع أو السجلات الأخرى بالفرع.
:::

:::warning[Active هنا يُحفظ]
على الفرع يختلف السلوك عن الموقع/الأصل/نظام تقنية المعلومات: تبديل **Active?** يستدعي الحفظ الفعلي.
:::
