# أولويات الخدمة

**أولوية الخدمة (Service Priority)** قيمة مرجعية لأسماء وأوصاف الأولوية مع لون للعرض.

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/ServicePriority`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة أولويات الخدمة قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/ServicePriority` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض أولويات الخدمة بالاسمين والأوصاف
- تتيح إنشاء وتعديل وحذف من درج
- توفّر مفتاح **Active?** يُحفظ عبر تعديل الأولوية (**editServicePriority**)

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح النشاط — يُحفظ |
| actions | تعديل / حذف |

## الحقول

| الحقل | الاستخدام |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الوصف باللغتين |
| color | لون العرض |

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/ServicePriority`
2. أنشئ أو عدّل أولوية خدمة
3. عبّئ الاسمين والأوصاف و**color**
4. احفظ من الدرج
5. استخدم مفتاح **Active?** عند الحاجة؛ التغيير يُpersist عبر التعديل

## أفضل الممارسات

:::tip[وحّد الأسماء واللون مع سياسة الخدمة]
اجعل **name** / **nameAr** و**color** متوافقين مع مستويات الأولوية المعتمدة في الخدمة وSLA.
:::

:::note[اللون للعرض]
**color** حقل نصي في النموذج؛ استخدمه لتمييز الأولوية بصريًا في الواجهات التي تعتمد عليه.
:::
