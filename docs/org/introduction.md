# مقدمة المؤسسة

وحدة **المؤسسة (ORG)** في Drixal ERP هي مركز الهيكل التشغيلي للمؤسسة: الأقسام والفرق والفروع والأهداف والعطلات والمواقع والأصول وأنظمة تقنية المعلومات، إضافة إلى قيم مرجعية مثل العملة ومعدل الضريبة وأولوية الخدمة.

بدون هذه الوحدة يبقى الهيكل والقيم المرجعية غير رسمية: قوائم متفرقة، خطوط تقرير غير واضحة، وبيانات مشتركة تختلف بين الفرق. داخل Drixal تصبح البنية التنظيمية مصدرًا واحدًا متصلًا بالتشغيل.

:::note[بند السطر LineItem ليس في هذا الدليل]
لا توجد قائمة مستقلة لـ **LineItem** تحت المؤسسة. واجهة بنود السطر التجارية تظهر في تدفقات المشاريع والمشتريات. راجع [بنود المشروع](/docs/pmo/line-items).
:::

## ماذا تفعل الوحدة لأعمالك

- تبني شجرة الهيكل: **قسم ← شعبة ← وحدة** (Department → Section → Unit)
- تدير **الفرق** وأعضاءها
- تصون **الفروع** و**الأهداف** و**العطلات**
- تتابع **المواقع** و**الأصول** و**أنظمة تقنية المعلومات**
- تحتفظ بقيم مرجعية من مسار المؤسسة: **العملة** و**معدل الضريبة** و**أولوية الخدمة**
- تشير إلى قيم مشتركة موثّقة في وحدات أخرى: [الدول](/docs/adm/country)، [سرية البيانات](/docs/adm/data-confidentiality)، [ورديات العمل](/docs/hrm/work-shift)

## التسلسل الهرمي

```text
المؤسسة (ORG)
  ├── القسم (شعبة / وحدة)
  ├── الفريق
  │     └── أعضاء الفريق
  ├── الفرع
  ├── الهدف
  ├── العطلة
  ├── الموقع
  ├── الأصل / نظام تقنية المعلومات
  └── قيم مرجعية (عملة، معدل ضريبة، أولوية خدمة)
```

| المستوى | الغرض |
|---|---|
| **القسم** | عقد شجرة الهيكل (قسم / شعبة / وحدة) مع مدير وروابط مالية اختيارية |
| **الفريق** | فريق عمل بقائد وأعضاء |
| **الفرع** | سجل فرع بمالك ومفتاح Active يُحفظ |
| **الهدف** | أهداف المؤسسة بنوع وحالة ومالك اختياري |
| **العطلة** | تواريخ عطلة مع تكرار سنوي وسرية بيانات |
| **الموقع** | مواقع تحت فرع مع أب اختياري |
| **الأصل / نظام تقنية المعلومات** | عناصر قابلة للتتبع؛ نظام تقنية المعلومات يضيف المورد |
| **القيم المرجعية** | عملة ومعدل ضريبة وأولوية خدمة تُستخدم عبر المنصة |

## أين تجده في النظام

**المسار:** القائمة الجانبية ← المؤسسة ← …

من القائمة الجانبية اختر **المؤسسة** ثم (عند الظهور):

- **الأهداف**
- **الأقسام**
- **الفروع**
- **الفرق**

توجد مسارات أخرى تحت المؤسسة بالرابط المباشر حتى إن لم تظهر في مجموعة القائمة (مثل العطلات، المواقع، الأصول، أنظمة تقنية المعلومات، العملات، معدلات الضريبة، أولويات الخدمة).

## من يستخدم هذا القسم

| الدور | الاستخدام اليومي |
|---|---|
| مسؤول المؤسسة / الموارد البشرية | الأقسام، الفرق، الفروع، العطلات |
| قائد العمليات | المواقع، الأصول، أنظمة تقنية المعلومات |
| مشرف مالي | العملات، معدلات الضريبة |
| مشرف الخدمة / SLA | أولويات الخدمة |
| فرق المشاريع والتسليم | الأهداف والهيكل المستخدم عبر الوحدات |

## كيف يُنظَّم دليل المؤسسة

1. [الأقسام](/docs/org/department) — الشجرة والقائمة والهيكل والموظفون وصفحة السجل
2. [الفرق](/docs/org/team) — البطاقات/القائمة، القائد، أعضاء الفريق
3. [الفروع](/docs/org/branch) — القائمة، المالك، حفظ Active
4. [الأهداف](/docs/org/objective) — أهداف بنوع وحالة
5. [العطلات](/docs/org/holiday) — التواريخ والتكرار السنوي
6. [المواقع](/docs/org/location) — التسلسل تحت الفرع والأب
7. [الأصول](/docs/org/asset) — الرقم التسلسلي والقيم والمالك
8. [أنظمة تقنية المعلومات](/docs/org/it-system) — مثل الأصل مع المورد
9. [العملات](/docs/org/currency) — سعر الصرف والعملة الأساسية (انظر أيضًا [عملات الإدارة](/docs/adm/currency))
10. [معدلات الضريبة](/docs/org/tax-rate) — النسبة وتسمية الفاتورة والافتراضي
11. [أولويات الخدمة](/docs/org/service-priority) — الأسماء والأوصاف واللون
12. [المصطلحات](/docs/org/glossary)

قيم مشتركة بلا صفحات مستقلة تحت دليل المؤسسة: [الدول](/docs/adm/country)، [سرية البيانات](/docs/adm/data-confidentiality)، [ورديات العمل](/docs/hrm/work-shift). بنود السطر: [بنود المشروع](/docs/pmo/line-items).

## أفضل الممارسات

:::tip[ابنِ شجرة الأقسام قبل الفرق]
أنشئ هيكل قسم ← شعبة ← وحدة أولًا، ثم اربط الفرق والأشخاص. فريق بلا سياق تنظيمي أوضح أصعب في الحوكمة.
:::

:::warning[اعرف أي مفتاح Active يُحفظ]
على **الفرع** يُpersist مفتاح Active. على **الموقع** و**الأصل** و**نظام تقنية المعلومات** التحكم Active يعرض إشعارًا فقط (toast) ولا يُحفظ مثل الفرع.
:::

:::note[لا توجد قائمة LineItem تحت المؤسسة]
لا تتوقع قائمة بنود سطر تحت المؤسسة. استخدم بنود المشروع في مكتب إدارة المشاريع (والواجهات المرتبطة).
:::
