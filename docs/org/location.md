# المواقع

**الموقع (Location)** سجل موقع فعلي يمكن ربطه بفرع وبموقع أب لبناء تسلسل هرمي.

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/Location`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة المواقع قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/Location` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة المواقع بالاسمين والأوصاف
- تربط الموقع بـ **BranchId** و**ParentId** اختياريًا
- تتيح إنشاء وتعديل وحذف من درج

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح ظاهر — انظر التحذير أدناه |
| actions | تعديل / حذف |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| name / nameAr | في SaveDetails: نعم | الاسم باللغتين |
| description / descriptionAr | لا | الأوصاف |
| OwnerUsrId | لا | المالك |
| BranchId | لا | الفرع المرتبط |
| ParentId | لا | الموقع الأب (تسلسل هرمي) |

:::warning[مفتاح Active لا يُحفظ مثل الفرع]
تبديل **Active?** على الموقع يعرض إشعارًا في الواجهة (toast) بالمعرّف **ولا يُpersist** كما يفعل مفتاح النشاط في [الفروع](/docs/org/branch) عبر **editBranch**. لا تعتمد على هذا المفتاح كحفظ فعلي لحالة النشاط.
:::

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/Location`
2. أنشئ موقعًا أو عدّل سجلًا
3. عبّئ الاسمين (مطلوبان في SaveDetails)
4. اربط **BranchId** و**ParentId** عند بناء التسلسل
5. احفظ من الدرج
6. لا تفترض أن تبديل **Active?** قد حُفظ في الخادم

## أفضل الممارسات

:::tip[اربط الموقع بالفرع قبل التوسع]
عيّن **BranchId** مبكرًا حتى تبقى المواقع مقروءة ضمن الفرع الصحيح.
:::

:::note[ParentId للتسلسل]
استخدم **ParentId** عندما يكون الموقع تابعًا لموقع آخر (مثل مبنى داخل مجمع).
:::
