# الأصول

**الأصل (Asset)** سجل أصل قابل للتتبع: نوع وحالة، مالك اختياري، رقم تسلسلي، تاريخ شراء، وقيم شراء/حالية (≥ 0).

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/Asset`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة الأصول قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/Asset` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة الأصول بالاسمين والأوصاف
- تتيح إنشاء وتعديل وحذف من درج
- تقيّد قيم الشراء والقيمة الحالية لتكون ≥ 0

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح ظاهر — انظر التحذير أدناه |
| actions | تعديل / حذف |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **EntityTypeId** | نعم | نوع الكيان |
| **EntityStatusId** | نعم | حالة الكيان |
| name / nameAr | في SaveDetails: نعم | الاسم باللغتين |
| description / descriptionAr | لا | الأوصاف |
| OwnerUsrId | لا | المالك |
| serial | لا | الرقم التسلسلي |
| purchaseDate | لا | تاريخ الشراء |
| purchaseValue_val | لا | قيمة الشراء (≥ 0) |
| currentValue_val | لا | القيمة الحالية (≥ 0) |

:::warning[مفتاح Active لا يُحفظ مثل الفرع]
تبديل **Active?** على الأصل يعرض إشعارًا في الواجهة (toast) بالمعرّف **ولا يُpersist** كما يفعل مفتاح النشاط في [الفروع](/docs/org/branch). لا تعتمد عليه كحفظ فعلي.
:::

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/Asset`
2. أنشئ أصلًا أو عدّل سجلًا
3. عبّئ **EntityTypeId** و**EntityStatusId** ثم الاسمين عند SaveDetails
4. أضف المالك والرقم التسلسلي والتواريخ والقيم (≥ 0) عند الحاجة
5. احفظ من الدرج
6. لا تفترض أن تبديل **Active?** قد حُفظ في الخادم

## أفضل الممارسات

:::tip[ثبّت النوع والحالة قبل القيم]
أكمل **EntityTypeId** و**EntityStatusId** أولًا؛ ثم أدخل قيم الشراء والحالية بأرقام غير سالبة.
:::

:::note[القيم ≥ 0]
**purchaseValue_val** و**currentValue_val** يقبلان أرقامًا ≥ 0 فقط في التحقق.
:::
