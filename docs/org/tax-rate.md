# معدلات الضريبة

**معدل الضريبة (Tax Rate)** قيمة مرجعية لنسبة الضريبة وتسمية الفاتورة وتعيين الافتراضي.

**المسار:** قد لا تظهر في القائمة الجانبية؛ استخدم المسار المباشر  
**الصفحة:** `/Entities/ORG/TaxRate`

:::note[قد لا تظهر في القائمة الجانبية]
صفحة معدلات الضريبة قد لا تظهر ضمن مجموعة المؤسسة في الشريط الجانبي؛ المسار `/Entities/ORG/TaxRate` يعمل عند توفر الصلاحية.
:::

## ماذا تفعل هذه الشاشة

- تعرض معدلات الضريبة بالاسمين والنسبة والأوصاف
- تتيح إنشاء وتعديل وحذف من درج
- توفّر مفتاح **Active?** يُحفظ عبر تعديل المعدل (**editTaxRate**)

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| taxValue_prc | نسبة الضريبة |
| description / descriptionAr | الأوصاف |
| Active? | مفتاح النشاط — يُحفظ |
| actions | تعديل / حذف |

## الحقول

| الحقل | الاستخدام |
|---|---|
| name / nameAr | الاسم بالإنجليزية والعربية |
| description / descriptionAr | الوصف باللغتين |
| taxValue_prc | نسبة الضريبة |
| labelOnInvoice | التسمية الظاهرة على الفاتورة |
| isDefault | هل هذا المعدل الافتراضي |

## كيف تستخدم الشاشة

1. افتح `/Entities/ORG/TaxRate`
2. أنشئ أو عدّل معدل ضريبة
3. عبّئ الاسمين و**taxValue_prc** و**labelOnInvoice** و**isDefault** عند الحاجة
4. احفظ من الدرج
5. استخدم مفتاح **Active?** عند الحاجة؛ التغيير يُpersist عبر التعديل

## أفضل الممارسات

:::tip[وحّد تسمية الفاتورة]
اجعل **labelOnInvoice** مطابقًا لما يظهر للعميل في الفواتير حتى لا تختلف النصوص بين الفرق.
:::

:::note[المعدل الافتراضي]
**isDefault** يميّز المعدل المستخدم افتراضيًا ضمن القائمة.
:::
