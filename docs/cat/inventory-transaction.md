# حركة المخزون

**حركة المخزون (Inventory Transaction)** تسجّل إضافة أو سحب أو نقل كميات منتجات بين المخازن. تُنشأ كمسودة ثم تُرحَّل؛ بعد الترحيل يُقفل السجل ويمكن معاينة قيد يومية.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← حركات المخزون  
**القائمة:** `/Entities/CAT/InventoryTransaction`  
**إنشاء:** `/Entities/CAT/InventoryTransaction/new?type=...`  
**السجل:** `/Entities/CAT/InventoryTransaction/{رقم}`

## أنواع الحركة

| النوع | المعنى | المخزن المطلوب |
|---|---|---|
| **Add** | إضافة للمخزن | **ToInventory** |
| **Withdraw** | سحب من المخزن | **FromInventory** |
| **Transfer** | نقل بين مخزنين | **FromInventory** و**ToInventory** |

## أعمدة القائمة والفلاتر

| العمود | المعنى |
|---|---|
| **name** | اسم الحركة |
| **From / To** | المخزن المصدر / الهدف |
| **transactionDate** | تاريخ الحركة |
| **entityTypeName** | النوع |
| **entityStatusName** | الحالة |
| **actions** | فتح / إجراءات الصف |

**الفلاتر:** بحث بالاسم/الرقم؛ EntityTypeId؛ EntityStatusId؛ FromInventoryId؛ ToInventoryId؛ CustomerId؛ SupplierId.

## الحقول الإلزامية

| الحقل | الاستخدام |
|---|---|
| **transactionDate** | تاريخ الحركة |
| **dataConfidentialityId** | سرية البيانات |
| **toInventoryId** | مطلوب في Add وTransfer |
| **fromInventoryId** | مطلوب في Withdraw وTransfer |

## الحقول الاختيارية

| الحقل | الاستخدام |
|---|---|
| **supplierId** | المورد — واجهة الإضافة (Add) |
| **customerId** | العميل — واجهة السحب (Withdraw) |
| **name** / الأوصاف / **entityTypeId** | تسمية وتصنيف إضافيان |

## بنود الحركة

كل بند يتطلب **Product** و**الكمية**. في النقل قد تظهر أعمدة رصيد مرتبطة بالتحويل.

## دورة Draft → Post

1. أنشئ الحركة بالنوع المناسب من القائمة
2. عبّئ التاريخ والسرية والمخزن/المخازن والبنود
3. احفظ كمسودة
4. اضغط **Post**؛ تظهر معاينة **Journal Entry** ببنود مدين/دائن محسوبة مع حوار الترحيل
5. بعد الترحيل يُقفل السجل

:::danger[شرط الترحيل]
يُعتبر السجل مرحّلًا إذا تضمّن اسم الحالة `post` (أو ما يكافئه في الواجهة مثل مرحل) **أو** كان `entityStatusId === 159`.
:::

## كيف تستخدم الشاشة

1. من القائمة اختر Add أو Withdraw أو Transfer
2. عبّئ الحقول الإلزامية حسب النوع
3. أضف بنود Product + الكمية
4. اربط Supplier عند الإضافة أو Customer عند السحب إن لزم
5. احفظ ثم رحّل بعد مراجعة معاينة القيد

## أفضل الممارسات

:::tip[راجع المخزن المصدر والهدف قبل النقل]
في Transfer كلا الحقلين إلزاميان؛ خطأ الاتجاه ينقل الرصيد للمخزن الخطأ بعد القفل.
:::

:::warning[لا تعدّل بعد الترحيل]
بعد Post تُقفل الحركة. صحّح بمسودة جديدة وفق سياسة العمليات إن لزم.
:::

:::note[المعاينة ليست شاشة قيود مستقلة]
معاينة Journal Entry جزء من مسار الترحيل على الحركة، وليست بديلًا عن دفتر اليومية المالي الكامل.
:::
