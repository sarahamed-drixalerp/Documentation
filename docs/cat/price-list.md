# قائمة الأسعار

**قائمة الأسعار (Price List)** تعريف تسعير كمي للمنتجات: اسمان، سرية بيانات، وبنود منتج بسعر وحدود كمية من/إلى.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← قوائم الأسعار  
**القائمة:** `/Entities/CAT/PriceList`  
**إنشاء:** `/Entities/CAT/PriceList/new`  
**السجل:** `/Entities/CAT/PriceList/{رقم}`

## ماذا تفعل هذه الشاشة

- تنشئ قوائم أسعار بأسماء ثنائية وسرية
- تضيف بنود منتج مع سعر الوحدة ونطاق الكمية
- تُعرض في درج الإنشاء بتبويبي General وProducts

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| **name** / **nameAr** | الاسم بالإنجليزية والعربية |
| **description** / **descriptionAr** | الأوصاف |
| **Active?** | النشاط |
| **actions** | تعديل / حذف |

## الحقول الإلزامية (الرأس)

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم بالإنجليزية |
| **nameAr** | الاسم بالعربية |
| **dataConfidentialityId** | سرية البيانات |

## الحقول الاختيارية (الرأس)

| الحقل | الاستخدام |
|---|---|
| **description** / **descriptionAr** | الأوصاف |

## بنود المنتجات

| الحقل | الاستخدام |
|---|---|
| **Product** (+ UOM عبر اختيار منتج/وحدة) | المنتج ووحدة القياس |
| **unitPrice_val** | سعر الوحدة |
| **fromQuantity_dec** | من كمية |
| **toQuantity_dec** | إلى كمية |

البنود تدعم الإنشاء والتعديل والحذف داخل القائمة.

## التبويبات / الأقسام

| القسم | المحتوى |
|---|---|
| **General** | الاسمين، الأوصاف، السرية |
| **Products** | جدول بنود التسعير |

على صفحة السجل تظهر الحقول والأقسام عبر SaveDetails، مع أنشطة/مرفقات/سجلات من قائمة الإضافات عند توفرها.

## كيف تستخدم الشاشة

1. افتح `/Entities/CAT/PriceList/new` أو أنشئ من القائمة
2. عبّئ **name** و**nameAr** و**dataConfidentialityId** في General
3. أضف بنود Products: منتج، سعر، FromQty، ToQty
4. احفظ وافتح السجل `/Entities/CAT/PriceList/{رقم}` للمتابعة

## أفضل الممارسات

:::tip[حدّد نطاق الكمية بوضوح]
اجعل **fromQuantity_dec** و**toQuantity_dec** غير متداخلين لنفس المنتج داخل القائمة حتى لا يلتبس السعر عند البيع.
:::

:::note[السرية إلزامية]
لا يُحفظ الرأس بدون **dataConfidentialityId**.
:::
