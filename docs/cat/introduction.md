# مقدمة كتالوج المنتجات

وحدة **كتالوج المنتجات (Product Catalogue / CAT)** في Drixal ERP هي مركز تعريف المنتجات والخدمات والتسعير والمخزون. تجمع الشجرة التصنيفية، المنتجات، وحدات القياس، قوائم الأسعار، المخازن، وحركات المخزون في مساحة واحدة، ثم تربط كل منتج بقدراته التجارية والضريبية والتخزينية.

بدون هذه الوحدة تبقى الأصناف متفرقة: سعر في عرض، رصيد في ملف، وتصنيف في جداول. داخل Drixal يصبح المنتج سجلًا متصلًا بالفئة والعلامة والوحدة والمخزن وقائمة الأسعار.

## ماذا تفعل الوحدة لأعمالك

- توحّد لغة العمل: وحدة سوق ← فئة ← علامة ← موديل ← منتج
- تعطي العمليات شاشة واحدة لتعريف البيع والشراء والتخزين والتكلفة
- تمكّن الإدارة من رؤية هامش الربح وتنبيهات إعادة الطلب من اللوحة
- تربط الكتالوج بالمبيعات والمشتريات والمخزون عبر الأسعار والحركات

## التسلسل الهرمي

```text
وحدة السوق (MarketUnit)
  └── فئة المنتج (ProductCategory)
        └── العلامة (Brand)
              └── الموديل (BrandModel)
                    └── المنتج (Product)
                          ├── وحدات قياس المنتج (ProductUOMs)
                          ├── المخرجات (Deliverables)
                          ├── المخزونات (Inventories)
                          └── المنتجات الفرعية / الحزم (SubProducts)
```

| المستوى | الغرض |
|---|---|
| **وحدة السوق (MarketUnit)** | جذر التصنيف في الشجرة والفلاتر |
| **فئة المنتج (ProductCategory)** | تجميع المنتجات تحت وحدة سوق اختيارية |
| **العلامة / الموديل (Brand / BrandModel)** | تصنيف تجاري أدق للمنتج |
| **المنتج (Product)** | وحدة التشغيل اليومية: سعر، تكلفة، قدرات، ضريبة |
| **المخزن والحركة** | رصيد المنتج وحركات الإضافة والسحب والنقل |
| **قائمة الأسعار / وحدة القياس** | تسعير كمي وهيكل الوحدات الأساسية والفرعية |

يمكنك فتح المنتج مباشرة من القائمة. الربط بوحدة السوق والفئة والعلامة اختياري عند الإنشاء لكنه مهم للشجرة والتقارير.

## أين تجده في النظام

من القائمة الجانبية اختر **كتالوج المنتجات** ثم:

- لوحة الكتالوج
- **المنتجات** ← محور هذا الدليل
- شجرة المنتجات
- فئات المنتجات
- قوائم الأسعار
- وحدات السوق
- معدلات الضريبة
- وحدات القياس
- أنواع التداول
- المخازن
- حركات المخزون

## من يستخدم هذا القسم

| الدور | الاستخدام اليومي |
|---|---|
| مدير الكتالوج | تعريف المنتجات والتصنيف والتسعير |
| المخازن | المخازن والأرصدة وحركات الإضافة/السحب/النقل |
| المبيعات | أسعار البيع وقوائم الأسعار والوصف التحذيري عند البيع |
| المشتريات | التكلفة والوصف التحذيري عند الشراء والمورد في الإضافة |
| المالية | معدلات الضريبة ومعاينة القيود عند ترحيل الحركة |

## كيف يُنظَّم دليل كتالوج المنتجات

1. فهم التسلسل الهرمي واللوحة
2. تعريف المنتجات ودورة Draft → Post
3. تصفح الشجرة والأرصدة
4. إدارة المخازن وحركات المخزون
5. قوائم الأسعار ووحدات القياس
6. البيانات المرجعية (وحدة سوق، فئة، علامة، ضريبة، lookups)

## أفضل الممارسات

:::tip[ابنِ التصنيف قبل تكديس المنتجات]
أنشئ وحدات السوق والفئات والعلامات أولًا، ثم أضف المنتجات. التصنيف اللاحق يصعّب الشجرة والفلاتر.
:::

:::warning[الترحيل يقفل السجل]
ترحيل المنتج أو حركة المخزون يحوّل السجل إلى وضع مقفول للقراءة حسب قواعد الحالة. راجع قبل الضغط على Post.
:::
