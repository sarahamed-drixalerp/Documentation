# المنتج

**المنتج (Product)** هو سجل الكتالوج التشغيلي: الاسم، السعر، التكلفة، القدرات التجارية، التصنيف، والضريبة. من القائمة تُنشئ وتُصفّي وتُجمّع؛ من صفحة الرقم تُدير التفاصيل والتبويبات التابعة حتى الترحيل.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← المنتجات  
**القائمة:** `/Entities/CAT/Product`  
**إنشاء:** `/Entities/CAT/Product/new`  
**السجل:** `/Entities/CAT/Product/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرض المنتجات بالاسم والحالة وسعر الوحدة وتكلفة الوحدة
- تتيح التصفية بالنوع والحالة، والتجميع بالنوع/الحالة/الفئة/وحدة السوق/معدل الضريبة
- تدعم عرض البطاقات ومعاينة **DlgView** دون فتح السجل كاملًا
- تربط المنتج بوحدات القياس والمخرجات والمخزونات والحزم بعد الإنشاء

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| **name** | الاسم مع صورة مصغّرة ورابط للسجل |
| **entityStatusName** | حالة السجل |
| **unitPrice_val** | سعر الوحدة (بيع) |
| **unitCost_val** | تكلفة الوحدة (شراء) |
| **actions** | معاينة / تعديل / حذف |

**الفلاتر:** بحث بالاسم؛ **Product.EntityTypeId**؛ **Product.EntityStatusId**.

**العروض:** قائمة | بطاقات | شجرة (تجميع).

**التجميع:** EntityTypeId، EntityStatusId، ProductCategoryId، MarketUnitId، TaxRateId.

### عرض البطاقات

كل بطاقة تعرض الصورة/شارة الحالة، العنوان، الفئة · وحدة السوق، السعر، وإجراءات تعديل/حذف. النقر يفتح `/Entities/CAT/Product/{رقم}`. ترقيم الصفحات: 12 / 24 / 36.

### معاينة DlgView

أيقونة العين تفتح حوار معاينة للقراءة فقط: الاسمين، الحالة، الرقم، SKU، PN، السعر/التكلفة، التصنيف، وحدة القياس، أعلام القدرات، والوصف، مع زر فتح المنتج.

## الحقول الإلزامية

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم بالإنجليزية |
| **nameAr** | الاسم بالعربية |

## الحقول الاختيارية

| الحقل | الاستخدام |
|---|---|
| **pN** | رقم الجزء الخارجي (PN) |
| **sKUNo** | المعرّف الداخلي (SKU) |
| **uOMId** | وحدة القياس الأساسية |
| **marketUnitId** → **productCategoryId** → **brandId** → **brandModelId** | تصنيف متسلسل؛ مسح الأب يمسح الأبناء |
| **taxRateId** | معدل الضريبة |
| **tradingTypeId** | نوع التداول |
| **deliveryProofId** | إثبات التسليم |
| **billingFrequencyId** | تكرار الفوترة |
| **reOrderLimit_dec** | حد إعادة الطلب (≥ 0) |
| **unitPrice_val** / **unitCost_val** | سعر وتكلفة الوحدة |
| **descriptionSales** / **descriptionPurchase** | وصف البيع / الشراء |
| **warningSales** / **warningPurchase** | تحذير عند البيع / الشراء |
| **description** / **descriptionAr** | الوصف العام |
| **photoUrl** | صور المنتج (مرفقات كيان) |
| **dataConfidentialityId** | سرية البيانات |
| **entityTypeId** / **entityStatusId** | النوع والحالة |

## القدرات

| القدرة | المعنى |
|---|---|
| **IsCanBeSold** | يمكن بيعه |
| **IsCanBePurchased** | يمكن شراؤه |
| **IsCanBeExpensed** | يمكن صرفه كنفقة |
| **IsCanBeStored** | يمكن تخزينه |
| **IsCanBeDecimal** | يسمح بالكميات العشرية |

في درج الإنشاء السريع تظهر Sold / Purchased؛ في تفاصيل السجل تظهر القدرات الخمس كاملة.

## دورة Draft → Post

1. أنشئ المنتج بالحقلين الإلزاميين واحفظ
2. أكمل التصنيف والأسعار والقدرات
3. اضغط **Post** عبر حوار الترحيل بعد وجود السجل
4. عند الترحيل تُقفل الحقول ويُخفى الحفظ/الترحيل وتصبح المرفقات للقراءة فقط

:::danger[الترحيل يقفل النموذج]
يُعتبر المنتج مرحّلًا عندما يتضمن اسم الحالة (بعد التحويل لحروف صغيرة) أحد: `post` أو `مرحل` أو `منشور` أو `publish`. لا يُستخدم رقم حالة ثابت للمنتج.
:::

## تبويبات السجل `/Entities/CAT/Product/{رقم}`

| التبويب | المحتوى |
|---|---|
| **Details** | نموذج التفاصيل والحفظ/الترحيل |
| **ProductUOMs** | وحدات قياس مرتبطة: UOM + unitPrice_val / unitCost_val — إنشاء/تعديل/حذف |
| **Deliverables** | مخرجات باسم — إنشاء/تعديل/حذف |
| **Inventories** | ربط مخازن باسم — إنشاء/تعديل/حذف |
| **SubProducts** | حزم/منتجات فرعية باسم — إنشاء/تعديل/حذف |

### أنشطة / مرفقات / سجلات

من قائمة الإضافات على السجل:

- **Activities** عبر مكوّن الأنشطة العام
- **Attachments**
- **Logs**

:::note[ProductActivity ListSub]
يوجد مكوّن `ProductActivity/ListSub` بإنشاء وتعديل وحذف، لكنه غير مُثبَّت كتبويب على صفحة المنتج الحالية. الأنشطة الظاهرة من قائمة الإضافات هي مسار الأنشطة العام.
:::

## كيف تستخدم الشاشة

1. افتح قائمة المنتجات
2. صفِّ بالنوع أو الحالة أو بدّل إلى البطاقات/التجميع عند الحاجة
3. أنشئ منتجًا من **Create New Product** أو عدّل صفًا موجودًا
4. عبّئ **name** و**nameAr** ثم اختياريًا PN/SKU والتصنيف المتسلسل والقدرات
5. احفظ، ثم أدر التبويبات التابعة (UOMs، Deliverables، Inventories، SubProducts)
6. رحّل عند اكتمال التعريف إذا كانت السياسة تتطلب القفل

## أفضل الممارسات

:::tip[عرّف وحدة القياس قبل التسعير المتعدد]
اربط **uOMId** الأساسي أولًا، ثم أضف صفوف ProductUOM لأسعار وحدات إضافية.
:::

:::warning[التصنيف متسلسل]
لا يمكن اختيار فئة بلا وحدة سوق مختارة في الواجهة، ولا علامة بلا فئة، ولا موديل بلا علامة. امسح الأب بحذر لأنه يمسح الأبناء.
:::

:::note[الصورة تُقفل بعد الترحيل]
مكوّن الصور يصبح للقراءة فقط عندما يكون المنتج مرحّلًا.
:::
