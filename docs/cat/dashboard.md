# لوحة كتالوج المنتجات

**لوحة كتالوج المنتجات (CAT Dashboard)** ملخص تحليلي لقيمة الكتالوج، هامش الربح، صحة المخزون، توزيع الفئات، والقدرات التجارية. الشاشة للقراءة والتنقل فقط — لا إنشاء ولا تعديل ولا حذف.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← لوحة الكتالوج  
**الصفحة:** `/Entities/CAT/Dashboard`

## الفلاتر

| الفلتر | المعنى |
|---|---|
| **Filter Category** | فئة واحدة أو الكل |
| **Capability Filter** | `all` / `sold` / `purchased` / `expensed` |

بعد تغيير الفلتر تُعاد تحميل بيانات اللوحة، ويظهر عدد العناصر المطابقة.

## مؤشرات الملخص (KPIs)

| المؤشر | المعنى |
|---|---|
| **Total Products** | عدد المنتجات بعد الفلتر |
| **Avg Margin** | متوسط هامش الربح % |
| **Total Sales Val** | مجموع قيم البيع المعروضة |
| **Categories** | عدد الفئات |
| **Re-Order Alerts** | تنبيهات حد إعادة الطلب |

## بطاقات الرسوم

| البطاقة | المحتوى |
|---|---|
| **Profit Margin % by Category** | متوسط الهامش عبر الفئات |
| **Pricing Tier Distribution** | توزيع المنتجات على شرائح سعرية |
| **Category Distribution** | عدد المنتجات لكل فئة |
| **Re-Order & Stock Health** | منتجات بحدود أمان مقابل القياسي |
| **Status & Lifecycle Breakdown** | توزيع الحالات (مثل Active / Draft / Archived) |

## أعلى المنتجات هامشًا

جدول **Top Highest Margin Products** يعرض أعلى 5 منتجات حسب هامش الربح الإجمالي مع الأعمدة: SKU، اسم المنتج، الفئة، تكلفة الوحدة، سعر الوحدة، هامش الربح.

رابط **View All Products** يفتح `/Entities/CAT/Product`.

## إجراءات سريعة

| الإجراء | الوجهة / الوظيفة |
|---|---|
| **Products** | `/Entities/CAT/Product` |
| **Categories** | `/Entities/CAT/ProductCategory` |
| **Refresh** | إعادة تحميل بيانات اللوحة |

## أفضل الممارسات

:::tip[حدّث اللوحة قبل اجتماع التسعير]
اضغط Refresh وطبق فلتر الفئة/القدرة المناسب حتى تعكس الأرقام آخر المنتجات.
:::

:::note[الملخص يعكس البيانات المحمّلة]
المؤشرات تُحسب من قائمة المنتجات التي تُرجعها واجهة اللوحة لصلاحياتك؛ ليست تقريرًا محاسبيًا مقفلاً.
:::

:::warning[لا CRUD على اللوحة]
التعديل يتم من شاشات المنتجات والفئات والمخزون، وليس من بطاقات اللوحة.
:::
