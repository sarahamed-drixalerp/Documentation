# المخزن

**المخزن (Inventory)** موقع تخزين تشغيلي بأسماء ثنائية وسرية بيانات، ويمكن ربطه بمالك وموقع. من صفحة الرقم تُدار منتجات المخزن وأرصدتها. لا يوجد ترحيل (Post) على المخزن نفسه.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← المخازن  
**القائمة:** `/Entities/CAT/Inventory`  
**إنشاء:** `/Entities/CAT/Inventory/new`  
**السجل:** `/Entities/CAT/Inventory/{رقم}`

## ماذا تفعل هذه الشاشة

- تنشئ وتعدّل مخازن بالاسمين وسرية البيانات
- تربط اختياريًا مالكًا (OwnerUsr) وموقعًا (Location)
- تدير جدول منتجات المخزن: إضافة / تعديل / حذف مع الرصيد
- تُستخدم كمصدر أو هدف في حركات المخزون

## الحقول الإلزامية

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم بالإنجليزية |
| **nameAr** | الاسم بالعربية |
| **dataConfidentialityId** | سرية البيانات |

## الحقول الاختيارية

| الحقل | الاستخدام |
|---|---|
| **ownerUsrId** | المستخدم المالك (OwnerUsr) |
| **locationId** | الموقع |
| **description** / **descriptionAr** | الأوصاف |

## جدول المنتجات على السجل

| العمود | المعنى |
|---|---|
| **productName** | المنتج |
| **balance** (Balance_dec) | الرصيد |
| **actions** | تعديل / حفظ / حذف |

يمكنك إضافة صف منتج جديد ثم حفظه أو حذفه عبر واجهات ProductInventory.

:::warning[لا Post على المخزن]
صفحة المخزن للحفظ فقط. قفل الحركات يتم على **حركة المخزون** بعد الترحيل، وليس على سجل المخزن.
:::

## كيف تستخدم الشاشة

1. افتح قائمة المخازن وأنشئ مخزنًا جديدًا
2. عبّئ **name** و**nameAr** و**dataConfidentialityId**
3. أضف OwnerUsr وLocation عند الحاجة ثم احفظ
4. من السجل أدر جدول المنتجات والأرصدة
5. نفّذ الحركات الفعلية من شاشة حركات المخزون

## أفضل الممارسات

:::tip[عرّف السرية مع الإنشاء]
**dataConfidentialityId** إلزامي؛ لا تؤجل اختياره حتى لا يفشل الحفظ.
:::

:::note[الرصيد يتحرك بالحركات]
تعديل صفوف المنتجات على المخزن يدير الربط والرصيد المعروض؛ الإضافة والسحب والنقل التشغيلية تتم عبر Inventory Transaction.
:::
