# المصطلحات

تعريفات مختصرة كما تظهر في كتالوج منتجات Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| كتالوج المنتجات (CAT) | وحدة تعريف المنتجات والخدمات والتسعير والمخزون والبيانات المرجعية |
| وحدة السوق (MarketUnit) | جذر التصنيف في الشجرة؛ قيمة مرجعية بلون اختياري |
| فئة المنتج (ProductCategory) | تجميع تحت وحدة سوق اختيارية |
| علامة (Brand) | مستوى تصنيفي تحت الفئة |
| موديل (BrandModel) | مستوى تحت العلامة؛ صفحة رقم دون قائمة جانبية مستقلة معتادة |
| منتج (Product) | سجل الكتالوج: سعر، تكلفة، قدرات، ضريبة، تصنيف |
| شجرة المنتجات (Product Tree) | تصفح هرمي + شبكة أرصدة مستودع بلا إنشاء |
| لوحة CAT (Dashboard) | مؤشرات ورسوم للكتالوج بلا CRUD |
| وحدة قياس (UOM) | وحدة أساسية (كمية 1) أو فرعية (كمية > 1 مع أب) |
| وحدة قياس منتج (ProductUOM) | ربط منتج بوحدة مع سعر/تكلفة على تبويب المنتج |
| قائمة أسعار (Price List) | رأس تسعير + بنود منتج بسعر ونطاق كمية |
| مخزن (Inventory) | موقع تخزين؛ بلا Post على السجل نفسه |
| حركة مخزون (Inventory Transaction) | Add / Withdraw / Transfer مع ترحيل ومعاينة قيد |
| ترحيل (Post) | تثبيت الحالة وقفل النموذج (منتج بالاسم؛ حركة بالاسم أو statusId 159) |
| قدرات المنتج | CanBeSold / Purchased / Expensed / Stored / Decimal |
| معدل ضريبة (Tax Rate) | نسبة، تسمية فاتورة، افتراضي؛ واجهة CAT وORG |
| تكرار فوترة (BillingFrequency) | lookup يُختار على المنتج |
| إثبات تسليم (DeliveryProof) | lookup يُختار على المنتج |
| نوع تداول (TradingType) | lookup يُختار على المنتج |
| نوع خصم (DiscountType) | lookup مرجعي للخصم |
| نوع هامش إدارة (ManagementBufferType) | lookup بهامش/مصدّة؛ تحقق اسم أضعف |
| مخرج (Deliverable) | سجل فرعي باسم على تبويب المنتج |
| حزمة / منتج فرعي (SubProduct / Bundle) | ربط منتجات فرعية على تبويب SubProducts |
| سرية البيانات (DataConfidentiality) | تصنيف إلزامي على المخزن وقائمة الأسعار وحركة المخزون |
| معاينة DlgView | حوار قراءة سريعة للمنتج من القائمة |
| معاينة قيد (Journal Entry) | بنود مدين/دائن مع ترحيل حركة المخزون |
