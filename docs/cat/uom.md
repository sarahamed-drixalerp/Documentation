# وحدة القياس

**وحدة القياس (UOM)** تعرّف الوحدات الأساسية والفرعية للكميات. الوحدة بلا أب يجب أن تكون كميتها 1؛ الفرعية ترتبط بأب وبكمية أكبر من 1.

**المسار:** القائمة الجانبية ← كتالوج المنتجات ← وحدات القياس  
**القائمة:** `/Entities/CAT/UOM`  
**إنشاء:** `/Entities/CAT/UOM/new`  
**السجل:** `/Entities/CAT/UOM/{رقم}`

## ماذا تفعل هذه الشاشة

- تدير وحدات القياس بالاسم والاختصارات والدقة والكمية
- تربط وحدات فرعية بأب عبر Parent
- تعرض الوحدات الفرعية في ListSub على السجل

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| **name** / **nameAr** | الاسم |
| **abbrvShort** / **abbrvLong** | الاختصار القصير / الطويل |
| **quantity_dec** | معامل الكمية |
| **roundingPrecision_dec** | دقة التقريب |
| **unitPrice_val** | سعر اختياري |
| **actions** | فتح / إجراءات |

## الحقول الإلزامية

| الحقل | الاستخدام |
|---|---|
| **name** | الاسم |
| **quantity_dec** | الكمية — انظر القاعدة أدناه |
| **roundingPrecision_dec** | دقة التقريب (≥ 0) |

### قاعدة quantity_dec

| الحالة | القيمة المطلوبة |
|---|---|
| بلا **parentId** (وحدة أساسية) | يجب أن تساوي **1** |
| مع **parentId** (وحدة فرعية) | يجب أن تكون **> 1** |

## الحقول الاختيارية

| الحقل | الاستخدام |
|---|---|
| **nameAr** | الاسم بالعربية |
| **description** / **descriptionAr** | الأوصاف |
| **abbrvShort** / **abbrvLong** | الاختصارات |
| **parentId** | الوحدة الأب |
| **unitPrice_val** / **unitCost_val** | سعر / تكلفة اختياريان (≥ 0 إن وُجدا) |

## الوحدات الفرعية (ListSub)

على السجل تظهر قائمة فرعية بالأعمدة: name، abbrvShort، quantity_dec، roundingPrecision_dec مع إنشاء/تعديل/حذف.

## كيف تستخدم الشاشة

1. أنشئ وحدة أساسية: **name**، **quantity_dec = 1**، **roundingPrecision_dec**
2. أنشئ وحدات فرعية مع Parent وكمية أكبر من 1
3. اربط المنتجات بوحدات أساسية من شاشة المنتج، وأضف ProductUOMs عند الحاجة

## أفضل الممارسات

:::tip[أبقِ الوحدات الأساسية نظيفة]
لا تضع أبًا لوحدة أساسية؛ القاعدة تفرض الكمية 1 عند غياب الأب.
:::

:::warning[الكمية الفرعية يجب أن تكون > 1]
قيمة 1 مع أب أو قيمة غير 1 بلا أب ترفضها الواجهة برسالة قاعدة الكمية.
:::
