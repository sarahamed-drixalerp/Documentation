# معدلات الضريبة

**معدل الضريبة (Tax Rate)** قيمة مرجعية لنسبة الضريبة وتسمية الفاتورة وتعيين الافتراضي. ضمن كتالوج المنتجات تُختار على المنتج عبر **taxRateId**.

**المسار (كتالوج المنتجات):** القائمة الجانبية ← كتالوج المنتجات ← معدلات الضريبة  
**الصفحة (CAT):** `/Entities/CAT/TaxRate`  
**الصفحة (ORG):** `/Entities/ORG/TaxRate`

:::note[ملكية الواجهة والـ API]
واجهة CAT ومسار القائمة الجانبية للكتالوج يفتحان `/Entities/CAT/TaxRate`. توجد أيضًا واجهة تحت المؤسسة على `/Entities/ORG/TaxRate`، وواجهة البرمجة الخلفية تتبع متحكم ORG.
:::

## ماذا تفعل هذه الشاشة

- تدير معدلات الضريبة بالاسمين والنسبة وتسمية الفاتورة
- تتيح تعيين **isDefault** للمعدل الافتراضي
- تُربط بالمنتج للضريبة على البيع/الشراء حسب الاستخدام

## الحقول

| الحقل | الإلزام | الاستخدام |
|---|---|---|
| **name** / **nameAr** | إلزامي في واجهة CAT | الاسم بالإنجليزية والعربية |
| **taxValue_prc** | اختياري في التحقق (≥ 0) | نسبة الضريبة % |
| **labelOnInvoice** | اختياري | التسمية على الفاتورة |
| **isDefault** | اختياري | هل المعدل الافتراضي |
| **description** / **descriptionAr** | اختياري | الأوصاف |

### أعمدة قائمة CAT

name / nameAr / الأوصاف / Active? / actions — دون عمود taxValue في قائمة CAT الحالية.

### أعمدة قائمة ORG

تضيف عمود **taxValue_prc** إلى جانب الاسمين والأوصاف والنشاط.

## كيف تستخدم الشاشة

1. افتح `/Entities/CAT/TaxRate` من قائمة الكتالوج (أو مسار ORG عند العمل من المؤسسة)
2. أنشئ أو عدّل معدلًا بالاسمين و**taxValue_prc** و**labelOnInvoice** و**isDefault**
3. اختر المعدل لاحقًا من حقل الضريبة في [المنتج](/docs/cat/product)

## أفضل الممارسات

:::tip[وحّد تسمية الفاتورة]
اجعل **labelOnInvoice** مطابقًا لما يظهر للعميل حتى لا تختلف النصوص بين الفرق.
:::

:::note[المعدل الافتراضي]
**isDefault** يميّز المعدل المستخدم افتراضيًا ضمن القائمة.
:::

:::warning[مساران للواجهة]
عدّل من مسار واحد معتمد في مؤسستك (CAT أو ORG) لتجنب ازدواجية الفهم التشغيلي، مع العلم أن الـ API خلفيًا تحت ORG.
:::
