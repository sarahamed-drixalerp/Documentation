# إجراءات DMS

**إجراء DMS (DMSAction)** قيمة lookup ثنائية اللغة لاسم الإجراء المستخدم في مسارات مراجعة أنواع الوثائق. الشاشة قائمة + درج فقط — بلا صفحة سجل `{رقم}` مستقلة في الواجهة الأمامية.

**المسار:** يُفتح ككيان `/Entities/DMS/DMSAction` (قد لا يظهر في القائمة الجانبية الرئيسية لـ DMS)  
**الصفحة:** `/Entities/DMS/DMSAction` (قائمة ودرج إنشاء/تعديل)

## ماذا تفعل هذه الشاشة

- تخزّن اسم الإجراء بالعربية والإنجليزية
- تدعم الوصف والرمز وتفعيل السجل
- تغذي خيارات الإجراءات في مصمم مراحل نوع الوثيقة

## القائمة

### الأعمدة

| العمود | المعنى |
|---|---|
| **English Name** | الاسم بالإنجليزية |
| **Arabic Name** | الاسم بالعربية |
| **English / Arabic Description** | الأوصاف |
| **Active?** | مفتاح التفعيل |
| **Actions** | إجراءات الصف |

### التصفية

| التصفية | الاستخدام |
|---|---|
| **Name** | بحث بالاسم |

## حقول الدرج

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | الاسم بالإنجليزية |
| **nameAr** | نعم | الاسم بالعربية |
| description / descriptionAr | لا | أوصاف |
| code | لا | رمز الإجراء |

الإنشاء والتعديل عبر الدرج من القائمة فقط.

## كيف تستخدم الشاشة

1. افتح قائمة DMSAction
2. أنشئ إجراءً بالاسم و`nameAr`
3. أضف وصفًا ورمزًا عند الحاجة وفعّل السجل
4. استخدم الإجراءات عند تصميم مراحل [نوع الوثيقة](/docs/dms/document-type)

## أفضل الممارسات

:::tip[وحّد الأسماء ثنائية اللغة]
الاسم و`nameAr` يظهران في مسارات المراجعة؛ حافظ على صياغة متسقة بين Code-A… والإجراءات المخصصة.
:::

:::note[ليست شاشة تشغيل يومية]
ضبط الإجراءات عمل إعداد. التشغيل اليومي يتم من الوثائق وسير العمل.
:::
