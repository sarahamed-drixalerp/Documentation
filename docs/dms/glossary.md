# المصطلحات

تعريفات مختصرة كما تظهر في إدارة وثائق Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| إدارة الوثائق (DMS) | وحدة ضبط وثائق المشاريع: أنواع، مرفقات، سير عمل، لوحة، بوابة مقاول |
| لوحة DMS (Dashboard) | مؤشرات ورسوم وامتثال أسبوعي ومهام SLA متأخرة بلا CRUD |
| وثيقة (Document) | سجل الضبط: بيانات، مرفقات، مراجعة أو رفع فقط |
| نوع الوثيقة (DocumentType) | قواعد البادئات والملفات والسلوك ومراحل سير العمل |
| سلوك الوثيقة (documentBehaviour) | 0 رفع فقط · 1 متعدد التخصصات · 2 تخصص واحد |
| رفع فقط (Upload Only) | بلا سير عمل وبلا إرسال للمراجعة |
| مشروع DMS (DMSProject) | حاوية المشروع مع رمز مشروع وفريق أدوار وتخصصات |
| مالك مشروع DMS (DMSProjectOwner) | جهة المالك المرجعية للمشاريع |
| تخصص المشروع (DMSProjectDiscipline) | ربط DisciplineId + DisciplineUsrId على المشروع |
| تخصص (Discipline) | مجال فني/تشغيلي مع DisciplineUsr وisTechnical |
| موظف تخصص (DisciplineEmployee) | ربط تخصص بمستخدم؛ تبويب أو مسار مستقل |
| مقاول (Contractor) | جهة خارجية مع مدير حساب ومشاريع معيَّنة |
| مستخدم خارجي (ExternalUser) | حساب بوابة: View Only / Add New Document / Admin |
| إجراء DMS (DMSAction) | lookup ثنائي اللغة لإجراءات مراحل المراجعة |
| مسودة / إرسال (Draft / Submit) | حالة ابتدائية ثم إرسال يتطلب مرفقًا ≥ 1 |
| معتمد / مرفوض (Approved / Rejected) | نهاية المسار؛ إعادة فتح كمسودة للمقاول عند الرفض |
| إرسال للمرحلة التالية (Submit & Next) | تقدّم مرحلة مع تعليق إلزامي |
| إرسال خطاب للمالك (Send Letter to Owner) | خيار في حوار سير العمل |
| مرحَّل (Migrated) | وثيقة بمفتاح قديم `oldKey` |
| وثيقة مرتبطة (LinkedDocument) | نسخ/قفل النوع والمقاول والمشروع من وثيقة سابقة |
| مرفق داعم (DocumentSupporting) | مرفقات داعمة بجانب المرفق الرئيسي |
| سرية البيانات (DataConfidentiality) | تصنيف سرية على نموذج الوثيقة عند تفعيله |
| اتفاقية مستوى الخدمة (SLA) | حدود زمنية للمراحل؛ المتأخر يظهر في لوحة Overdue |
