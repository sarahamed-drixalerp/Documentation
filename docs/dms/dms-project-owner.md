# مالكو مشاريع DMS

**مالك مشروع DMS (DMSProjectOwner)** جهة المالك المرجعية التي تُربط بمشاريع DMS: الاسم، النوع/الحالة، وبيانات الاتصال والعنوان.

**المسار:** القائمة الجانبية ← إدارة الوثائق ← مالكو مشاريع DMS  
**الصفحات:** `/Entities/DMS/DMSProjectOwner` · `/Entities/DMS/DMSProjectOwner/new` · `/Entities/DMS/DMSProjectOwner/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرّف جهة المالك قبل أو مع مشاريع DMS
- تخزّن بيانات التسجيل والاتصال والعنوان
- تظهر في قائمة المشاريع وفلاترها

## القائمة

### الأعمدة

| العمود | المعنى |
|---|---|
| **Name** | الاسم |
| **RegistrationNo** | رقم التسجيل |
| **Email** | البريد |
| **Phone** | الهاتف |
| **Actions** | إجراءات الصف |

### التصفية

| التصفية | الاستخدام |
|---|---|
| **Name** | بحث بالاسم |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | الاسم |
| **nameAr** | نعم | الاسم بالعربية |
| **EntityTypeId** | نعم (في SaveDetails) | نوع الكيان |
| **EntityStatusId** | نعم (في SaveDetails) | حالة الكيان |
| description / descriptionAr | لا | أوصاف |
| domain / website | لا | النطاق / الموقع |
| registrationNo | لا | رقم التسجيل |
| vATRegNo | لا | الرقم الضريبي |
| mobile / email | لا | جوال / بريد |
| **العنوان** | لا | CountryId، city، state، address، street، zipCode |

النوع والحالة قيم lookup عبر EntityType / EntityStatus وليست تعدادًا ثابتًا في الواجهة.

## كيف تستخدم الشاشة

1. أنشئ المالك بالاسم و`nameAr`
2. عيّن EntityType وEntityStatus
3. أضف الاتصال والعنوان عند الحاجة
4. اربط المالك من شاشة [مشروع DMS](/docs/dms/dms-project)

## أفضل الممارسات

:::tip[أنشئ المالك قبل تكديس المشاريع]
المالك يظهر في قوائم وفلاتر المشاريع؛ إعداد المالك أولًا يسهّل الربط لاحقًا.
:::
