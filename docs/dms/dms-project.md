# مشاريع DMS

**مشروع DMS (DMSProject)** هو حاوية ضبط الوثائق لمشروع تشغيلي: الاسم، رمز المشروع، العقد، المالك، المقاول، وفريق الأدوار (مدير مشروع، مدير منطقة، ضابط وثائق، مساح كميات)، مع تخصصات المشروع.

**المسار:** القائمة الجانبية ← إدارة الوثائق ← مشاريع DMS  
**الصفحات:** `/Entities/DMS/DMSProject` · `/Entities/DMS/DMSProject/new` · `/Entities/DMS/DMSProject/{رقم}`  
استعلام التبويب: `?tab=disciplines`

## ماذا تفعل هذه الشاشة

- تعرّف مشروع الوثائق المستخدم في قوائم الوثائق واللوحة
- تربط المالك والمقاول وفريق أدوار DMS
- تربط تخصصات المشروع بمستخدمين عبر `DMSProjectDiscipline`
- تغذي فلاتر الوثائق واللوحة

## قائمة المشاريع

### الأعمدة

| العمود | المعنى |
|---|---|
| **Name** | اسم المشروع |
| **ContractNo** | رقم العقد |
| **ProjectCode** | رمز المشروع |
| **DMSProjectOwnerId** | المالك |
| **ContractorId** | المقاول |
| **Actions** | إجراءات الصف |

### التصفية

| التصفية | الاستخدام |
|---|---|
| **Name** | بحث بالاسم |
| **DMSProjectOwnerId** | المالك |
| **ContractorId** | المقاول |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | الاسم |
| **nameAr** | نعم | الاسم بالعربية |
| **projectCode** | نعم | رمز المشروع |
| contractNo | لا | رقم العقد |
| startDate / endDate | لا | تواريخ المشروع |
| description / descriptionAr | لا | أوصاف |
| **ContractorId** | لا | المقاول |
| **DMSProjectOwnerId** | لا | مالك مشروع DMS |
| ProjectManagerUsrId | لا | مدير المشروع |
| AreaManagerUsrId | لا | مدير المنطقة |
| DocumentControllerUsrId | لا | ضابط الوثائق |
| QuantitySurveyorUsrId | لا | مساح الكميات |
| **EntityTypeId / EntityStatusId** | نعم (في SaveDetails) | نوع وحالة الكيان |

## التبويبات

| التبويب | الغرض |
|---|---|
| **General** | الهوية، العقد، المالك، المقاول، أدوار الفريق |
| **Disciplines** | تخصصات المشروع (`DMSProjectDiscipline`) |

:::note[تبويب التخصصات بعد الحفظ]
تبويب Disciplines يُعطَّل حتى يُحفظ سجل المشروع.
:::

### تخصص المشروع (DMSProjectDiscipline)

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **DisciplineId** | نعم | التخصص |
| **DisciplineUsrId** | نعم | المستخدم المرتبط بالتخصص على المشروع |
| IsActive | — | نشط / غير نشط |

## كيف تستخدم الشاشة

1. أنشئ [مالك مشروع DMS](/docs/dms/dms-project-owner) والمقاول عند الحاجة
2. أنشئ مشروع DMS بالاسم و`nameAr` و`projectCode`
3. عيّن المالك والمقاول وأدوار الفريق
4. احفظ ثم افتح تبويب Disciplines لربط التخصصات والمستخدمين
5. استخدم المشروع عند إنشاء الوثائق وفي فلاتر اللوحة

## أفضل الممارسات

:::tip[ثبّت رمز المشروع مبكرًا]
`projectCode` إلزامي ويظهر في القوائم؛ وحّد أسلوب الترميز قبل تكديس الوثائق.
:::

:::warning[أدوار الفريق تغذي المسار]
مدير المشروع ومدير المنطقة وضابط الوثائق ومساح الكميات يُستخدمون في سياق المراجعة والمشروع — عيّنهم قبل إرسال وثائق ذات سير عمل.
:::
