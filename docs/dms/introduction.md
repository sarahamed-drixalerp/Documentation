# مقدمة إدارة الوثائق

وحدة **إدارة الوثائق (Document Management / DMS)** في Drixal ERP تضبط وثائق المشاريع: المالك، المشروع، التخصص، نوع الوثيقة، المرفقات، وسير عمل المراجعة متعدد المراحل — مع وضع **رفع فقط** عند عدم الحاجة للمراجعة.

بدون هذه الوحدة تبقى الملفات متفرقة بين البريد والمجلدات. داخل Drixal تصبح الوثيقة سجلًا متصلًا بمشروع DMS ونوع وثيقة ومقاول ومسار مراجعة بمراجع حالي وتقدّم مراحل.

## ماذا تفعل الوحدة لأعمالك

- توحّد لغة العمل: مالك ← مشروع DMS ← تخصص ← نوع وثيقة ← وثيقة
- تعطي العمليات شاشة واحدة للرفع والمراجعة والاعتماد أو الرفض
- تمكّن الإدارة من متابعة الحالة والامتثال والمهام المتأخرة من اللوحة
- تدعم بوابة المقاول والمستخدم الخارجي بصلاحيات محددة

## ترتيب الإعداد الموصى به

الترتيب ليس معالجًا مدمجًا في النظام؛ يفرضه الاعتماد بين السجلات:

```text
مالك مشروع DMS (DMSProjectOwner)
  └── مشروع DMS (DMSProject)
        ├── تخصصات المشروع (DMSProjectDiscipline)
        └── …
تخصص (Discipline) + موظفون (DisciplineEmployee)
نوع الوثيقة (DocumentType) + مراحل سير العمل
  └── الوثيقة (Document)
مقاول (Contractor) · مستخدم خارجي (ExternalUser)
```

| الخطوة | السجل | الغرض |
|---|---|---|
| 1 | **مالك مشروع DMS** | جهة المالك قبل ربط المشاريع |
| 2 | **مشروع DMS** | المشروع والفريق (مدير مشروع، منطقة، ضابط وثائق، مساح كميات) |
| 3 | **تخصص** | التخصصات الفنية وربط الموظفين |
| 4 | **نوع الوثيقة** | البادئات، الملفات، السلوك (رفع فقط / متعدد / أحادي)، ومراحل سير العمل |
| 5 | **الوثيقة** | السجل اليومي: مرفقات ومراجعة أو رفع فقط |
| — | **مقاول / مستخدم خارجي** | الوصول عبر البوابة وصلاحيات الإنشاء/الإدارة |

يمكن فتح الوثيقة مباشرة من القائمة بعد توفّر النوع والمشروع. المقاول والمالك اختياريان على بعض الشاشات لكنهما مهمان للتقارير والبوابة.

## بوابة المقاول والمستخدم الخارجي

في **Aspire-Contractor** يصل المقاول والمستخدم الخارجي إلى الوثائق حسب **مستوى الصلاحية**:

| المستوى | المعنى |
|---|---|
| **View Only** | قراءة الوثائق والحالات |
| **Add New Document** | عرض وإرسال وثائق جديدة |
| **Admin** | إدارة المستخدمين والمشاريع والوثائق ضمن نطاق المقاول |

إنشاء وثيقة بديلة يمكن أن يمر عبر `?LinkedDocumentId=` مع قفل النوع والمقاول والمشروع من الوثيقة السابقة.

## من يستخدم هذا القسم

| الدور | الاستخدام اليومي |
|---|---|
| ضابط الوثائق / إدارة الوثائق | الأنواع، المشاريع، المتابعة، اللوحة |
| مدير المشروع / مدير المنطقة | مراجعة المراحل وتقدّم سير العمل |
| المقاول / مستخدم خارجي | الرفع والإرسال وإعادة الفتح عند الرفض (حسب الصلاحية) |
| الإدارة | مؤشرات اللوحة والامتثال الأسبوعي والمهام المتأخرة |

## كيف يُنظَّم دليل إدارة الوثائق

1. فهم الترتيب واللوحة
2. تعريف المالك والمشروع والتخصص
3. إعداد نوع الوثيقة وسير العمل
4. إنشاء الوثائق ودورة المسودة ← الإرسال ← الاعتماد/الرفض
5. المقاولون والمستخدمون الخارجيون
6. lookups والإجراءات والمصطلحات

## أفضل الممارسات

:::tip[أعدّ المرجع قبل تكديس الوثائق]
أنشئ المالك والمشروع والتخصص ونوع الوثيقة أولًا، ثم أضف الوثائق. العكس يبطئ الفلاتر وسير العمل.
:::

:::warning[السلوك يحدد المسار]
نوع الوثيقة بسلوك **رفع فقط** لا يُنشئ تبويب سير عمل ولا زر إرسال للمراجعة. راجع السلوك قبل توزيع النوع على الفرق.
:::

:::note[المساعدة من الترويسة]
اضغط **المساعدة** من ترويسة التطبيق وأنت على صفحة DMS لفتح الدليل المطابق.
:::
