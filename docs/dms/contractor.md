# المقاولون

**المقاول (Contractor)** جهة خارجية ترفع وتراجع وثائق المشاريع في DMS. السجل يحمل الاسم، مدير الحساب، بيانات التسجيل والاتصال، والمشاريع المعيَّنة.

**المسار:** القائمة الجانبية ← إدارة الوثائق ← المقاولون  
**الصفحات:** `/Entities/DMS/Contractor` · `/Entities/DMS/Contractor/new` · `/Entities/DMS/Contractor/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرّف المقاول المستخدم على المشاريع والوثائق والمستخدمين الخارجيين
- تعيّن **مدير الحساب (Account Manager)**
- تخزّن التسجيل والاتصال والعنوان والبيانات التجارية
- تعرض **المشاريع المعيَّنة (Assigned Projects)** بعد الحفظ

## القائمة

### الأعمدة

| العمود | المعنى |
|---|---|
| **Name** | الاسم |
| **EntityStatusId** | الحالة |
| **AccountManagerUsr** | مدير الحساب |
| **RegistrationNo** | رقم التسجيل |
| **Email** | البريد |
| **Phone** | الهاتف |
| **Actions** | إجراءات الصف |

### التصفية

| التصفية | الاستخدام |
|---|---|
| **Name** | بحث بالاسم |
| **EntityTypeId** | نوع الكيان |
| **EntityStatusId** | الحالة |
| **AccountManagerUsrId** | مدير الحساب |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | اسم المقاول |
| AccountManagerUsrId | لا | مدير الحساب |
| IndustryId / SectorId / CurrencyId | لا | الصناعة / القطاع / العملة |
| annualRevenue_val / employees_num | لا | إيرادات / عدد موظفين |
| cRNo / vATRegNo / registrationNo | لا | سجل تجاري / ضريبة / تسجيل |
| phone / mobile / email / website / domain | لا | اتصال وحضور رقمي |
| description | لا | وصف |
| **العنوان** | لا | حقول العنوان |

## التبويبات

| التبويب | الغرض |
|---|---|
| **Details** | الهوية، مدير الحساب، التسجيل، الاتصال |
| **Assigned Projects** | المشاريع المرتبطة بالمقاول |

:::note[المشاريع المعيَّنة بعد الحفظ]
تبويب Assigned Projects يُعطَّل حتى يُحفظ سجل المقاول.
:::

## كيف تستخدم الشاشة

1. أنشئ المقاول بالاسم وعيّن Account Manager عند الحاجة
2. أدخل التسجيل والاتصال
3. احفظ ثم راجع Assigned Projects
4. اربط المقاول من مشروع DMS و/أو الوثيقة و/أو المستخدم الخارجي
5. في البوابة يعتمد وصول المستخدمين الخارجيين على المقاول ومستوى الصلاحية

## أفضل الممارسات

:::tip[اربط مدير الحساب قبل التشغيل]
مدير الحساب يظهر في القائمة والفلاتر ويسهّل المتابعة الداخلية للمقاول.
:::

:::warning[البوابة تعتمد على المقاول]
المستخدمون الخارجيون يُربطون بمقاول؛ بدون مقاول صحيح تتعطل إدارة الصلاحيات والمشاريع المعيَّنة في البوابة.
:::
