# أنواع الوثائق

**نوع الوثيقة (DocumentType)** يعرّف قواعد الوثيقة في DMS: الاسم، البادئات، أنواع الملفات المسموحة، حدود الحجم والعدد، الإصدارات، وسلوك المسار — رفع فقط أو سير عمل بتخصص واحد أو متعدد.

**المسار:** القائمة الجانبية ← إدارة الوثائق ← أنواع الوثائق  
**الصفحات:** `/Entities/DMS/DocumentType` · `/Entities/DMS/DocumentType/new` · `/Entities/DMS/DocumentType/{رقم}`  
استعلام التبويب: `?tab=workflow` أو `?tab=disciplines` لفتح مصمم المراحل

## ماذا تفعل هذه الشاشة

- تضبط البادئات وأنواع الملفات والحدود لكل صنف وثيقة
- تختار **سلوك الوثيقة (documentBehaviour)** الذي يحدد وجود سير العمل
- تصمّم مراحل التخصصات والإجراءات وSLA (ما لم يكن رفع فقط)
- تغذّي قائمة الوثائق وقواعد الإرسال والمرفقات

## قائمة أنواع الوثائق

### الأعمدة

| العمود | المعنى |
|---|---|
| **Name** | اسم النوع |
| **Code** | الرمز |
| **Document Prefixes** | البادئات |
| **Max Allowed Attachments** | الحد الأقصى للمرفقات |
| **Allowed File Types** | الامتدادات المسموحة |
| **Upload Only** | نعم / لا |
| **Actions** | إجراءات الصف |

### التصفية

| التصفية | الاستخدام |
|---|---|
| **Name** | بحث بالاسم |

## الحقول

| الحقل | إلزامي؟ | الاستخدام |
|---|---|---|
| **name** | نعم | الاسم المعروض |
| nameAr | لا | الاسم بالعربية |
| code | لا | رمز اختياري |
| **prefixes (Document Prefixes)** | نعم | بادئات الرمز عند إنشاء الوثيقة |
| **fileTypes (Allowed File Types)** | نعم | الامتدادات المسموحة |
| **documentBehaviour** | نعم | سلوك المسار (انظر الجدول أدناه) |
| maxFilesCount (`Max Allowed Attachments`) | لا | أقصى عدد مرفقات |
| maxSize (`Max File Size (MB)`) | لا | أقصى حجم بالميغابايت |
| isAllowVersioning (`Allow Versioning`) | لا | السماح بالإصدارات |
| description | لا | وصف |
| **EntityTypeId / EntityStatusId** | نعم (في SaveDetails) | نوع وحالة الكيان |

### سلوك الوثيقة (documentBehaviour)

| القيمة | التسمية في الواجهة | المعنى |
|---|---|---|
| **0** | Upload Only (No Workflow) | رفع فقط — بلا سير عمل |
| **1** | Multi-Discipline (Submit Only) | متعدد التخصصات — إرسال للمراجعة |
| **2** | Single Discipline (Take Action) | تخصص واحد — اتخاذ إجراء (الافتراضي عند الإنشاء) |

## التبويبات

| التبويب | الغرض |
|---|---|
| **Details** | الهوية، البادئات، الملفات، الحدود، السلوك |
| **Workflow / Disciplines** | مصمم مراحل `DocumentTypeDiscipline` (تسلسل، SLA، إجراءات) |

:::warning[تبويب سير العمل مخفي للرفع فقط]
إذا كان السلوك **Upload Only (0)** لا يظهر تبويب Workflow/Disciplines ولا تُبنى مراحل مراجعة لهذا النوع.
:::

على المصمم تُقفل تسلسلات النظام: `0`, `10`, `20`, `70`, `90`, `99`. عند إنشاء نوع غير رفع فقط يُزرع مسار أولي بخطوات مثل المقاول وضابط الوثائق ومدير المنطقة ومدير المشروع مع إجراءات مثل In-Progress / Submitted وCode-A…Code-D حسب التهيئة الخلفية.

## كيف تستخدم الشاشة

1. أنشئ نوع الوثيقة بالاسم والبادئات وأنواع الملفات
2. اختر **documentBehaviour** المناسب للعملية
3. اضبط الحد الأقصى للحجم/العدد والإصدارات إن لزم
4. احفظ، ثم افتح تبويب Workflow (إن لم يكن رفع فقط) لضبط التخصصات والمراحل
5. استخدم النوع عند إنشاء الوثائق

## أفضل الممارسات

:::tip[ثبّت السلوك قبل توزيع النوع]
غيّر السلوك مبكرًا. الوثائق القائمة تتبع قواعد النوع؛ الرفع فقط لا يمر بالمراجعة.
:::

:::note[البادئة تظهر عند إنشاء الوثيقة]
بادئات النوع تغذي حقل Prefix الاختياري على شاشة الوثيقة مع الرمز/الاسم.
:::

:::warning[التخصصات على النوع ≠ تخصصات المشروع]
مصمم المراحل على النوع يحدد مسار المراجعة. ربط تخصصات المشروع يتم من [مشروع DMS](/docs/dms/dms-project).
:::
