# المواقع

**الموقع (Location)** في GPS نقطة جغرافية باسم وتسمية وإحداثيات ونصف قطر (geofence). يُستخدم لاحقًا في التوقفات المخططة ومقارنة الحضور داخل/خارج المنطقة.

**المسار:** القائمة الجانبية ← GPS ← المواقع  
**الصفحات:** `/Entities/GPS/Location` · `/Entities/GPS/Location/{رقم}` · `/Entities/GPS/Location/360/{رقم}`

:::note[ليس موقع المؤسسة]
هذا الكيان مختلف عن [موقع المؤسسة (ORG Location)](/docs/org/location) الذي يبني تسلسلًا هرميًا بلا إحداثيات.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة مواقع GPS بالاسم والتسمية والمالك والإحداثيات ونصف القطر والحالة
- تتيح الإنشاء والتعديل والحذف من القائمة أو الدرج
- تتيح اختيار الإحداثيات من **MapPicker** (خريطة Google Maps بدبوس ودائرة نصف القطر) أو **Use Current Location**
- تفتح العرض القياسي أو عرض 360 للسجل

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| **name** | الاسم |
| **label** | التسمية |
| **ownerUsrName** | اسم المالك |
| **latitude** | خط العرض |
| **longitude** | خط الطول |
| **radius** | نصف القطر |
| **entityStatusName** | اسم الحالة |
| **actions** | تعديل / عرض 360 / حذف |

اضغط الاسم لفتح `/Entities/GPS/Location/{رقم}`.

## التصفية والبحث

| الفلتر | الاستخدام |
|---|---|
| **search** (Name / Label) | بحث نصي في الاسم والتسمية |
| **OwnerUsrId** | المالك |
| **EntityStatusId** | الحالة |
| **EntityTypeId** | النوع |

## الإجراءات من القائمة

1. **إنشاء موقع جديد** — زر الإنشاء يفتح درج الإنشاء
2. **تعديل** — أيقونة القلم تفتح الدرج
3. **عرض 360** — يفتح `/Entities/GPS/Location/360/{رقم}`
4. **حذف** — يتطلب تأكيدًا ولا يمكن التراجع عنه
5. فتح السجل بالاسم — `/Entities/GPS/Location/{رقم}`

:::danger[احذف فقط السجلات غير المستخدمة]
لا تحذف موقعًا مرتبطًا بتوقفات مخططة أو تعتمد عليه مقارنة الحضور. صحّح الإحداثيات أو الحالة بدل الحذف عند الحاجة.
:::

## الحقول الإلزامية

| الحقل | القيود / الاستخدام |
|---|---|
| **name** | الاسم |
| **label** | التسمية |
| **radius** | ≥ **0.01** — الواجهة بوحدة **km**؛ القيمة **≥ 50** تُعامل كأمتار عند التحويل/الحفظ |
| **latitude** | من **−90** إلى **90** |
| **longitude** | من **−180** إلى **180** |
| **entityTypeId** | نوع الكيان |
| **entityStatusId** | حالة الكيان |

## حقول اختيارية

| الحقل | الاستخدام |
|---|---|
| **nameAr** | الاسم بالعربية |
| **ownerUsrId** | المالك |
| **dataConfidentialityId** | مستوى سرية البيانات |
| **description** / **descriptionAr** | الأوصاف |

## اختيار الموقع من الخريطة (MapPicker)

من حقول خط العرض أو خط الطول افتح منتقي الخريطة:

1. تُعرض خريطة **Google Maps** مع **دبوس** و**دائرة نصف القطر**
2. انقر على الخريطة أو اسحب الدبوس لتحديد الإحداثيات
3. استخدم **Use Current Location** لأخذ موقع المتصفح الحالي (يتطلب إذن الموقع)
4. أكّد الاختيار لتحديث **latitude** و**longitude** في النموذج

:::tip[اضبط نصف القطر قبل التأكيد على الخريطة]
الدائرة المعروضة تعتمد على **radius**. راجع القيمة بوحدة km في النموذج حتى تطابق منطقة العمل الفعلية.
:::

:::warning[وحدة نصف القطر]
الواجهة تعرض وتتحقق من **radius** بوحدة **km** وبحد أدنى **0.01**. عند الحفظ، القيم **≥ 50** تُعامل كأمتار. لا تخلط بين إدخال الكيلومترات والأمتار دون مراجعة هذه القاعدة.
:::

## صفحة السجل والعرض 360

### العرض القياسي — `/Entities/GPS/Location/{رقم}`

- **Active** — مفتاح النشاط
- منتقي **النوع** و**الحالة**
- تبديل **العرض القياسي ↔ 360**
- نموذج التفاصيل (SaveDetails) للحفظ

### عرض 360 — `/Entities/GPS/Location/360/{رقم}`

ملخص الشريط الجانبي يشمل:

- **latitude** / **longitude** / **radius**
- **owner** (ownerUsrName)

ومن التبويبات المتاحة:

- **Activities** (الأنشطة)
- **Attachments** (المرفقات)
- **Logs** (السجلات)
- التفاصيل للتعديل

## كيف تستخدم الشاشة

1. افتح `/Entities/GPS/Location`
2. أنشئ موقعًا أو افتح سجلًا للتعديل
3. عبّئ **name** و**label** و**radius** (≥ 0.01 km)
4. عيّن **latitude** و**longitude** يدويًا أو عبر MapPicker / Use Current Location
5. اختر **entityTypeId** و**entityStatusId**
6. أضف الحقول الاختيارية عند الحاجة ثم احفظ
7. راجع الملخص والأنشطة/المرفقات/السجلات من عرض 360 عند التشغيل اليومي

## أفضل الممارسات

:::tip[ثبّت الإحداثيات ونصف القطر قبل الجدولة]
لا تربط توقفات مخططة بموقع بلا إحداثيات صحيحة. التتبع يعتمد على موقع الموقع ونصف قطره لمقارنة داخل/خارج.
:::

:::note[المالك اختياري]
**ownerUsrId** اختياري؛ استخدمه عندما تريد مسؤولية واضحة عن سجل الموقع.
:::
