# المصطلحات

تعريفات مختصرة كما تظهر في وحدة التتبع الجغرافي (GPS) في Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| التتبع الجغرافي (GPS) | وحدة المواقع الجغرافية والتوقفات المخططة وخريطة تتبع أيام الحضور الميداني |
| موقع GPS (Location) | نقطة بإحداثيات ونصف قطر (geofence) على `/Entities/GPS/Location` |
| موقع المؤسسة (ORG Location) | سجل تسلسل هرمي بلا إحداثيات؛ موثَّق في [مواقع المؤسسة](/docs/org/location) وليس كيان GPS |
| منطقة جغرافية / سياج جغرافي (Geofence) | دائرة حول إحداثيات الموقع يحددها **radius** للتحقق داخل/خارج المنطقة |
| نصف القطر (Radius) | في واجهة الموقع بوحدة **km** (≥ 0.01)؛ القيم **≥ 50** تُعامل كأمتار عند التحويل/الحفظ |
| توقف مخطط (PlannedStop) | زيارة مخططة لموقع في **planDate** لموظف مُسند؛ الإحداثيات ونصف القطر من الموقع |
| مخطط مقابل فعلي (Planned vs actual) | مقارنة توقفات اليوم المخططة بنقاط الحضور/الانصراف المسجّلة على الخريطة |
| غير مخطط (Unplanned) | نقطة حضور ظاهرة على خريطة التتبع دون ربط بتوقف مخطط |
| داخل نصف القطر (Inside radius) | نقطة فعلية تقع ضمن دائرة نصف قطر الموقع/التوقف المخطط |
| خارج نصف القطر (Outside radius) | نقطة فعلية تقع خارج دائرة نصف القطر |
| خطوط المسافة (Distance lines) | خطوط على خريطة اليوم تربط الفعلي بالمخطط وتُعلَّم داخل/خارج |
| التتبع (Tracking) | شاشة قراءة لأيام العمل وخريطة FieldMap على `/Entities/GPS/Tracking` — بلا CRUD |
| العرض القياسي / السجل | صفحة التفاصيل والإنشاء والتعديل للموقع أو التوقف المخطط |
| عرض 360 | مساحة عمل السجل مع ملخص وأنشطة ومرفقات وسجلات |
