# التوقفات المخططة

**التوقف المخطط (PlannedStop)** زيارة ميدانية مخططة: اسم وتسمية، **موقع GPS**، تاريخ خطة، وموظف مُسند. الإحداثيات ونصف القطر تُقرأ من الموقع المرتبط وليست حقول إدخال قابلة للتعديل في النموذج.

**المسار:** القائمة الجانبية ← GPS ← التوقفات المخططة  
**الصفحات:** `/Entities/GPS/PlannedStop` · `/Entities/GPS/PlannedStop/{رقم}` · `/Entities/GPS/PlannedStop/360/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرض قائمة التوقفات بالاسم والتسمية والموقع وتاريخ الخطة والمُسند والإحداثيات
- تتيح الإنشاء والتعديل والحذف من القائمة أو الدرج
- عند اختيار **Location** يمكن تعبئة **Label** تلقائيًا إن كان فارغًا
- تفتح العرض القياسي أو عرض 360 للسجل

## أعمدة القائمة

| العمود | المعنى |
|---|---|
| **name** | الاسم |
| **label** | التسمية |
| **locationName** | اسم الموقع المرتبط |
| **planDate** | تاريخ الخطة |
| **assignedToUsrName** | اسم الموظف المُسند |
| **latitude** | خط العرض (من الموقع) |
| **longitude** | خط الطول (من الموقع) |
| **actions** | تعديل / عرض 360 / حذف |

اضغط الاسم لفتح `/Entities/GPS/PlannedStop/{رقم}`.

## التصفية والبحث

| الفلتر | الاستخدام |
|---|---|
| **search** (Name / Label) | بحث نصي في الاسم والتسمية |
| **LocationId** | الموقع |
| **AssignedToUsrId** | الموظف المُسند |
| **EntityStatusId** | الحالة |
| **EntityTypeId** | النوع |

## الإجراءات من القائمة

1. **إنشاء توقف مخطط جديد** — زر الإنشاء يفتح درج الإنشاء
2. **تعديل** — أيقونة القلم تفتح الدرج
3. **عرض 360** — يفتح `/Entities/GPS/PlannedStop/360/{رقم}`
4. **حذف** — يتطلب تأكيدًا ولا يمكن التراجع عنه
5. فتح السجل بالاسم — `/Entities/GPS/PlannedStop/{رقم}`

:::danger[احذف المسودات الخاطئة فقط]
لا تحذف توقفًا تعتمد عليه مراجعة التتبع لليوم. صحّح التاريخ أو الموقع أو الإسناد بدل الحذف عند الحاجة.
:::

## الحقول الإلزامية

| الحقل | القيود / الاستخدام |
|---|---|
| **name** | الاسم |
| **label** | التسمية |
| **planDate** | تاريخ الخطة — **تاريخ فقط** (بدون وقت) |
| **locationId** | موقع GPS المرتبط |
| **assignedToUsrId** | الموظف المُسند |
| **entityTypeId** | نوع الكيان |
| **entityStatusId** | حالة الكيان |

## حقول اختيارية

| الحقل | الاستخدام |
|---|---|
| **nameAr** | الاسم بالعربية |
| **description** / **descriptionAr** | الأوصاف |

## الإحداثيات ونصف القطر (للقراءة فقط)

| الحقل | المصدر |
|---|---|
| **latitude** | من **Location** المرتبط — للقراءة فقط |
| **longitude** | من **Location** المرتبط — للقراءة فقط |
| **radius** | من **Location** المرتبط — للقراءة فقط |

تظهر هذه القيم في القائمة وفي ملخص عرض 360. لتغييرها عدّل [الموقع](/docs/gps/location) نفسه.

:::tip[اختيار الموقع يملأ التسمية]
عند اختيار **Location**، إن كان حقل **Label** فارغًا يُملأ تلقائيًا باسم الموقع المختار. يمكنك تعديله بعد ذلك.
:::

:::note[planDate تاريخ فقط]
**planDate** يُحفظ كتاريخ يومي دون وقت. استخدم يوم الزيارة المخطط وليس ختمًا زمنيًا.
:::

## صفحة السجل والعرض 360

### العرض القياسي — `/Entities/GPS/PlannedStop/{رقم}`

- **Active** — مفتاح النشاط
- منتقي **النوع** و**الحالة**
- تبديل **العرض القياسي ↔ 360**
- نموذج التفاصيل (SaveDetails) للحفظ

### عرض 360 — `/Entities/GPS/PlannedStop/360/{رقم}`

ملخص الشريط الجانبي يشمل:

- **locationName**
- **planDate**
- **latitude** / **longitude** / **radius** (من الموقع)

ومن التبويبات المتاحة:

- **Activities** (الأنشطة)
- **Attachments** (المرفقات)
- **Logs** (السجلات)
- التفاصيل للتعديل

## كيف تستخدم الشاشة

1. افتح `/Entities/GPS/PlannedStop`
2. تأكد من وجود [موقع GPS](/docs/gps/location) صالح أولًا
3. أنشئ توقفًا أو افتح سجلًا للتعديل
4. عبّئ **name** و**label** و**planDate**
5. اختر **locationId** و**assignedToUsrId** و**entityTypeId** و**entityStatusId**
6. راجع أن الإحداثيات ونصف القطر ظهرت من الموقع (للقراءة فقط)
7. احفظ، ثم تابع التنفيذ من [التتبع](/docs/gps/tracking) في يوم الخطة

## أفضل الممارسات

:::tip[اربط الموقع والموظف قبل تاريخ الخطة]
بدون **locationId** و**assignedToUsrId** و**planDate** صحيحة لن يظهر التوقف بوضوح في خريطة يوم العمل.
:::

:::warning[لا تعدّل الإحداثيات من هنا]
إن كانت الإحداثيات أو نصف القطر خاطئة، صحّحها في سجل [الموقع](/docs/gps/location). التوقف المخطط لا يحرّر هذه الحقول.
:::
