# التتبع

**التتبع (Tracking)** شاشة قراءة لأيام الحضور الميداني على الخريطة: التوقفات المخططة مقابل نقاط الحضور الفعلية، مع عدّ داخل/خارج نصف القطر وخطوط المسافة.

**المسار:** القائمة الجانبية ← GPS ← التتبع  
**الصفحات:** `/Entities/GPS/Tracking` · `/Entities/GPS/Tracking/{userId}/{date}`

يمكن الوصول أيضًا عبر إعادة توجيه مسارات حضور التطبيق:

- `/app/Attendance/Tracking` → `/Entities/GPS/Tracking`
- `/app/Attendance/Tracking/{userId}/{date}` → `/Entities/GPS/Tracking/{userId}/{date}`

:::note[للقراءة فقط — بلا CRUD]
التتبع **لا ينشئ ولا يعدّل ولا يحذف** مواقع أو توقفات أو سجلات حضور. استخدم [المواقع](/docs/gps/location) و[التوقفات المخططة](/docs/gps/planned-stop) و[الحضور](/docs/app/attendance) للتغيير.
:::

## ماذا تفعل هذه الشاشة

- تعرض قائمة **أيام العمل** مع التاريخ والموظف والسيناريو وزر **Open Map**
- تصفّي بالبحث وبيوم محدد
- تفتح خريطة اليوم (**FieldMap**) للمخطط مقابل الفعلي
- تربط العودة السريعة بتطبيق الحضور `/app/Attendance`

## قائمة الأيام

| العمود | المعنى |
|---|---|
| **date** | تاريخ يوم العمل |
| **employee** (userName) | الموظف |
| **scenario** | ملخص السيناريو لليوم |
| **Open Map** | فتح خريطة اليوم |

### التصفية

| الفلتر | الاستخدام |
|---|---|
| **search** | بحث في اسم الموظف / الدور / السيناريو / التاريخ |
| **day** (date) | تصفية بيوم من الأيام المتاحة |

### الإجراءات

1. **Refresh** — إعادة تحميل قائمة الأيام
2. **Open Map** — الانتقال إلى `/Entities/GPS/Tracking/{userId}/{date}`
3. رابط **Attendance** — `/app/Attendance`

## تفاصيل يوم العمل — FieldMap

على `/Entities/GPS/Tracking/{userId}/{date}` تعرض الخريطة واللوحات الجانبية:

| العنصر | المعنى |
|---|---|
| **التوقفات المخططة (أزرق + نصف قطر)** | مواقع مخططة مع دائرة نصف القطر |
| **Check-in / Check-out** | نقاط الحضور والانصراف الفعلية |
| **Unplanned** | نقاط غير مخططة |
| **Inside / Outside radius** | عدّاد داخل/خارج نصف القطر |
| **Distance lines** | خطوط المسافة بين الفعلي والمخطط (داخل/خارج) |

مؤشرات أعلى الصفحة تشمل عادةً: عدد التوقفات المخططة، عدد النقاط الفعلية، داخل نصف القطر، خارج نصف القطر.

:::tip[انقر البطاقة للتكبير على الخريطة]
النقر على توقف مخطط أو نقطة حضور ذات إحداثيات يُركّز الخريطة على ذلك الموضع.
:::

:::warning[نقاط بلا إحداثيات]
قد تظهر سجلات حضور بلا GPS. لا يمكن تكبيرها على الخريطة كإحداثيات فعلية.
:::

## كيف تستخدم الشاشة

1. افتح `/Entities/GPS/Tracking` (أو عبر إعادة توجيه حضور التطبيق)
2. صفِّ بالبحث أو باليوم عند الحاجة
3. اضغط **Refresh** إن لزم تحديث البيانات
4. اضغط **Open Map** ليوم وموظف
5. راجع المخطط (أزرق + نصف قطر) مقابل الحضور وخطوط المسافة
6. للعودة للحضور التشغيلي استخدم `/app/Attendance` — انظر [الحضور والانصراف](/docs/app/attendance)

## أفضل الممارسات

:::tip[جهّز المواقع والتوقفات قبل مراجعة الخريطة]
بدون [مواقع](/docs/gps/location) و[توقفات مخططة](/docs/gps/planned-stop) لن يظهر مخطط أزرق ذو معنى لمقارنة داخل/خارج.
:::

:::note[مصدر البيانات هو الحضور]
التتبع يعرض ما سُجّل من الحضور الميداني. تصحيح وقت أو غياب يتم من مسار الحضور وليس من شاشة التتبع.
:::
