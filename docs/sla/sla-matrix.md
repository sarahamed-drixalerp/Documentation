# مصفوفة SLA

**مصفوفة SLA (SLA Matrix)** تعرّف زمن الاستجابة وزمن الحل لكل أولوية خدمة (أيام / ساعات / دقائق).

![مصفوفة SLA](/img/sla/sla-matrix.svg)

## ماذا تفعل المصفوفة لأعمالك

- تربط كل أولوية بأهداف استجابة وحل
- تتيح تهيئة قيم افتراضية لأولويات شائعة ثم الحفظ
- تضيف أولويات جديدة عبر درج أولوية الخدمة
- تمنع الحفظ عند أوقات غير صالحة أو حل أقصر من الاستجابة

**المسار:** القائمة الجانبية ← دليل الخدمات ← مصفوفة SLA  
**الصفحة:** `/Entities/SLA/SLAMatrix`

## مساحة العمل

| العنصر | السلوك |
|---|---|
| **العنوان** | مصفوفة SLA + عدد الأولويات |
| **تغييرات غير محفوظة** | شارة عند التعديل |
| **تهيئة الافتراضيات** | تظهر عندما كل الأوقات صفر؛ تحمّل قيمًا للمراجعة ثم احفظ |
| **إضافة أولوية** | درج أولوية خدمة (APP) |
| **تحديث / إلغاء** | إعادة تحميل أو التراجع عن التعديلات |
| **حفظ التغييرات** | يُفعَّل عند وجود تغييرات صالحة |

### الأعمدة

الأولوية | زمن الاستجابة (يوم / ساعة 0–23 / دقيقة 0–59) | زمن الحل (نفس الوحدات)

### قواعد التحقق

| القاعدة | التفصيل |
|---|---|
| الأيام | ≥ 0 |
| الساعات | 0–23 |
| الدقائق | 0–59 |
| الحل ≥ الاستجابة | زمن الحل يجب أن يكون أكبر من أو يساوي زمن الاستجابة |
| حد أدنى للأولويات | الإبقاء على أولويتين على الأقل عند الحذف |

قيم افتراضية شائعة عند التهيئة (لا تُحفظ حتى تضغط حفظ): عالية ≈ استجابة 4 ساعات وحل يوم؛ متوسطة ≈ 8 ساعات / يومين؛ منخفضة ≈ يوم / 3 أيام.

### إضافة أولوية

الدرج يستخدم نموذج أولوية الخدمة: الاسم، الاسم AR، الأوصاف، اللون (اختيارية في التحقق). المرجع الإداري أيضًا: [أولويات الخدمة](/docs/org/service-priority).

## أفضل الممارسات

:::tip[راجع الافتراضيات ثم احفظ]
تهيئة الافتراضيات لا تثبت وحدها — اضغط **حفظ التغييرات** بعد المراجعة.
:::

:::warning[لا تحذف حتى تبقي أولويتين]
النظام يرفض النزول عن أولويتين في المصفوفة.
:::
