# تفاصيل الموظف وحقوله

نموذج التفاصيل هو قلب البيانات الأساسية. يظهر في العرض القياسي بالكامل على `/Entities/HRM/Employee/{رقم}`، وفي تبويب **التفاصيل** داخل عرض 360. الحقول مقسّمة إلى أقسام قابلة للطي.

## حقول الترويسة

من أعلى الصفحة، دون النزول للنموذج:

| الحقل | الشرح |
|---|---|
| **نشط (Active)** | يحدد إن كان السجل مفعّلًا في التشغيل اليومي |
| **مستوى السرية (DataConfidentiality)** | من يمكنه رؤية السجل |
| **الحالة (EntityStatus)** | حالة دورة الحياة — إلزامي |
| **النوع (EntityType)** | تصنيف الموظف — إلزامي |

## 1) الأسماء والهوية المعروضة

| الحقل | الشرح |
|---|---|
| الاسم الأول / الأوسط / الأخير (إنجليزي) | أجزاء الاسم الإنجليزية — إلزامية |
| الاسم الأول / الأوسط / الأخير (عربي) | أجزاء الاسم العربية — إلزامية |
| الاسم المعروض | يُركَّب تلقائيًا من الاسم الأول والأخير |

## 2) المعلومات العامة

| الحقل | الشرح |
|---|---|
| تاريخ الميلاد (birthDate) | تاريخ ميلاد الموظف |
| البريد الشخصي (personalEmail) | بريد غير تشغيلي؛ يجب أن يكون بصيغة صحيحة إن أُدخل |
| الجوال (mobile) | رقم التواصل الشخصي |
| الجنسية (Nationality) | جنسية الموظف |
| الحالة الاجتماعية (Marital) | الحالة الاجتماعية |
| الجنس (Gender) | جنس الموظف |
| فصيلة الدم (BloodGroup) | فصيلة الدم عند الحاجة الطبية |

## 3) معلومات النظام

| الحقل | الشرح |
|---|---|
| مستخدم التطبيق (AppUsr) | ربط بحساب مستخدم في النظام — يُقفل بعد الإنشاء |
| بريد العمل (workEmail) | البريد التشغيلي — يُقفل بعد الإنشاء |

:::note[بعد أول حفظ]
مستخدم التطبيق وبريد العمل يصبحان للقراءة فقط. أي تصحيح لاحق يحتاج مسارًا إداريًا خارج التعديل المباشر من النموذج.
:::

## 4) معلومات التوظيف

| الحقل | الشرح |
|---|---|
| تاريخ البداية / النهاية | مدة التعيين الظاهرة؛ النهاية لا تسبق البداية |
| تاريخ الالتحاق / الخروج | تواريخ الالتحاق والخروج الفعلية؛ الخروج لا يسبق الالتحاق |
| المدير المباشر (DirectManager) | المسؤول التشغيلي المباشر |
| وردية العمل (WorkShift) | وردية الدوام |
| الدرجة (Grade) | الدرجة الوظيفية |
| الوظيفة (Job) | المسمى الوظيفي |
| الفرع (Branch) | فرع العمل |
| القسم (Department) | القسم التنظيمي |
| التأمين الطبي (MedicalInsurance) | ربط أو بيانات التأمين الطبي |
| مصدر السيرة (ResumeSource) | من أين وصل المرشح/الموظف |
| العملة (Currency) | عملة التعويض |
| ساعات العمل | ساعات العمل المعتمدة للسجل |

## 5) العنوان

يسجّل عنوان الإقامة أو العنوان المعتمد للتواصل (الدولة، المدينة، المنطقة، الشارع، الرمز البريدي حسب الحقول الظاهرة في الواجهة).

## تحققات النموذج

1. تاريخ النهاية ≥ تاريخ البداية
2. تاريخ الخروج ≥ تاريخ الالتحاق
3. البريد الإلكتروني بصيغة صحيحة عند تعبئته
4. النوع والحالة مطلوبان في الترويسة

إذا ظهر خطأ تحقق، أكمل الحقل الناقص ثم احفظ مرة أخرى.

## كيف تحفظ

1. عدّل الحقول المطلوبة
2. اضغط **حفظ التغييرات**
3. للمتابعة التشغيلية افتح `/Entities/HRM/Employee/360/{رقم}`

## أفضل الممارسات

:::tip[عبّئ القسم والوظيفة والمدير من الأسبوع الأول]
تقارير الهيكل ومسيرات الرواتب تضعف إذا بقيت حقول التوظيف فارغة بعد التعيين الفعلي.
:::

:::warning[العملة ليست للعرض فقط]
مبالغ الراتب والتكلفة تُقرأ بعملة السجل. ثبّتها مبكرًا حتى لا تختلط مقارنات المسيرات.
:::
