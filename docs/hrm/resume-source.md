# مصدر السيرة

**مصدر السيرة (Resume Source)** قيمة مرجعية توضّح من أين وصل المرشح أو الموظف (موقع، توصية، وكالة، إلخ حسب بياناتك).

**الصفحة:** `/Entities/HRM/ResumeSource`

## ماذا تفعل هذه الشاشة

- تدير مصادر السير الذاتية
- تُختار في معلومات التوظيف للمرشح أو الموظف

## الاستخدام

1. افتح قائمة مصادر السيرة
2. أنشئ المصادر التي تعتمدها الاستقطاب
3. اربطها عند إنشاء [مرشح](/docs/hrm/candidate) أو تعبئة توظيف الموظف

:::tip[ثبّت المصادر قبل حملات التوظيف]
مصدر واضح يسهّل قياس فعالية قنوات الاستقطاب مع [إعلان الوظيفة](/docs/hrm/job-post).
:::
