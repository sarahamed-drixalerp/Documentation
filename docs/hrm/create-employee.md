# إنشاء موظف جديد

إنشاء الموظف هو الخطوة التي تحوّل قرار التعيين إلى سجل يمكن للرواتب والحضور والإجازات الارتباط به. بعد الحفظ يظهر رقم الموظف، ويمكن فتح عرض 360 وإضافة البنود التابعة.

## كيف تنشئ موظفًا

1. من **الموظفون** اضغط زر الإنشاء (+)
2. تُفتح صفحة العرض القياسي على `/Entities/HRM/Employee/new`
3. عبّئ الحقول الإلزامية في الترويسة والأسماء باللغتين
4. أضف المعلومات العامة والنظام والتوظيف والعنوان إن كانت معروفة الآن
5. اضغط **حفظ التغييرات**
6. بعد الحفظ انتقل إلى [عرض 360](/docs/hrm/employee-360) لمتابعة البنود التابعة

:::tip[راجع بريد العمل قبل أول حفظ]
مستخدم التطبيق وبريد العمل يُقفلان بعد الإنشاء. صحّحهما قبل الحفظ الأول.
:::

## الحقول الإلزامية

لن يُحفظ الموظف بدون هذه الحقول:

| الحقل | لماذا هو إلزامي |
|---|---|
| **الاسم الأول / الأوسط / الأخير (إنجليزي)** | الهوية التشغيلية والبحث |
| **الاسم الأول / الأوسط / الأخير (عربي)** | الواجهة العربية والتقارير المحلية |
| **النوع (EntityTypeId)** | تصنيف السجل |
| **الحالة (EntityStatusId)** | نقطة البداية في دورة الحياة |

يُركَّب **الاسم المعروض** تلقائيًا من الاسم الأول والأخير؛ لا يُكتب يدويًا كحقل مستقل في النموذج الرئيسي.

## أقسام النموذج عند الإنشاء

| القسم | الحقول |
|---|---|
| **معلومات عامة** | تاريخ الميلاد، البريد الشخصي، الجوال، الجنسية، الحالة الاجتماعية، الجنس، فصيلة الدم |
| **معلومات النظام** | مستخدم التطبيق (AppUsr)، بريد العمل (يُقفل بعد الإنشاء) |
| **معلومات التوظيف** | تواريخ البداية/النهاية والالتحاق/الخروج، المدير المباشر، وردية العمل، الدرجة، الوظيفة، الفرع، القسم، التأمين الطبي، مصدر السيرة، العملة، ساعات العمل |
| **العنوان** | الدولة، المدينة، المنطقة، الشارع، الرمز البريدي (حسب الحقول الظاهرة في الواجهة) |

تفاصيل كل حقل في [تفاصيل الموظف وحقوله](/docs/hrm/employee-details).

## تحققات عند الحفظ

| التحقق | النتيجة |
|---|---|
| تاريخ النهاية أقدم من البداية | يُرفض أو يُفرَّغ التاريخ غير الصالح |
| تاريخ الخروج أقدم من الالتحاق | يُرفض التعديل |
| بريد إلكتروني بصيغة غير صحيحة | يظهر خطأ تحقق على الحقل |
| ترك النوع أو الحالة | يظهر «هذا الحقل مطلوب» |

## أخطاء شائعة عند الإنشاء

- نسيان الأسماء العربية أو الإنجليزية بأجزائها الثلاثة
- ترك النوع أو الحالة فارغين
- إدخال تاريخ نهاية قبل تاريخ البداية
- إدخال تاريخ خروج قبل تاريخ الالتحاق
- كتابة بريد بصيغة ناقصة ثم محاولة الحفظ

## بعد الحفظ مباشرة

1. راجع الرقم في الترويسة
2. انتقل إلى `/Entities/HRM/Employee/360/{رقم}`
3. أضف [بنود الراتب](/docs/hrm/employee-salary-items) إن وُجدت
4. أضف [المعالين](/docs/hrm/employee-dependants) و[المؤهلات](/docs/hrm/employee-qualifications) عند الحاجة
5. عيّن الموظف لاحقًا في [مسير رواتب](/docs/hrm/payroll)

## أفضل الممارسات

:::tip[أنشئ الموظف قبل تسجيل الحضور أو الرواتب]
أي حضور أو مسير رواتب بدون سجل موظف معتمد يفقد الربط بالتكلفة والتقارير.
:::

:::warning[لا تستخدم سجلًا واحدًا لشخصين]
كل فرد يستحق سجل موظف مستقل حتى لو تشابه القسم أو الراتب.
:::
