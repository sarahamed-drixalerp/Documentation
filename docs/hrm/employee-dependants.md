# معالو الموظف

تبويب المعالين يسجّل الأفراد المرتبطين بالموظف لأغراض الموارد البشرية (مثل التأمين أو السجلات العائلية) داخل سجل الموظف نفسه.

**المكان:** عرض 360 ← **المعالون (Dependants)**  
**السجل الأب:** `/Entities/HRM/Employee/360/{رقم}`

## ماذا يفعل هذا التبويب

- يدير سجلات المعالين التابعة للموظف
- يحفظ الاسم باللغتين والنوع والحالة والعلاقة
- يوثّق بيانات الميلاد والجنس عند الحاجة

## الحقول الإلزامية

| الحقل | الشرح |
|---|---|
| الاسم (name) | الاسم الإنجليزي للمعال |
| الاسم بالعربية (nameAr) | الاسم العربي |
| النوع (type) | تصنيف سجل المعال |
| الحالة (status) | حالة السجل |

## حقول إضافية

| الحقل | الشرح |
|---|---|
| العلاقة (RelationId) | صلة القرابة أو العلاقة بالموظف |
| الاسم الأول / الأوسط / الأخير | تفصيل الاسم إن وُجدت الحقول |
| تاريخ الميلاد (birthDay) | تاريخ ميلاد المعال |
| الجنس (GenderId) | جنس المعال |

## كيف تضيف معالًا

1. افتح عرض 360 للموظف
2. انتقل إلى تبويب **المعالون**
3. أضف سجلًا جديدًا
4. عبّئ `name` و`nameAr` و`type` و`status`
5. اختر العلاقة والجنس وتاريخ الميلاد عند توفرها
6. احفظ السجل التابع

## أفضل الممارسات

:::tip[طابق الأسماء مع الوثائق الرسمية]
استخدم الأسماء كما تظهر في الهوية أو جواز السفر حتى لا تتعارض مع التأمين أو الطلبات الرسمية.
:::

:::warning[لا تترك النوع أو الحالة فارغين]
بدون النوع والحالة لن يُحفظ السجل. أكمل الحقول الإلزامية قبل المغادرة من الحوار.
:::
