# التأمين الطبي

**التأمين الطبي (Medical)** يعرّف بوليصة أو تغطية طبية يمكن ربطها بالموظف، مع مورد وتواريخ اختيارية.

**المسار:** القائمة الجانبية ← الموارد البشرية ← التأمين الطبي  
**الصفحات:** `/Entities/HRM/Medical` · `/Entities/HRM/Medical/new` · `/Entities/HRM/Medical/{رقم}`

## ماذا تفعل هذه الشاشة

- تنشئ سجلات التأمين بالاسمين
- تربط بمورد (Supplier) وتواريخ بداية/نهاية
- تدعم عرض الشجرة مع التجميع حسب المورد

## الحقول الأساسية

| الحقل | المعنى |
|---|---|
| **الاسم (name)** | اسم التغطية / البوليصة |
| **الاسم العربي (nameAr)** | العرض بالعربية |
| **المورد (supplierId)** | جهة التأمين أو المزود |
| **تاريخ البداية (startDate)** | بداية التغطية |
| **تاريخ النهاية (endDate)** | نهاية التغطية |

النوع والحالة في الترويسة إلزاميان كحوكمة سجل.

## القائمة والشجرة

- **قائمة / بطاقات:** للعمل اليومي
- **شجرة:** تجميع حسب المورد (`Supplier`) وغيرها من حقول التجميع المتاحة

يمكنك أيضًا تصفية القائمة حسب المورد.

## أفضل الممارسات

:::tip[حدّث تواريخ التغطية قبل ربط الموظفين]
تواريخ منتهية أو فارغة تضعف وضوح من هم تحت تغطية سارية.
:::
