# درجة التقييم

**درجة التقييم (Evaluation Score)** هي مقياس الدرجات المستخدم في المخططات والتقييمات: حد أدنى وحد أقصى، ومستويات فرعية بينها.

**المسار:** القائمة الجانبية ← الموارد البشرية ← درجات التقييم  
**الصفحات:** `/Entities/HRM/EvaluationScore` · `/Entities/HRM/EvaluationScore/new` · `/Entities/HRM/EvaluationScore/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرّف مقياسًا بالاسمين والحدين الأدنى والأقصى
- تدير المستويات الفرعية (Evaluation Score Levels)
- تُستخدم كـ «نوع درجة» داخل [مخطط التقييم](/docs/hrm/evaluation-schema)

## الحقول الإلزامية

| الحقل | لماذا هو إلزامي |
|---|---|
| **الاسم (name)** | تعريف المقياس |
| **الاسم العربي (nameAr)** | العرض بالعربية |
| **الحد الأدنى (min / Min Score Level)** | بداية المقياس |
| **الحد الأقصى (max / Max Score Level)** | نهاية المقياس (≥ الحد الأدنى) |

## المستويات الفرعية

بعد الحفظ تظهر مستويات الدرجة كسجلات فرعية. يمكن إضافة مستويات وسيطة ضمن النطاق.

:::warning[نهايات المقياس غير قابلة للحذف]
مستويا **الحد الأدنى** و**الحد الأقصى** (نهايات المقياس / endpoints) لا يُحذفان من الواجهة. احذف فقط المستويات الوسيطة إن لزم.
:::

## أفضل الممارسات

:::tip[اختر نطاقًا واضحًا قبل البناء]
نطاق مثل 0–100 أو 1–5 يحدد شكل المستويات وخيارات Choose Level في التقييم.
:::

:::tip[اربط المخطط بعد استقرار المستويات]
لا تنشر مخططًا قبل أن تكون مستويات الدرجة جاهزة للتقييم.
:::
