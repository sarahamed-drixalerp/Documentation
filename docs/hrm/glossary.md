# المصطلحات

تعريفات مختصرة كما تظهر في موارد بشرية Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| الموارد البشرية (HRM) | وحدة تشغيل الأفراد: موظفون، رواتب، توظيف، تقييم، هيكل وبيانات مرجعية |
| موظف (Employee) | سجل الفرد التشغيلي المرتبط بالقسم والوظيفة والراتب والحضور |
| عرض 360 | مساحة عمل السجل بالتبويبات التابعة (مثل موظف أو JobPost على مساره) |
| العرض القياسي / السجل | صفحة التفاصيل والإنشاء والتعديل |
| مسير رواتب (Payroll) | فترة رواتب تُحسب ثم تُنشر وتُقفل |
| احتساب (Generate) | حساب مستحقات واستقطاعات المسير قبل القفل النهائي |
| نشر (Publish / Post) | تثبيت حالة السجل (مثل نشر مخطط تقييم، أو Post لإعلان وظيفة إلى Published، أو نشر مسير) |
| بنود المسير (Payroll Items) | مركز تبويبي لـ SalaryItems وCostItems وليس كيان CRUD |
| بند راتب (Salary Item) | عنصر كتالوج مستحق/استقطاع (`sI_val` / `sI_prc`) |
| بند تكلفة (Cost Item) | عنصر كتالوج تكلفة صاحب العمل (`cI_val` / `cI_prc`) |
| إعلان وظيفة (JobPost) | شاغر منشور؛ واجهة على `/Entities/HRM/JobPost` و`/Entities/HRM/Post` |
| مرشح (Candidate) | متقدم للتوظيف مع سير مراحل |
| مرشح إعلان (JobPostCandidate) | ربط مرشح بإعلان؛ التعديل يفتح صفحة المرشح |
| تقييم (Evaluation) | تنفيذ تقييم موظف على مخطط؛ يُقفل عند Submitted |
| مخطط تقييم (Evaluation Schema) | هيكل Goals/KPIs مع نوع درجة؛ يُنشر بعد اكتمال المحتوى |
| درجة تقييم (Evaluation Score) | مقياس min/max مع مستويات فرعية |
| مستوى درجة (Score Level) | قيمة اختيار ضمن المقياس (`levelValue_dec`) |
| هدف / مؤشر (Goal / KPI) | عناصر المخطط؛ في التقييم يُختار مستوى لكل KPI |
| وظيفة (Job) | مسمّى وظيفي؛ اختياريًا بقسم ودرجة |
| درجة (Grade) | سلم/مستوى وظيفي |
| وردية (Work Shift) | جدول ساعات أسبوعي مع منطقة زمنية |
| تأمين طبي (Medical) | تغطية طبية مرتبطة بمورد وتواريخ |
| هيكل تنظيمي (Org Chart) | شجرة من المدير المباشر مع بحث وتحريك |
| لوحة HRM (Dashboard) | مؤشرات ورسوم القوى العاملة |
| جهاز بصمة (Biometric / ZKTeco) | جهاز حضور يُسجَّل في إعدادات HRM |
| مصدر سيرة (Resume Source) | قناة وصول المرشح |
| صلة قرابة (Relation) | نوع علاقة المعال |
| فصيلة دم / جنس / حالة اجتماعية | قيم مرجعية للملف الشخصي |
