# الدرجات

**الدرجة (Grade)** تمثّل مستوى أو سلمًا وظيفيًا يُربط بالموظف أو بالوظيفة عند الحاجة.

**المسار:** القائمة الجانبية ← الموارد البشرية ← الدرجات  
**الصفحات:** `/Entities/HRM/Grade` · `/Entities/HRM/Grade/new` · `/Entities/HRM/Grade/{رقم}`

## ماذا تفعل هذه الشاشة

- تعرّف الدرجات بالاسمين مع النوع والحالة
- تتيح ثلاثة أساليب عرض: قائمة، بطاقات، شجرة تجميع

## الحقول الإلزامية

| الحقل | لماذا هو إلزامي |
|---|---|
| **الاسم (name)** | تعريف الدرجة |
| **الاسم العربي (nameAr)** | العرض بالعربية |
| **النوع (EntityTypeId)** | تصنيف السجل |
| **الحالة (EntityStatusId)** | حالة الدرجة |

## طرق العرض

| العرض | الاستخدام |
|---|---|
| **قائمة** | العمل اليومي والترتيب والإجراءات |
| **بطاقات** | نظرة سريعة |
| **شجرة** | التجميع حسب حقول التجميع المتاحة في الواجهة |

## أفضل الممارسات

:::tip[وحّد تسمية الدرجات قبل التعيين]
درجات متضاربة الأسماء تضعف تقارير الهيكل والرواتب عند ربط الموظفين والوظائف.
:::
