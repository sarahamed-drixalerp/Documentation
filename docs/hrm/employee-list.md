# قائمة الموظفين

قائمة الموظفين هي نقطة الدخول اليومية. منها تبحث، تصفّي، تقارن الرواتب، وتنشئ موظفًا جديدًا، أو تفتح سجلًا للتعديل أو لمساحة 360.

**المسار:** القائمة الجانبية ← الموارد البشرية ← الموظفون  
**الصفحة:** `/Entities/HRM/Employee`

## ماذا تفعل هذه الشاشة

- تعرض كل الموظفين الذين تسمح لك صلاحياتك برؤيتهم
- تلخّص الراتب الأساسي وصافي الراتب والتكلفة الإجمالية والعمل الإضافي والقروض المعلقة
- تتيح ثلاثة أساليب عرض: جدول، بطاقات، شجرة تجميع
- تفتح الإنشاء أو التعديل أو عرض 360 أو الحذف (حسب الصلاحية)

## طرق العرض

في أعلى الصفحة ثلاثة أيقونات:

| العرض | متى تستخدمه |
|---|---|
| **قائمة** | العمل اليومي، الترتيب، الأعمدة، الإجراءات السريعة |
| **بطاقات** | نظرة إدارية سريعة مع الوظيفة والقسم وصافي الراتب |
| **شجرة** | التجميع حسب النوع أو الحالة أو الدرجة أو الفرع أو الوظيفة أو القسم أو الدولة |

### عرض القائمة

الأعمدة الافتراضية:

- الاسم
- الوظيفة
- القسم
- الدولة
- صافي الراتب (NetPay)
- تاريخ البداية
- تاريخ النهاية
- إجراءات الصف: تعديل، عرض 360، حذف

اضغط اسم الموظف لفتح العرض القياسي.

### عرض البطاقات

كل بطاقة تُظهر ملخصًا سريعًا للموظف (مثل الوظيفة والقسم وصافي الراتب) لتسهيل المراجعة الإدارية دون فتح السجل.

### عرض الشجرة

اختر **تجميع حسب** ثم أحد الحقول:

- النوع (EntityType)
- الحالة (EntityStatus)
- الدرجة (Grade)
- الفرع (Branch)
- الوظيفة (Job)
- القسم (Department)
- الدولة (Country)

عند اختيار مجموعة تظهر تحليلات تلك المجموعة. عند اختيار موظف فردي تظهر مؤشراته.

## التصفية والبحث

يمكنك التصفية حسب:

- الاسم (Name)
- النوع (EntityType)
- الحالة (EntityStatus)
- الدرجة (Grade)
- الفرع (Branch)
- الوظيفة (Job)
- القسم (Department)
- الدولة (Country)

استخدم عدة عوامل معًا لتضييق القائمة، مثل: الحالة = نشط + القسم = الموارد البشرية.

## مؤشرات أعلى القائمة

تعرض الشاشة مجاميع للحقول التالية على النتائج الحالية:

- الراتب الأساسي (Basic_val)
- صافي الراتب (NetPay_val)
- التكلفة الإجمالية (TotalCost_val)
- العمل الإضافي (OverTime_val)
- القروض المعلقة (PendingLoans_val)

هذه الأرقام تتغير مع الفلاتر، فهي ملخص لما تراه الآن وليس بالضرورة لكل المؤسسة.

## الإجراءات من القائمة

1. **إنشاء موظف جديد** — زر الإنشاء (+) يفتح `/Entities/HRM/Employee/new`
2. **تعديل** — أيقونة القلم تفتح العرض القياسي `/Entities/HRM/Employee/{رقم}`
3. **عرض 360** — يفتح مساحة التشغيل `/Entities/HRM/Employee/360/{رقم}`
4. **حذف** — يتطلب تأكيدًا ولا يمكن التراجع عنه

:::danger[احذف فقط المسودات الخاطئة]
لا تحذف موظفًا له حضور أو مسيرات رواتب أو قروض. استخدم [إنهاء الخدمة](/docs/hrm/employee-actions) إذا غادر العمل رسميًا.
:::

## أفضل الممارسات

:::tip[ثبّت عرض القائمة للعمل اليومي]
اعتمد القائمة للتشغيل، والبطاقات للاجتماعات الإدارية، والشجرة لمراجعة قسم أو فرع أو درجة معيّنة.
:::

:::note[الأعمدة قابلة للتخصيص]
يمكنك إظهار أو إخفاء أعمدة الجدول حسب دورك. لا تحذف عمود الحالة أو القسم من عرضك اليومي إن كنت تعتمد عليهما في التصفية.
:::
