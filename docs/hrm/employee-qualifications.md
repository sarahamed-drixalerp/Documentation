# مؤهلات الموظف

تبويب المؤهلات يوثّق الشهادات والمؤهلات العلمية أو المهنية المرتبطة بالموظف داخل سجل 360.

**المكان:** عرض 360 ← **المؤهلات (Qualifications)**  
**السجل الأب:** `/Entities/HRM/Employee/360/{رقم}`

## ماذا يفعل هذا التبويب

- يدير سجلات المؤهلات التابعة للموظف
- يحفظ الاسم باللغتين والنوع والحالة
- يوثّق تاريخ الاكتساب والجامعة والكلية والوصف

## الحقول الإلزامية

| الحقل | الشرح |
|---|---|
| الاسم (name) | اسم المؤهل بالإنجليزية |
| الاسم بالعربية (nameAr) | اسم المؤهل بالعربية |
| النوع (type) | تصنيف المؤهل |
| الحالة (status) | حالة السجل |

## حقول إضافية

| الحقل | الشرح |
|---|---|
| تاريخ الاكتساب (acquireOn) | متى اكتُسب المؤهل |
| الجامعة (univercity) | اسم الجامعة كما يظهر في الواجهة |
| الكلية (college) | الكلية أو القسم الأكاديمي |
| الوصف (descriptions) | تفاصيل إضافية عن المؤهل |

:::note[تهجئة الحقل univercity]
اسم الحقل في الواجهة هو `univercity` كما هو مُعرَّف في النظام.
:::

## كيف تضيف مؤهلًا

1. افتح عرض 360 للموظف
2. انتقل إلى تبويب **المؤهلات**
3. أضف سجلًا جديدًا
4. عبّئ `name` و`nameAr` و`type` و`status`
5. أدخل تاريخ الاكتساب والجامعة والكلية والوصف عند الحاجة
6. احفظ السجل التابع

## أفضل الممارسات

:::tip[اربط المؤهل بتاريخ اكتساب واضح]
تاريخ الاكتساب يساعد في التحقق لاحقًا وفي تقارير الكفاءات دون الرجوع للملفات الورقية.
:::

:::warning[الاسم باللغتين مطلوب]
لا تعتمد على لغة واحدة فقط. التقارير والواجهات العربية والإنجليزية تقرأ الحقلين معًا.
:::
