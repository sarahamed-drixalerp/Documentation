# مقدمة الموارد البشرية

وحدة الموارد البشرية في Drixal ERP هي مركز تشغيل الأفراد داخل المؤسسة. تجمع الموظفين والرواتب والتوظيف والتقييم والبيانات الأساسية والهيكل التنظيمي في مساحة واحدة، ثم تربط كل موظف بسجل حي: التعيين، الحضور، الإجازات، التعويضات، والقروض.

بدون هذه الوحدة تبقى بيانات الأفراد متفرقة: عقد في البريد، راتب في ملف، حضور في جهاز، وإجازات في جداول. داخل Drixal يصبح الموظف سجلًا متصلًا بالقسم والوظيفة والدرجة ومسير الرواتب وتكلفة التشغيل.

## ماذا تفعل الوحدة لأعمالك

- توحّد لغة العمل: موظف ← تعيين ← راتب ← حضور وإجازات
- تعطي موارد البشرية شاشة واحدة لمتابعة الصافي والتكلفة والقروض والتقييم
- تمكّن الإدارة من رؤية الهيكل والقوى العاملة بدل سؤال كل قسم على حدة
- تربط التشغيل بالمالية عبر مسيرات الرواتب وبنود الراتب والتعويضات

## التسلسل الهرمي

```text
المؤسسة / الفروع
  └── الأقسام والوظائف والدرجات
        └── الموظف (Employee)
              ├── بنود الراتب والتعويض
              ├── الحضور والإجازات
              ├── التقييمات والمعالون والمؤهلات
              └── المسيرات والقروض والمصاريف ورحلات العمل
```

| المستوى | الغرض |
|---|---|
| **الفرع / القسم / الوظيفة / الدرجة** | الإطار التنظيمي للتعيين والتقارير |
| **الموظف** | وحدة التشغيل اليومية: هوية، تعيين، راتب، حضور |
| **مسير الرواتب** | تشغيل فترة رواتب لمجموعة موظفين ثم احتساب ونشر |
| **التبويبات التابعة** | سجلات فرعية مربوطة بالموظف (بنود، معالون، قروض…) |

يمكنك فتح سجل الموظف مباشرة من القائمة. الربط بالقسم والوظيفة والمدير المباشر اختياري عند الإنشاء لكنه مهم للتقارير الإدارية ومسيرات الرواتب.

## أين تجده في النظام

من القائمة الجانبية اختر **الموارد البشرية** ثم:

- لوحة التحكم
- **الموظفون** ← محور هذا الدليل
- مسيرات الرواتب
- التوظيف / التوظيفات
- التقييم
- الهيكل التنظيمي
- البيانات الأساسية (أنواع وحالات ودرجات وبنود راتب…)
- الإعدادات

## من يستخدم هذا القسم

| الدور | الاستخدام اليومي |
|---|---|
| مدير الموارد البشرية | الحوكمة، التعيين، إنهاء الخدمة، السياسات |
| أخصائي الرواتب | بنود الراتب، المسيرات، الاحتساب والنشر |
| مدير القسم | متابعة الفريق، الحضور، التقييمات |
| التوظيف | مصادر السير والمرشحون حتى التحويل لموظف |
| الموظف (تطبيق شخصي) | الحضور والإجازات الشخصية عبر تطبيق الحضور عند تفعيله |

## كيف يُنظَّم دليل الموارد البشرية

1. فهم الموظف وأنواعه وحالاته ودورة حياته
2. العمل على القائمة (بحث، تصفية، إنشاء)
3. تعبئة التفاصيل والتوظيف والعنوان
4. استخدام عرض 360 وكل تبويب تابع
5. الإجراءات الرسمية: إنهاء الخدمة، تغيير القسم/الوظيفة/الراتب
6. مسيرات الرواتب ودورة الاحتساب والنشر

## أفضل الممارسات

:::tip[لا تبدأ بالراتب قبل سجل الموظف]
أنشئ الموظف أولًا بالحقول الإلزامية، ثم أضف بنود الراتب وعيّنه في المسير. أي احتساب بلا سجل موظف معتمد يفقد الربط بالتكلفة والتقارير.
:::

:::warning[الصلاحيات تُظهر أو تخفي البيانات]
بعض المستخدمين يرون الموظف للقراءة فقط، وبعض الحقول المالية قد تُحجب. إذا ظهر «معلومات محجوبة» فهذا إعداد صلاحيات وليس عطلًا.
:::
