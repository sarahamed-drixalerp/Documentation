# بنود راتب الموظف

تبويب بنود الراتب يربط الموظف بعناصر التعويض: مستحقات واستقطاعات تظهر لاحقًا في احتساب المسيرات والتقارير.

**المكان:** عرض 360 ← **بنود الراتب (SalaryItems)**  
**السجل الأب:** `/Entities/HRM/Employee/360/{رقم}`

## ماذا يفعل هذا التبويب

- يعرض بنود الراتب المرتبطة بالموظف
- يضيف بندًا جديدًا أو يعدّل قيم المستحق والاستقطاع
- يوضح أثر كل بند على هيكل التعويض قبل دخول المسير

## أعمدة القائمة

| العمود | الشرح |
|---|---|
| اسم بند الراتب (salaryItemName) | اسم البند المعروض |
| المستحق (earning_val) | قيمة المستحق |
| الاستقطاع (deduction_val) | قيمة الاستقطاع |

## الحقول عند الإضافة أو التعديل

| الحقل | الشرح |
|---|---|
| بند الراتب (SalaryItemId) | اختيار البند من البيانات الأساسية |
| المستحق (earning_val) | قيمة ≥ 0 |
| الاستقطاع (deduction_val) | قيمة ≥ 0 |

## كيف تضيف بند راتب

1. افتح عرض 360 للموظف
2. انتقل إلى تبويب **بنود الراتب**
3. أضف سجلًا جديدًا
4. اختر **SalaryItemId**
5. أدخل `earning_val` و/أو `deduction_val` بحيث لا تقل أي قيمة عن صفر
6. احفظ السجل التابع

:::warning[لا تُدخل قيمًا سالبة]
المستحق والاستقطاع يجب أن يكونا ≥ 0. صحّح الإشارة قبل الحفظ.
:::

## أفضل الممارسات

:::tip[راجع البنود قبل أول احتساب مسير]
أي بند ناقص أو بقيمة خاطئة ينعكس على إجمالي المستحقات والاستقطاعات وصافي الدفع بعد الاحتساب.
:::

:::note[البند مرتبط بالموظف لا بالمسير فقط]
البنود هنا جزء من هيكل تعويض الموظف. المسير يستهلك هذا الهيكل عند الاحتساب.
:::
