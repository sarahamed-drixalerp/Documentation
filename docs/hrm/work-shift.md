# ورديات العمل

**وردية العمل (Work Shift)** تعرّف جدول ساعات الأسبوع للمنطقة الزمنية المحددة، وتُربط بالموظف عند التعيين.

**الصفحة:** `/Entities/HRM/WorkShift` · السجل `/Entities/HRM/WorkShift/{رقم}`

## ماذا تفعل هذه الشاشة

- تنشئ وردية بالاسمين والمنطقة الزمنية
- تضبط من/إلى لكل يوم من الأحد إلى السبت

## الحقول الأساسية

| الحقل | المعنى |
|---|---|
| **الاسم (name)** | اسم الوردية |
| **الاسم العربي (nameAr)** | العرض بالعربية |
| **المنطقة الزمنية (timeZoneId)** | مرجع التوقيت للوردية |

### أوقات الأيام

لكل يوم حقلان:

| اليوم | من | إلى |
|---|---|---|
| الأحد | `sun_From` | `sun_To` |
| الإثنين | `mon_From` | `mon_To` |
| الثلاثاء | `tue_From` | `tue_To` |
| الأربعاء | `wed_From` | `wed_To` |
| الخميس | `thr_From` | `thr_To` |
| الجمعة | `fri_From` | `fri_To` |
| السبت | `sat_From` | `sat_To` |

النوع والحالة جزء من ترويسة السجل كباقي كيانات HRM.

## أفضل الممارسات

:::tip[طابق المنطقة الزمنية مع موقع العمل]
وردية بدون timeZoneId صحيح تربك تفسير الحضور عبر الفروع.
:::

:::note[أيام الراحة]
اترك من/إلى فارغين أو حسب سياسة مؤسستك لأيام غير العمل؛ لا تخترع ساعات غير موجودة في الواجهة.
:::
