# لوحة الموارد البشرية

**لوحة الموارد البشرية (HRM Dashboard)** ملخص تشغيلي للقوى العاملة: الأعداد، التوطين، توزيع الأقسام والرواتب، اتجاه الحضور، وجداول العقود.

**المسار:** القائمة الجانبية ← الموارد البشرية ← لوحة الموارد البشرية  
**الصفحة:** `/Entities/HRM/Dashboard`

## مؤشرات الملخص (KPIs)

| المؤشر | المعنى |
|---|---|
| **Total Employees** | إجمالي الموظفين في البيانات المحمّلة |
| **Departments** | عدد الأقسام الظاهرة في التوزيع |
| **Avg Salary** | متوسط الراتب |
| **Active Contracts** | العقود النشطة حسب منطق اللوحة |

## البطاقات والرسوم

| البطاقة | المحتوى |
|---|---|
| **Saudization** | توزيع سعودي / غير سعودي ونسبة الامتثال المعروضة |
| **Employees vs Departments** | توزيع العدد على الأقسام |
| **Employees vs Salaries** | ترتيب أعلى الرواتب تنازليًا |
| **Workforce Attendance Trend** | اتجاه ساعات الحضور عبر الأيام |
| **Employee Contract Timelines** | شريط زمني / غانت لتواريخ العقود من البداية إلى النهاية |

## الإجراءات السريعة

| الإجراء | الوجهة / الوظيفة |
|---|---|
| **Attendance Clock** | ساعة الحضور `/app/Attendance` |
| **Directory** | دليل الموظفين `/Entities/HRM/Employee` |
| **Refresh** | إعادة تحميل بيانات اللوحة |

## أفضل الممارسات

:::tip[حدّث اللوحة قبل اجتماع الإدارة]
اضغط Refresh لضمان أن الأعداد والرسوم تعكس آخر بيانات الموظفين.
:::

:::note[الملخص يعكس البيانات المحمّلة]
المؤشرات تعتمد على ما تُرجعُه واجهة اللوحة لصلاحياتك؛ ليست بالضرورة تقريرًا محاسبيًا مقفلاً.
:::
