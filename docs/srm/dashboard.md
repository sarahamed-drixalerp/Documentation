# لوحة المشتريات

**لوحة المشتريات (SRM Dashboard)** ملخّص تحليلي لمسار التوريد والتزام أوامر الشراء والذمم الدائنة. الشاشة للقراءة والتحديث — وليست لإنشاء أو تعديل أو حذف سجلات SRM.

**المسار:** القائمة الجانبية ← المشتريات ← لوحة المشتريات  
**الصفحة:** `/Entities/SRM/Dashboard`

## الفلاتر

| الفلتر | المعنى |
|---|---|
| **المورد (Supplier)** | مورد واحد أو **All Suppliers** (للمؤشرات والرسوم المقيَّدة بالمورد) |

تغيير الفلتر يعيد تحميل بيانات اللوحة. استخدم **Refresh** لإعادة التحميل دون مغادرة الصفحة.

## المؤشرات الرئيسية (شريط KPI)

| المؤشر | المعنى |
|---|---|
| **PO Commitment** | التزام أوامر الشراء (مجموع المبلغ) |
| **PO Unpaid** | غير المدفوع على أوامر الشراء |
| **AP Outstanding** | مستحقات فواتير المشتريات غير المدفوعة |
| **AP Paid** | المدفوع على فواتير المشتريات |
| **Supplier Exposure** | تعرض المورد (مستحقات الفواتير) |
| **Bid Pipeline** | قيمة مسار المناقصات |

## أقسام اللوحة

| القسم | المحتوى |
|---|---|
| **Procurement Pipeline** | رسوم دائرية لحالة PurchaseRequisition وBid وSupplierQuote |
| **Spend & Accounts Payable** | التزام PO حسب الحالة؛ فواتير AP / غير المدفوع حسب الحالة؛ الإنفاق والفوترة حسب المورد؛ قيمة المناقصة حسب الحالة |
| **Historical Trends** | اتجاه التزام PO؛ الفاتورة مقابل المدفوع؛ مدفوعات الموردين؛ قيمة مسار المناقصات عبر الزمن |

## كيف تستخدم اللوحة

1. افتح لوحة المشتريات من SRM
2. صفِّ اختياريًا حسب المورد (أو اترك All Suppliers)
3. راجع شريط المؤشرات ثم رسوم المسار والذمم الدائنة
4. اضغط **Refresh** قبل اجتماع مراجعة إن كانت البيانات قد تغيّرت

## أفضل الممارسات

:::tip[صفِّ حسب المورد لمراجعات الحساب]
استخدم فلتر المورد ليطابق المؤشرات ورسوم الذمم الحساب الذي تناقشه.
:::

:::warning[لا CRUD على اللوحة]
أنشئ وعدّل الطلبات والأوامر والفواتير والمدفوعات من شاشات الكيانات — لا من بطاقات اللوحة.
:::

:::note[الأرقام تتبع صلاحياتك]
المجاميع والرسوم من البيانات المتاحة لصلاحياتك؛ ليست تقرير تدقيق خارجي محكمًا.
:::
