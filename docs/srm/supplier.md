# الموردون

**المورد (Supplier)** هو سجل الحساب الرئيسي في المشتريات: الهوية التجارية، التسعير، الحظر، ومحور أوامر الشراء وفواتير الحسابات الدائنة المرتبطة.

**المسار:** القائمة الجانبية ← المشتريات ← الموردون  
**الصفحات:** `/Entities/SRM/Supplier` · `/Entities/SRM/Supplier/{رقم}` · `/Entities/SRM/Supplier/360/{رقم}`

## ماذا يفعل المورد لأعمالك

- يحمل الاسم ثنائي اللغة والنوع والحالة وبيانات الاتصال والحساب
- يدعم **Block** / **UnBlock** و**AssignPriceList** و**OpeningBalance** و**CreateInvoice** و**AddPayment**
- يوفّر مساحة **360** لأوامر الشراء والفواتير

## نوعان من صفحات المورد

| الصفحة | متى تستخدمها |
|---|---|
| **العرض القياسي** `/Entities/SRM/Supplier/{رقم}` | التركيز على التفاصيل وإطار السجل |
| **عرض 360** `/Entities/SRM/Supplier/360/{رقم}` | التشغيل اليومي عبر أوامر الشراء والفواتير |

## قائمة الموردين

### الأعمدة (الأهم)

الاسم والحالة وبيانات الحساب كما تظهر في قائمة الموردين.

### التصفية

بحث وفلاتر القائمة المتاحة على الشاشة.

### إجراءات الصف

تعديل، عرض **360**.

## إجراءات دورة الحياة

| الإجراء | الوظيفة |
|---|---|
| **Block** / **UnBlock** | تقييد أو استعادة النشاط التجاري على حساب المورد |
| **AssignPriceList** | ربط قائمة أسعار بالمورد |
| **OpeningBalance** | تعيين أو تعديل الرصيد الافتتاحي |
| **CreateInvoice** | بدء فاتورة مشتريات للمورد |
| **AddPayment** | تسجيل دفعة للمورد |

## بعد الحفظ — تبويبات 360

| التبويب | المحتوى |
|---|---|
| **Details** | نموذج المورد |
| **PurchaseOrders** | أوامر الشراء المرتبطة |
| **Invoices** | فواتير المشتريات المرتبطة |

## كيف تنشئ أو تصون موردًا

1. افتح قائمة الموردين وأنشئ موردًا أو افتح سجلًا موجودًا
2. عبّئ الهوية والنوع والحالة وبيانات الاتصال
3. احفظ ثم استخدم Id أو 360 للإجراءات والتبويبات المرتبطة
4. استخدم Block فقط عند وقف النشاط؛ UnBlock عند الاستعادة

## أفضل الممارسات

:::tip[360 هو محور التشغيل]
استخدم 360 عند العمل عبر أوامر الشراء والفواتير لمورد واحد.
:::

:::warning[الحظر يقيّد النشاط]
لا تحظر موردًا ما زالت عليه أوامر أو فواتير نشطة دون اتفاق تشغيلي.
:::

:::note[CreateInvoice وAddPayment من المورد]
يمكن بدء الفاتورة والدفعة من إجراءات المورد مع الإبقاء على رابط الطرف واضحًا.
:::
