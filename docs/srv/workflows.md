# مسارات العمل

عنصر الشريط **مسارات العمل (Workflows)** يشير إلى `/Entities/APP/Workflow` لتصميم تدفقات الموافقة المرتبطة بالخدمات.

![مسارات العمل](/img/srv/workflows.svg)

## الوضع الحالي في البوابة

:::danger[واجهة مسارات العمل غير متاحة]
لا توجد صفحة APP عاملة لـ Workflow. يوجد غلاف يتيم تحت `/Entities/ADM/Workflow` يشير لمكوّنات غير موجودة. لا تعتمد على هذه الشاشة للتصميم اليوم.
:::

## ما يرتبط بمسارات العمل

| الموضوع | الصفحة / الدليل |
|---|---|
| تخصيص مهام أنشطة المسار | [تخصيص المهام](/docs/srv/task-allocation) — `/Entities/PMO/TaskAllocation` |
| طلب الخدمة بعد الحفظ | تبويبا Workflow و Approvals في شاشة الإرسال (قد تكون فارغة حتى يُربط المسار) |
| صندوق الوارد | [صندوق الوارد](/docs/app/inbox) لمهام الموافقة عند توفرها |

على مستوى البيانات: كيان Workflow يدعم الاسم، الإصدار، التصميم (VueFlow)، والحالة — دون واجهة تحرير جاهزة هنا.

## أفضل الممارسات

:::tip[جهّز تخصيص المهام وأولويات SLA]
بينما محرّر المسارات غير جاهز، أكمل [تخصيص المهام](/docs/srv/task-allocation) و[مصفوفة SLA](/docs/sla/sla-matrix) حتى تكون المراجع جاهزة عند تفعيل الواجهة.
:::
