# الماليات والفوترة

تبويب الماليات يربط تنفيذ المشروع بالنقد: متى نطالب، ماذا فوترنا، ماذا دفعنا للموردين، وما أوامر الشراء المفتوحة.

**المكان:** عرض 360 ← **الماليات**

الأقسام الأربعة:

1. خطة الفوترة
2. فواتير العملاء (AR)
3. فواتير الموردين (AP)
4. أوامر الشراء

## خطة الفوترة

خطة الفوترة هي جدول المطالبات المتوقع: ماذا نفوتر، ومتى، وبأي حالة.

**أنواع شائعة**

- توريد مواد
- تسليم تراخيص
- قوى عاملة

**حالات الخطة**

| الحالة | المعنى |
|---|---|
| مخطط | الدفعة في الخطة ولم يحن وقتها |
| مستحق | حان وقت المطالبة |
| مفوتر | صدرت فاتورة |
| مقدَّم | قُدّم للعميل |
| معتمد | اعتمده العميل |
| محصَّل | وصل التحصيل |

اربط الخطة بالعميل وبفاتورة العملاء عند صدورها.

## فواتير العملاء

فاتورة المبيعات المرتبطة بالمشروع: العميل، مدير الحساب، أمر البيع، المبلغ، المفوتر، المحصّل، تاريخ الفاتورة والاستحقاق.

راجع هنا:

- هل طُوّبت القيم حسب الخطة؟
- هل توجد فواتير مستحقة غير محصّلة؟
- هل تتطابق عملة الفاتورة مع عملة المشروع؟

## فواتير الموردين

تكلفة الموردين على المشروع: المورد، أمر الشراء، المبلغ، ما طُولب به، تواريخ الفاتورة والاستحقاق.

هذا الجانب يغذّي التكلفة الفعلية ومؤشر أداء التكلفة.

## أوامر الشراء

التزامات الشراء المرتبطة بالمشروع قبل وصول فاتورة المورد: المورد، مدير الحساب، تاريخ الإصدار، القيمة، الميزانية، الربح المخطط.

استخدم أمر الشراء حتى لا تظهر التكاليف فجأة عند وصول الفاتورة فقط.

## مؤشرات مالية تراها في المشروع

تُحسب على مستوى السجل وتظهر في التحليلات والترويسة:

- القيمة / الميزانية / الربح المخطط / الربح الفعلي
- التكلفة الفعلية والتكلفة المتبقية للإتمام
- الإيراد المعترف به وغير المعترف به
- المفوتر وغير المفوتر والمستحق
- المحصّل وغير المحصّل
- المدفوع وغير المدفوع
- المخطط وغير المخطط

:::note[بعض الأدوار لا ترى المبالغ]
إذا كانت صلاحيتك للقراءة التشغيلية فقط، قد تظهر عبارة «معلومات محجوبة» بدل الأرقام.
:::

## أفضل الممارسات

:::tip[لا تفوتر من الذاكرة]
كل مطالبة تمر: معلم أو بند → خطة فوترة → فاتورة عملاء. هذا المسار يحمي التحصيل عند اختلاف فريق المالية عن فريق المشروع.
:::

:::warning[أوامر شراء بلا سقف]
أمر شراء مفتوح على المشروع دون قيمة واضحة يضعف ميزانية المشروع قبل أن تبدأ الأعمال.
:::
