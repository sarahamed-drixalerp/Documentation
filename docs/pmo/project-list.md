# قائمة المشاريع

قائمة المشاريع هي نقطة الدخول اليومية. منها تبحث، تصفّي، تقارن القيم، وتنشئ مشروعًا جديدًا، أو تفتح سجلًا للتعديل أو لمساحة 360.

**المسار:** القائمة الجانبية ← مكتب إدارة المشاريع ← المشاريع

## ماذا تفعل هذه الشاشة

- تعرض كل المشاريع التي يسمح لك صلاحياتك برؤيتها
- تلخّص المبالغ والميزانية والربح المخطط والتكلفة الفعلية والتكلفة المتبقية
- تتيح ثلاثة أساليب عرض: جدول، بطاقات، شجرة تجميع
- تفتح الإنشاء أو التعديل أو عرض 360 أو الحذف (حسب الصلاحية)

## طرق العرض

في أعلى الصفحة ثلاثة أيقونات:

| العرض | متى تستخدمه |
|---|---|
| **قائمة** | العمل اليومي، الترتيب، الأعمدة، الإجراءات السريعة |
| **بطاقات** | نظرة إدارية سريعة مع شريط التقدم وأصحاب المصلحة |
| **شجرة** | التجميع حسب النوع أو الحالة أو العميل أو الاتفاقية أو المحفظة أو البرنامج أو المدير |

### عرض القائمة

الأعمدة الافتراضية:

- الاسم
- مدير المشروع
- القيمة المحتسبة
- الميزانية المحتسبة
- الربح الإجمالي المخطط
- تاريخ البداية
- تاريخ النهاية
- إجراءات الصف: تعديل، عرض 360، حذف

اضغط اسم المشروع لفتح العرض القياسي.

### عرض البطاقات

كل بطاقة تُظهر العميل ومدير المشروع والقيمة وتواريخ البداية والنهاية، مع شريط تقدم ومع أفاتار أصحاب المصلحة عند توفرهم.

### عرض الشجرة

اختر **تجميع حسب** ثم أحد الحقول:

- نوع المشروع
- حالة المشروع
- العميل
- الاتفاقية
- المحفظة
- البرنامج
- مدير المشروع
- مدير الحساب

عند اختيار مجموعة تظهر تحليلات تلك المجموعة. عند اختيار مشروع فردي تظهر تحليلاته.

## التصفية والبحث

يمكنك التصفية حسب:

- الاسم
- النوع
- الحالة
- العميل
- الاتفاقية
- المحفظة
- البرنامج
- مدير المشروع
- مدير الحساب

استخدم عدة عوامل معًا لتضييق القائمة، مثل: حالة = نشط + مدير المشروع = أنت.

## مؤشرات أعلى القائمة

تعرض الشاشة مجاميع للحقول التالية على النتائج الحالية:

- القيمة المحتسبة
- الميزانية المحتسبة
- الربح الإجمالي المخطط
- التكلفة الفعلية
- التكلفة المتبقية للإتمام

هذه الأرقام تتغير مع الفلاتر، فهي ملخص لما تراه الآن وليس بالضرورة لكل المؤسسة.

## الإجراءات من القائمة

1. **إنشاء مشروع جديد** — الزر الرئيسي أعلى اليسار/اليمين حسب اتجاه اللغة
2. **تعديل** — أيقونة القلم تفتح العرض القياسي
3. **عرض 360** — أيقونة المخطط تفتح مساحة التشغيل
4. **حذف** — يتطلب تأكيدًا ولا يمكن التراجع عنه

:::danger[احذف فقط المسودات الخاطئة]
لا تحذف مشروعًا له ساعات أو فواتير أو مخرجات. استخدم [الإنهاء](/docs/pmo/project-actions) إذا توقف العمل تعاقديًا.
:::

## أفضل الممارسات

:::tip[ثبّت عرض القائمة للعمل اليومي]
اعتمد القائمة للتشغيل، والبطاقات للاجتماعات الإدارية، والشجرة لمراجعة محفظة أو مدير معيّن.
:::

:::note[الأعمدة قابلة للتخصيص]
يمكنك إظهار أو إخفاء أعمدة الجدول حسب دورك. لا تحذف عمود الحالة من عرضك اليومي.
:::
