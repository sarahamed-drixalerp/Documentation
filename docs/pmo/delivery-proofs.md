# إثباتات التسليم

إثباتات التسليم هي الوثائق التي تُظهر أن العمل وصل للعميل وقُبل. بدونها تتأخر الفوترة ويضعف موقفك عند أي نزاع.

**المكان:** عرض 360 ← **إثباتات التسليم**

ثلاثة سجلات:

1. إشعار التسليم
2. شهادة الإنجاز (COC)
3. كشف الفريق

يمكن ربط كل منها بمرحلة أو معلم أو جهة اتصال أو فاتورة عملاء حسب سياق العمل.

## إشعار التسليم

يوثّق أن مواد أو خدمات أو حزمة عمل غادرت عهدتك إلى العميل أو الموقع.

| الحقل | الشرح |
|---|---|
| تاريخ الإصدار | يوم التسليم |
| تاريخ الاعتماد | يوم قبول العميل أو الاستشاري |
| المرحلة / المعلم | السياق الزمني |
| جهة الاتصال | من استلم |
| فاتورة العملاء | الربط المالي إن وُجد |

استخدم إشعار التسليم قبل المطالبة المرتبطة بتوريد أو تسليم جزئي.

## شهادة الإنجاز (COC)

شهادة الإنجاز تؤكد اكتمال نطاق متفق عليه — مرحلة أو مشروع أو معلم رئيسي — وهي غالبًا شرط الدفعة الأخيرة أو دفعة الاستلام.

اربط الشهادة بـ:

- العميل
- المرحلة أو المعلم المكتمل
- جهة الاعتماد
- فاتورة العملاء الناتجة عنها

:::tip[لا تُصدر فاتورة الاستلام قبل شهادة الإنجاز]
إذا كان عقدك يشترط الاستلام، فالشهادة هي المفتاح وليست المحادثة الشفهية.
:::

## كشف الفريق

كشف بأسماء الفريق الذي عمل على المشروع أو المرحلة، ويُطلب أحيانًا في عقود القوى العاملة أو عند التدقيق الأمني في موقع العميل.

اربط الكشف بالمرحلة أو المعلم إذا كان العقد يحاسب على حضور فريق معيّن في فترة معيّنة.

## أفضل الممارسات

:::warning[إثبات بلا تاريخ اعتماد]
إشعار تسليم أو شهادة بلا تاريخ اعتماد تبقى «ادّعاءً داخليًا» لا مستندًا تجاه العميل.
:::

:::note[ارفع المرفق على السجل نفسه]
استخدم مرفقات المشروع أو مرفقات السجل الفرعي لصورة الاستلام أو نسخة الشهادة الموقّعة.
:::
