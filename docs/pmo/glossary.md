# المصطلحات

تعريفات مختصرة كما تظهر في مشروع Drixal ERP. الأسماء الإنجليزية كما في النظام بين قوسين.

| المصطلح | التعريف |
|---|---|
| مكتب إدارة المشاريع (PMO) | التطبيق الذي يجمع المحافظ والبرامج والاتفاقيات والمشاريع وحوكمتها |
| محفظة (Portfolio) | تجميع استراتيجي لبرامج أو مشاريع |
| برنامج (Programme) | مجموعة مشاريع مترابطة تحت هدف واحد |
| اتفاقية (Agreement) | الإطار التعاقدي مع العميل، ويمكن أن يُشتق منه مشروع |
| مشروع (Project) | سجل التنفيذ: نطاق، جدول، تكلفة، فريق، تسليم |
| عرض 360 | مساحة العمل الكاملة للمشروع بكل التبويبات |
| العرض القياسي | صفحة التفاصيل والإنشاء والحوكمة |
| ترحيل (Post) | حفظ وتثبيت التحديث الظاهر مع بقاء التعديل ممكنًا |
| بند المشروع (Line Item) | تفصيل منتج أو خدمة داخل قيمة المشروع |
| أمر بيع (Sales Order) | الالتزام التجاري التفصيلي المرتبط بالمشروع |
| طلب تغيير (Change Request) | تعديل نطاق بعد الخطة المعتمدة |
| مخرج (Deliverable) | نتيجة قابلة للقبول من العميل |
| بند عمل (Work Item) | عنصر في هيكل التجزئة: مسار، حزمة، نشاط، مهمة، حدث |
| هيكل تجزئة العمل (WBS) | ترقيم هرمي لبنود العمل مثل 1.2.3 |
| مخطط جانت | عرض الجدول بالزمن والاعتماديات |
| الخطة الأساسية (Baseline) | التواريخ الأصلية المعتمدة للمقارنة |
| مرحلة (Phase) | فترة من المشروع لها بداية ونهاية |
| معلم (Milestone) | تاريخ استحقاق لنتيجة، وقد يكون قابلاً للفوترة |
| صاحب مصلحة (Stakeholder) | شخص أو جهة تؤثر أو تتأثر بالمشروع |
| RACI | مسؤول، محاسب، يُستشار، يُبلَّغ |
| خطة فوترة (Billing Plan) | جدول المطالبات وحالاتها حتى التحصيل |
| فاتورة عملاء (Invoice AR) | مطالبة مالية على العميل |
| فاتورة موردين (Invoice AP) | مطالبة المورد على المشروع |
| أمر شراء (Purchase Order) | التزام شراء قبل فاتورة المورد |
| إشعار تسليم (Delivery Note) | إثبات تسليم مواد أو خدمات |
| شهادة إنجاز (COC) | إثبات اكتمال نطاق أو مرحلة |
| كشف الفريق (Team Roster) | أسماء الفريق على مرحلة أو مشروع |
| افتراض (Assumption) | أمر اعتُبر صحيحًا دون إثبات كامل |
| قيد (Constraint) | حدّ معروف على الموارد أو الميزانية أو الزمن |
| محضر اجتماع (MOM) | توثيق قرارات الاجتماع |
| درس مستفاد (Lesson) | معرفة تُعاد استخدامها بعد مشكلة أو نجاح |
| مخاطرة (Risk) | حدث مستقبلي محتمل الأثر |
| مشكلة (Issue) | حدث وقع ويحتاج حلاً |
| SPI | مؤشر أداء الجدول |
| CPI | مؤشر أداء التكلفة |
| إيراد معترف به | الجزء الذي ينطبق عليه الاعتراف المحاسبي |
| تكلفة متبقية للإتمام | تقدير ما تبقّى صرفه حتى الإغلاق |
| زيادة الساعات | أصغر وحدة لتسجيل الوقت |
| اعتماد الجدول الزمني | قبول أو رفض ساعات الفريق على المشروع |
| مدقق المكتب (PMO Auditor) | المشرف على التزام المشروع بإجراءات المكتب |
| مدير المشروع | المسؤول التشغيلي عن التسليم |
| مدير الحساب | المسؤول التجاري عن علاقة العميل |
| مستوى السرية | تصنيف يحدد من يرى السجل |
| نوع المشروع | تصنيف مثل بسيط / ضخم / متعدد التخصصات |
| حالة المشروع | نشط، إيقاف مؤقت، دعم، مكتمل، منتهٍ |
