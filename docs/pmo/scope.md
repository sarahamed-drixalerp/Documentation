# النطاق

تبويب النطاق يجيب عن سؤال: **ماذا التزمنا تسليمه لهذا العميل، وما الذي تغيّر بعد التوقيع؟** يضم ثلاثة سجلات فرعية.

**المكان:** عرض 360 ← **النطاق**

## أوامر البيع

أمر البيع هو الالتزام التجاري التفصيلي المرتبط بالمشروع: العميل، الاتفاقية، التاريخ، القيمة، الميزانية، ونسبة الربح المخطط.

استخدمه عندما يتحوّل الاتفاق إلى طلب تنفيذ قابل للفوترة داخل النظام المالي.

**ماذا تتابع فيه**

- العميل والاتفاقية
- تاريخ أمر البيع
- القيمة والميزانية والربح المخطط

:::tip[اربط أمر البيع بالمشروع نفسه لا بمشروع شقيق]
أي أمر بيع على مشروع خاطئ يفسد مقارنة الإيراد بالتكلفة.
:::

## طلبات التغيير

طلب التغيير يوثّق تعديل النطاق بعد اعتماد الخطة الأصلية: بلا أثر، بلا تكلفة، بلا أثر زمني، أو بأثر على التكلفة والزمن.

| النوع الشائع | المعنى |
|---|---|
| بلا أثر | توضيح أو تصحيح لا يغيّر الالتزام |
| تكلفة صفر | تغيير نطاق دون مطالبة مالية |
| بلا أثر زمني | تغيير لا يحرّك تاريخ النهاية |
| أثر تكلفة وزمن | يحتاج اعتمادًا قبل التنفيذ |

الحالات المعتادة: مسودة ثم منشور.

**كيف تستخدمه**

1. سجّل الطلب بمجرد ظهوره من العميل أو من الموقع
2. حدّد النوع والتاريخ
3. لا تبدأ التنفيذ إن كان له أثر مالي أو زمني قبل الاعتماد
4. بعد الاعتماد حدّث الجدول والبنود وخطة الفوترة

:::warning[التنفيذ قبل اعتماد طلب التغيير]
أكثر سبب لخسائر المشروع هو تنفيذ عمل إضافي «مجاملة» ثم اكتشاف أنه غير قابل للفوترة.
:::

## المخرجات

المخرج هو نتيجة ملموسة: وثيقة، تقرير، تسليم فني، أو حزمة عمل يقبلها العميل.

| الحقل | الشرح |
|---|---|
| النوع | فني / وثيقة / تقرير (أو أنواع مؤسستك) |
| الحالة | مخطط / قيد التنفيذ / مكتمل |
| البند | ربط المخرج ببند المشروع |
| بند العمل | ربطه بمهمة أو حزمة في الجدول |
| تاريخ التسليم | متى يُفترض التسليم |
| تاريخ الاعتماد | متى قبله العميل |

**حالات المخرج**

- مخطط
- قيد التنفيذ
- مكتمل

## أفضل الممارسات

:::tip[أغلق حلقة النطاق أسبوعيًا]
راجع أوامر البيع المفتوحة وطلبات التغيير المعلقة والمخرجات المتأخرة في اجتماع واحد قصير. لا تترك طلب تغيير في المسودة أسابيع.
:::
