# نظرة عامة على المشروع

**المشروع** هو سجل التنفيذ في Drixal ERP. كل التزام تعاقدي أو مبادرة داخلية تحتاج تاريخ بداية ونهاية، مديرًا مسؤولًا، عميلًا، نطاقًا، فريقًا، وتكلفة — يُدار كمشروع.

المشروع ليس مجرد اسم وحالة. هو المركز الذي تُعلَّق عليه أوامر البيع، وطلبات التغيير، والمخرجات، ومخطط جانت، والفواتير، والمخاطر، وإثباتات التسليم، ومحاضر الاجتماعات.

## ماذا يفعل المشروع لأعمالك

- يعرّف العمل: الاسم، العميل، المدير، المدة، القيمة، النوع، الحالة
- يربط التنفيذ بالعقد عبر الاتفاقية والبرنامج والمحفظة
- يجمع التقدم المالي والتشغيلي في مؤشرات تُحسب تلقائيًا
- يوفّر إجراءات رسمية لدورة الحياة: نشط، إيقاف مؤقت، استئناف، مكتمل، إنهاء

## نوعان من صفحات المشروع

| الصفحة | متى تستخدمها |
|---|---|
| **العرض القياسي** `/Entities/PMO/Project/{رقم}` | إنشاء مشروع جديد أو التركيز على البيانات الأساسية والحوكمة والإعدادات |
| **عرض 360** `/Entities/PMO/Project/360/{رقم}` | التشغيل اليومي: كل التبويبات، الجدول، الفريق، الماليات، الإجراءات السريعة |

يمكنك التبديل بين العرضين من أعلى الصفحة دون فقدان السجل.

## أنواع المشروع

تُضبط من حقل **النوع** في ترويسة المشروع:

| النوع | الاستخدام المعتاد |
|---|---|
| مشروع بسيط | نطاق محدود، فريق صغير، مدة قصيرة |
| مشروع ضخم | قيمة عالية أو مدة طويلة أو تعدد مواقع |
| مشروع متعدد التخصصات | أكثر من تخصّص فني أو أكثر من مسار عمل |

يمكنك إضافة أنواع أخرى من إعدادات النظام حسب سياسة المؤسسة.

## حالات المشروع

| الحالة | المعنى التشغيلي |
|---|---|
| **نشط** | العمل جارٍ ويمكن تسجيل الساعات وتحديث التقدم |
| **إيقاف مؤقت** | العمل متوقف مؤقتًا مع سبب وإمكانية الاستئناف |
| **دعم** | المشروع في مرحلة دعم بعد التنفيذ |
| **مكتمل** | أُغلق بنجاح عبر إجراء الإكمال |
| **منتهٍ** | أُغلق دون إكمال عبر إجراء الإنهاء مع سبب |

الحالة ليست للزينة: تعتمد عليها التقارير، واعتماد الجداول الزمنية، وصلاحية بعض الإجراءات.

## دورة حياة مبسّطة

1. إنشاء المشروع وربطه بالعميل والمدير والتواريخ
2. تعبئة الحوكمة (اتفاقية / برنامج / محفظة / مدقق المكتب)
3. إضافة البنود والنطاق والجدول وأصحاب المصلحة
4. التنفيذ اليومي: مهام، ساعات، مخاطر، محاضر
5. الفوترة عبر خطة الفوترة وإثباتات التسليم
6. الإكمال أو الإنهاء مع حفظ الدروس المستفادة

## أفضل الممارسات

:::tip[سمِّ المشروع كما يعرفه العميل]
استخدم اسمًا واضحًا بالإنجليزية في حقل الاسم، والاسم العربي في الحقل المخصص. الرقم التسلسلي يُولَّد تلقائيًا.
:::

:::warning[لا تغيّر الحالة يدويًا بدل الإجراءات]
للإيقاف أو الإكمال أو الإنهاء استخدم الأزرار في ترويسة المشروع. هذا يحفظ السياق والتاريخ بدل تغيير شارة فقط.
:::
