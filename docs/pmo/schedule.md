# الجدول الزمني والتقويم

الجدول هو خطة التنفيذ المرئية: ماذا يُعمل، بأي ترتيب، ومن المسؤول، ومتى يبدأ ومتى ينتهي. في Drixal يظهر بوجهين داخل المشروع:

- **التقويم** لرؤية الأيام والاجتماعات والمعالم
- **الجدول الزمني** لمخطط جانت وهيكل تجزئة العمل

**المكان:** عرض 360 ← **التقويم** أو **الجدول الزمني**

يمكنك أيضًا إدارة بنود العمل من السجلات الفرعية للمشروع.

## ماذا يفعل الجدول لأعمالك

- يحوّل نطاق المشروع إلى حزم ومهام قابلة للإسناد
- يُظهر التأخير مقابل الخطة الأساسية (Baseline)
- يربط الساعات والتكلفة الفعلية بالمهمة لا بالمشروع ككتلة واحدة
- يغذّي مؤشرات أداء الجدول (SPI)

## هيكل تجزئة العمل

بند العمل يمكن أن يكون أحد الأنواع التالية:

| النوع | الدور |
|---|---|
| مسار عمل المشروع | مسار كبير (مثل تصميم، توريد، تركيب) |
| حزمة عمل | مجموعة مهام تحت مسار |
| نشاط | خطوة تنفيذ داخل الحزمة |
| مهمة | عمل يومي مسند لشخص |
| مكالمة / اجتماع / زيارة / ملاحظة | أحداث سريعة من الشريط الجانبي |
| مسار عمل (Workflow) | بند مرتبط بمسار اعتماد |

ولكل بند خصائص تخطيط:

- رمز هيكل التجزئة (WBS) مثل 1.2.3
- بند أب وترتيب بين الإخوة
- سابق ولاحق (اعتماديات)
- مسند إلى مستخدم أو مجموعة (دور / فريق / إدارة)
- جهد وتكلفة ومدة مخططين
- تواريخ مخطط، أساسي، فعلي
- حجم المهمة وأولويتها وتعقيدها
- هل هو معلم، وهل هو ورقة شجر، وهل يقبل تسجيل وقت

## حالات بند العمل

| الحالة | المعنى |
|---|---|
| مخطط | لم يبدأ |
| قيد التنفيذ | العمل جارٍ |
| قلق | يحتاج انتباهًا رغم أنه لم يتأخر بعد أو تأخّر جزئيًا |
| متأخر | تجاوز الخطة |
| مكتمل | أُغلق |

## كيف تبني الجدول

1. افتح تبويب **الجدول الزمني**
2. أنشئ مسارات العمل أولًا ثم الحزم ثم المهام
3. أسند كل مهمة لشخص أو مجموعة
4. ضع التواريخ والاعتماديات بالسحب في جانت عند الحاجة
5. ثبّت الخطة الأساسية بعد اعتماد العميل حتى يبقى لديك مرجع للمقارنة
6. حدّث التقدم الفعلي أسبوعيًا على الأقل

الإنشاء السريع من الشريط الجانبي (مهمة، اجتماع، زيارة…) ينشئ بند عمل مربوطًا بالمشروع دون مغادرة 360.

## التقويم

عرض التقويم مناسب لـ:

- اجتماعات العميل
- الزيارات الميدانية
- المعالم ذات التاريخ الواحد
- مراجعة أسبوع العمل القادم مع الفريق

## أفضل الممارسات

:::tip[لا تجعل كل شيء مهمة]
إذا أصبح الجدول مئات المهام الصغيرة بلا حزم، تفقد الإدارة القدرة على القراءة. استخدم 3 إلى 4 مستويات كحد عملي.
:::

:::warning[الخطة الأساسية ليست للتجميل]
إذا حرّكت التواريخ كل أسبوع دون الاحتفاظ بالأساس، يفقد مؤشر الجدول معناه. غيّر الأساس فقط بعد اعتماد رسمي (غالبًا طلب تغيير).
:::

:::note[الساعات تُسجَّل على المهام التي تسمح بذلك]
فعّل «يقبل جدولًا زمنيًا» للمهام التنفيذية فقط، لا لمسار العمل الأب.
:::
