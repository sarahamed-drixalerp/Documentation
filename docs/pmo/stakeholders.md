# أصحاب المصلحة

صاحب المصلحة هو كل من يؤثر في المشروع أو يتأثر به: من العميل، الفريق الداخلي، الاستشاري، إلى الجهة المنظمة. تبويب أصحاب المصلحة يمنع أن يبقى التواصل «في رأس مدير المشروع».

**المكان:** عرض 360 ← **أصحاب المصلحة**

## ماذا يفعل هذا التبويب

- يسجّل الأشخاص والجهات المرتبطة بالمشروع
- يوضّح المسؤولية عبر نموذج RACI مبسّط
- يقيس القوة والاهتمام والدعم والتأثير والمعرفة
- يظهر في بطاقات المشروع كأفاتارات الفريق

## الحقول الأساسية

| الحقل | الشرح |
|---|---|
| التصنيف | نوع صاحب المصلحة (داخلي، عميل، شريك…) |
| جهة الاتصال | ربط بسجل جهة اتصال |
| عضو الفريق | ربط بمستخدم داخلي |
| المسمى الوظيفي | الدور الظاهر للعميل |
| الجوال / البريد | قنوات التواصل |
| مسؤول عن | R — من ينفّذ |
| محاسب عن | A — من يُساءل عن النتيجة |
| يُستشار | C — يُسأل قبل القرار |
| يُبلَّغ | I — يُعلم بعد القرار |
| القوة / الاهتمام / الدعم / التأثير / المعرفة | تقييم نسبي لتوجيه التواصل |

يمكن ربط صاحب المصلحة بصفقة أيضًا إذا نشأ المشروع من فرصة بيع.

## كيف تضيف صاحب مصلحة

1. افتح تبويب **أصحاب المصلحة**
2. أضف سجلًا
3. اربط مستخدمًا داخليًا أو جهة اتصال خارجية
4. حدّد RACI بوضوح: تجنّب أن يكون الجميع «مسؤولًا»
5. ضع تقييم القوة والاهتمام حتى تعرف من يحتاج متابعة لصيقة

## من يجب أن يظهر دائمًا

- مدير المشروع
- مدير الحساب
- ممثل العميل المعتمد للقبول
- مدقق مكتب إدارة المشاريع إن وُجد
- قادة المسارات الفنية الرئيسية

## أفضل الممارسات

:::tip[صاحب مصلحة بلا قناة تواصل = مخاطر]
إذا لم يُسجَّل جوال أو بريد لممثل العميل، ستتأخر الاعتمادات عند كل مخرج.
:::

:::warning[لا تخلط بين «مسؤول» و«محاسب»]
المسؤول ينفّذ. المحاسب يُساءل. إذا أصبح شخص واحد A وR على كل شيء، فالمصفوفة لم تُفد.
:::
