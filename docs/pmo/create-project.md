# إنشاء مشروع جديد

إنشاء المشروع هو الخطوة التي تحوّل الاتفاق أو المبادرة إلى سجل يمكن للفريق العمل عليه. بعد الحفظ يظهر رقم المشروع، ويمكن فتح مساحة 360 وإضافة النطاق والجدول.

## كيف تنشئ مشروعًا

1. من **المشاريع** اضغط **إنشاء مشروع جديد**
2. تُفتح صفحة العرض القياسي بعنوان «إنشاء مشروع جديد»
3. عبّئ الحقول الإلزامية في الترويسة وفي قسم المعلومات العامة
4. أضف الحوكمة والإعدادات إن كانت معروفة الآن
5. اضغط **حفظ التغييرات**
6. بعد الحفظ يمكنك **ترحيل** المشروع ليبقى قابلاً للتعديل مع تثبيت التحديث الظاهر في الصفحة

:::tip[يمكن الإنشاء من الاتفاقية]
إذا وُجدت اتفاقية مع العميل، اربطها أثناء الإنشاء. بعض المؤسسات تبدأ من الاتفاقية ثم تحوّلها إلى مشروع حتى يبقى العقد والتنفيذ متصلين.
:::

## الحقول الإلزامية

لن يُحفظ المشروع بدون هذه الحقول:

| الحقل | لماذا هو إلزامي |
|---|---|
| **الاسم (بالإنجليزية)** | الاسم التشغيلي للسجل والبحث |
| **مدير المشروع** | المسؤولية التشغيلية |
| **النوع** | تصنيف المشروع للتقارير |
| **الحالة** | نقطة البداية في دورة الحياة (غالبًا نشط) |
| **مستوى السرية** | من يمكنه رؤية السجل |
| **تاريخ البداية** | بداية الخطة |
| **تاريخ النهاية** | يجب أن يكون في يوم البداية أو بعده |

حقل **الاسم بالعربية** مستحسن للواجهات العربية والتقارير المحلية، لكنه ليس إلزاميًا.

## معلومات يُفضَّل إدخالها من اليوم الأول

| الحقل | الفائدة |
|---|---|
| العميل | يربط الفوترة والتقارير التجارية |
| مدير الحساب | جسر المبيعات/الحسابات |
| عدد الفريق | مؤشر تخطيط أولي |
| القيمة والعملة | أساس الميزانية والفوترة |
| الوصف باللغتين | سياق للفريق الجديد دون سؤال مدير المشروع |
| الاتفاقية / البرنامج / المحفظة | التقارير الإدارية |
| مدقق مكتب إدارة المشاريع | مسار الحوكمة |

## الحفظ والترحيل

| الزر | ماذا يفعل |
|---|---|
| **حفظ التغييرات** | يخزّن البيانات الحالية |
| **ترحيل** | يحفظ ثم يحدّث المشروع بالبيانات الظاهرة، ويُبقي السجل قابلاً للتعديل |

عند الترحيل يظهر حوار يوضح أن:

- التعديلات تُحفظ
- المشروع يُحدَّث بالبيانات الظاهرة
- المشروع يبقى متاحًا للتعديل بعد الترحيل

:::note[الترحيل هنا ليس إغلاقًا محاسبيًا]
ترحيل المشروع يثبّت التحديث الحالي ولا يمنع التعديل لاحقًا. لإغلاق العمل استخدم إكمال أو إنهاء.
:::

## أخطاء شائعة عند الإنشاء

- تاريخ نهاية أقدم من تاريخ البداية
- ترك مدير المشروع فارغًا
- إنشاء المشروع باسم داخلي لا يعرفه العميل ثم البحث عنه لاحقًا بلا نتيجة
- نسيان مستوى السرية فيظهر خطأ «هذا الحقل مطلوب»

## بعد الحفظ مباشرة

1. راجع الرقم التسلسلي في الترويسة
2. انتقل إلى [عرض 360](/docs/pmo/workspace-360)
3. أضف [بنود المشروع](/docs/pmo/line-items) إن وُجد نطاق سعري
4. أضف [أصحاب المصلحة](/docs/pmo/stakeholders)
5. ابنِ [الجدول الزمني](/docs/pmo/schedule)

## أفضل الممارسات

:::tip[أنشئ المشروع قبل أن يبدأ الفريق تسجيل الساعات]
أي ساعة تُسجَّل خارج مشروع معتمد تضيع من التكلفة والتقدم واعتماد الجدول الزمني.
:::

:::warning[لا تستخدم مشروعًا واحدًا لعدة عملاء]
كل عميل وكل التزام تعاقدي يستحق سجل مشروع مستقل حتى لو تشابه الفريق.
:::
