# مساحة العمل 360

عرض 360 هو غرفة عمليات المشروع. بدل التنقل بين شاشات متفرقة، يعمل مدير المشروع والفريق من سجل واحد فيه التفاصيل، النطاق، الجدول، الفريق، الماليات، المخاطر، التسليم، والحوكمة.

**المسار:** من قائمة المشاريع اضغط أيقونة المخطط، أو من العرض القياسي بدّل إلى عرض 360.

## ماذا يقدّم عرض 360

- ترويسة ثابتة بالاسم والرقم والحالة والنوع والإجراءات
- تبويبات لكل مجال عمل
- شريط جانبي لإنشاء نشاط سريع ومشاهدة الأنشطة والمرفقات والسجل والتحليلات
- مؤشرات مالية مختصرة: القيمة، الميزانية، الربح المخطط
- الخط الزمني للبداية والنهاية عندما تكون التواريخ معبأة

## التبويبات

| التبويب | ماذا تجد فيه |
|---|---|
| **التفاصيل** | المعلومات العامة والحوكمة والإعدادات |
| **بنود المشروع** | المنتجات والكميات والمبالغ ونسب الإنجاز |
| **النطاق** | أوامر البيع، طلبات التغيير، المخرجات |
| **التقويم** | عرض تقويمي لخطة العمل |
| **الجدول الزمني** | مخطط جانت وهيكل تجزئة العمل |
| **أصحاب المصلحة** | الفريق والعملاء ومصفوفة المسؤوليات |
| **الوقت** | المراحل والمعالم |
| **الماليات** | خطة الفوترة وفواتير العملاء والموردين وأوامر الشراء |
| **المخاطر والمشكلات** | المخاطر الاستباقية والمشكلات القائمة |
| **إثباتات التسليم** | إشعارات التسليم، شهادات الإنجاز، كشف الفريق |
| **مركز الإدارة** | الافتراضات، القيود، الخطط، المحاضر، الدروس |

## الشريط الجانبي

### إنشاء سريع

| الزر | الاستخدام |
|---|---|
| ملاحظات | توثيق قرار أو معلومة سريعة |
| مكالمات | تسجيل مكالمة مرتبطة بالمشروع |
| مهام | مهمة تنفيذية لعضو فريق |
| اجتماع | اجتماع بجدول أعمال لاحقًا في المحاضر |
| زيارة | زيارة موقع أو عميل |

هذه العناصر تُنشأ كبنود عمل مرتبطة بالمشروع، وتظهر في الجدول عند الحاجة.

### لوحات السياق

- **الأنشطة** — الحركة اليومية على السجل
- **المرفقات** — ملفات المشروع
- **السجلات** — أثر من غيّر ماذا
- **التحليلات** — مؤشرات مالية وجدول زمني ومؤشرا SPI و CPI

زر **العودة إلى التفاصيل** يُخرجك من لوحة السياق إلى التبويب الحالي.

## الفرق بين العرض القياسي وعرض 360

| | قياسي | 360 |
|---|---|---|
| الإنشاء | نعم | بعد وجود السجل |
| التركيز | البيانات الأساسية | التشغيل الكامل |
| التبويبات | لا | نعم |
| الإجراءات الرسمية | نعم | نعم |
| الجدول والماليات | لا | نعم |

## أفضل الممارسات

:::tip[اجعل 360 هو الشاشة الافتراضية لمدير المشروع]
بعد الإنشاء، أدِر العمل من 360. استخدم العرض القياسي للتدقيق السريع على الحقول فقط.
:::

:::note[التبويبات العريضة تُمرَّر أفقيًا]
إذا لم يظهر تبويب «مركز الإدارة» على الشاشات الصغيرة، مرّر شريط التبويبات.
:::
