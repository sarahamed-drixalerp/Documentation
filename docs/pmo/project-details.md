# تفاصيل المشروع وحقوله

نموذج التفاصيل هو قلب البيانات الأساسية. يظهر في العرض القياسي بالكامل، وفي تبويب **التفاصيل** داخل عرض 360. الحقول مقسّمة إلى ثلاثة أقسام قابلة للطي.

## 1) المعلومات العامة

البيانات التي يعرّف بها الجميع المشروع.

| الحقل | الشرح |
|---|---|
| الاسم | الاسم التشغيلي بالإنجليزية |
| الاسم بالعربية | يظهر في الواجهة العربية والتقارير |
| مدير الحساب | المسؤول التجاري عن علاقة العميل |
| مدير المشروع | المسؤول التشغيلي — حقل إلزامي |
| العميل | الجهة المستفيدة |
| عدد الفريق | حجم الفريق المخطط أو الحالي |
| تاريخ البداية / النهاية | مدة المشروع — إلزاميان، والنهاية لا تسبق البداية |
| القيمة المحتسبة | قيمة المشروع بالعملة المختارة |
| العملة | عملة المشروع. عرض المبالغ يتبع عملة السجل |
| الوصف / الوصف بالعربية | سياق العمل بحد أقصى 10,000 حرف |

في عرض 360 يظهر عدّاد أحرف الوصف حتى لا تتجاوز الحد.

## 2) حوكمة المشروع

تربط المشروع بالإطار الإداري والتعاقدي.

| الحقل | الشرح |
|---|---|
| الاتفاقية | العقد أو الإطار مع العميل |
| البرنامج | البرنامج الأب إن وُجد |
| المحفظة | المحفظة الاستثمارية أو الاستراتيجية |
| مدقق مكتب إدارة المشاريع | من يشرف على الالتزام بإجراءات المكتب |

:::tip[عبّئ الحوكمة ولو لاحقًا في الأسبوع الأول]
التقارير الإدارية (حسب المحفظة أو البرنامج) تضعف إذا بقيت هذه الحقول فارغة في المشاريع الكبرى.
:::

## 3) إعدادات المشروع

تتحكّم في تسجيل الوقت والتقدم والتكلفة المتبقية.

| الحقل | الشرح |
|---|---|
| زيادة الساعات | أصغر وحدة لتسجيل الوقت (الافتراضي 1 ساعة) |
| الحد الأقصى للساعات العادية | سقف اليوم العادي (الافتراضي 8) |
| الحد الأقصى لساعات العمل الإضافي | سقف الإضافي (الافتراضي 4) |
| نسبة الإنجاز | تقدم المشروع. يُحدَّث مع التنفيذ |
| التكلفة المتبقية للإتمام | تقدير ما تبقّى من تكلفة حتى الإغلاق |

هذه الإعدادات تؤثر على الجداول الزمنية واعتماد الساعات ومؤشرات التكلفة. لا تغيّرها بعد بدء التسجيل إلا بقرار واضح من مدير المشروع.

## حقول الترويسة (خارج النموذج)

من أعلى الصفحة، دون النزول للنموذج:

- **الصورة / الأفاتار**
- **تعديل العنوان** مباشرة
- **تفعيل / إلغاء تفعيل** المشروع
- **مستوى السرية**
- **الحالة** و**النوع**
- أزرار الإجراءات: إنهاء، إيقاف، استئناف، إكمال، اعتماد الجدول الزمني

## كيف تحفظ

1. عدّل الحقول المطلوبة
2. **حفظ التغييرات** لتخزين المسودة المحدّثة
3. **ترحيل** إذا أردت تثبيت التحديث الظاهر مع الإبقاء على قابلية التعديل

إذا ظهر خطأ تحقق، تنتقل الشاشة إلى أول حقل ناقص. أكمله ثم احفظ مرة أخرى.

## أفضل الممارسات

:::tip[اجعل الوصف مفيدًا لشخص جديد]
اكتب هدف المشروع، موقع العمل، وما هو خارج النطاق في سطور قصيرة. لا تترك الوصف نسخة من الاسم.
:::

:::warning[العملة ليست للعرض فقط]
المبالغ تُحفظ بعملة المشروع. تغيير العملة لاحقًا يربك مقارنة الميزانية بالفواتير. ثبّتها من اليوم الأول.
:::
