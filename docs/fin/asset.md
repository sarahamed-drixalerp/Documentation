# الأصول

**الأصل (Asset)** أصل ثابت بإعداد شراء واستهلاك. الحفظ يثبّت البيانات؛ **لا يوجد زر ترحيل** على شاشة الأصل نفسها.

## ماذا يفعل الأصل لأعمالك

- يسجّل أصلًا بالاسم والحساب الرئيسي وتاريخ بدء الخدمة
- يضبط سعر الشراء وحساب النقد ومعدل الضريبة اختياريًا
- يعرّف الاستهلاك التلقائي (نسبة أو قيمة) وتكراره وتاريخ البدء

**المسار:** القائمة الجانبية ← المالية ← الأصول  
**الصفحات:** `/Entities/FIN/Asset` · `/new` · `/{رقم}`

## قائمة الأصول

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الاسم، الرقم التسلسلي، تاريخ الشراء، سعر الشراء، قيمة الخردة، الإجراءات |
| **الفلاتر** | بحث (اسم/تسلسل/رقم)، الحالة، النوع، تاريخ الشراء |
| **العروض** | قائمة أو بطاقات |

## إنشاء أصل

1. أنشئ أصلًا جديدًا
2. أكمل **المعلومات العامة** و**تفاصيل الشراء** و**استهلاك الأصل**
3. عيّن السرية والنوع والحالة في الترويسة ثم **حفظ التغييرات**

### المعلومات العامة

| الحقل | ملاحظات |
|---|---|
| **الاسم** | إلزامي |
| **الحساب الرئيسي** | إلزامي |
| **تاريخ بدء الخدمة** | إلزامي |
| **العمر الإنتاجي** | اختياري (+ يوم/شهر/سنة) |
| **الكمية** | اختيارية |

### تفاصيل الشراء

| الحقل | ملاحظات |
|---|---|
| **سعر الشراء + العملة** | إلزامي |
| **تاريخ الشراء** | إلزامي |
| **حساب النقد** | إلزامي |
| **معدل الضريبة** | اختياري |

### استهلاك الأصل

| الحقل | ملاحظات |
|---|---|
| **نوع الاستهلاك** | نسبة أو قيمة — إلزامي |
| **تكرار الاستهلاك التلقائي** | عدد + يوم/شهر/سنة — إلزامي |
| **النسبة أو القيمة** | حسب النوع — إلزامي |
| **تاريخ بدء الاستهلاك التلقائي** | إلزامي |
| **قيمة الخردة / تاريخ الانتهاء** | اختياري؛ الانتهاء ≥ البداية |
| **حسابات مجمع الاستهلاك / مصروف الاستهلاك** | اختيارية |

:::note[لا ترحيل على الأصل]
شاشة الأصل للحفظ والإعداد فقط. حركات الأستاذ تتم عبر مسارات المالية الأخرى (مثل القيود) حسب السياسة.
:::

## أفضل الممارسات

:::tip[أكمل الاستهلاك قبل الاعتماد التشغيلي]
اضبط النوع والتكرار وتاريخ البدء والحسابات المرتبطة قبل استخدام الأصل في التقارير التشغيلية.
:::
