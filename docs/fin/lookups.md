# البيانات المرجعية

مراجع تجارية في المالية تُختار في المستندات والعقود: **الإنكوترمز**، **شروط الدفع** (مع بنود نسب/أيام)، و**طرق الشحن**.

## Incoterm

شروط التجارة الدولية (Incoterms).

**الصفحة:** `/Entities/FIN/Incoterm` (قائمة + درج)

| الحقل | ملاحظات |
|---|---|
| **name / nameAr** | في نموذج التفاصيل غالبًا مطلوبان |
| **الوصف EN/AR** | اختياري |
| **code** | اختياري في الدرج |
| **Active** | مفتاح في القائمة |

تصفية بالبحث على الاسم.

## PaymentTerm

جدول شروط دفع مع بنود نسب وأيام استحقاق.

**الصفحات:** `/Entities/FIN/PaymentTerm` · `/new` · `/{رقم}`

| الحقل | ملاحظات |
|---|---|
| **name / nameAr** | إلزاميان |
| **الأوصاف** | اختيارية |
| **السرية / نشط** | في الترويسة |

### بنود شرط الدفع (PaymentTermLine)

قسم مضمّن: **إضافة دفعة**. الأعمدة: النسبة (%)، عدد الأيام، الإجراءات.

| القاعدة | التفصيل |
|---|---|
| احفظ الشرط أولًا | لا بنود قبل حفظ شرط الدفع |
| الأيام | 0–999 (0 = دفعة مقدّمة / Advance) |
| النسبة | > 0 و ≤ 100؛ مجموع النسب ≤ 100% |
| تحرير بند واحد | لا تفتح بندًا آخر أثناء وضع التحرير |

يوجد كيان مستقل `/Entities/FIN/PaymentTermLine`؛ الاستخدام اليومي من داخل شرط الدفع.

## معدلات الضريبة

عنصر الشريط الجانبي للمالية يشير إلى `/Entities/FIN/TaxRate` دون صفحة مستضافة هناك. استخدم [معدلات الضريبة في الكتالوج](/docs/cat/tax-rate).
