# التحويلات

**التحويل (Transfer)** حركة نقدية بين حسابات بنكية وخزائن (`TreasuryTransaction`): من/إلى، مبلغ، تاريخ، ثم **ترحيل** لتثبيت الحركة.

## ماذا يفعل التحويل لأعمالك

- ينقل نقدًا بين بنك↔بنك، خزينة↔خزينة، خزينة↔بنك، بنك↔خزينة
- يعرض الرصيد الحالي والرصيد بعد التحويل والمبلغ المستلم عند اختلاف العملة
- يثبّت الحركة عبر **ترحيل** ويمنع التعديل والحذف بعدها

**المسار:** القائمة الجانبية ← المالية ← التحويلات  
**الصفحات:** `/Entities/FIN/Transfer` · `/{رقم}`

## قائمة التحويلات

### الأعمدة

الاسم (مع الرقم)، من/إلى، تاريخ الحركة، المبلغ، النوع، الحالة، الإجراءات.

### التصفية

بحث في الاسم والرقم؛ الحالة.

عرض قائمة أو بطاقات؛ ملخص بعدد التحويلات ومجموع مبلغ الأساس.

:::danger[لا تحذف تحويلًا مرحَّلًا]
الحذف معطّل للتحويلات المرحَّلة.
:::

## إنشاء تحويل وترحيله

1. أنشئ تحويلًا جديدًا
2. عيّن **الاسم** و**تاريخ التحويل** و**نوع التحويل** (أربع بطاقات اتجاه)
3. اختر حساب **من** و**إلى** والمبلغ (> 0)
4. عند اختلاف العملات عيّن سعر الصرف؛ راجع المبلغ المستلم والرصيد بعد
5. عيّن السرية والنوع والحالة، ثم **حفظ التغييرات** ثم **ترحيل**

### الحقول الأساسية

| الحقل | ملاحظات |
|---|---|
| **الاسم** | إلزامي |
| **تاريخ التحويل** | إلزامي |
| **نوع التحويل** | بنك→بنك، خزينة→خزينة، خزينة→بنك، بنك→خزينة |
| **من / إلى** | حسب النوع؛ عملة البنك مقفلة على الحساب |
| **المبلغ** | إلزامي وأكبر من صفر |
| **سعر الصرف** | عند اختلاف العملات |
| **السرية** | إلزامية في الترويسة |

### دورة الحياة

| الحالة | المعنى |
|---|---|
| **مسودة / محفوظ** | قابل للتعديل والحفظ والترحيل |
| **مرحَّل (Posted)** | للقراءة فقط؛ لا حفظ ولا ترحيل ولا حذف |

الترحيل يحفظ أولًا ثم يثبّت الحالة. عند فشل الترحيل بعد الحفظ يبقى السجل مسودة.

## أخطاء شائعة

- رصيد غير كافٍ
- حساب بلا عملة أو نوع تحويل غير محدد
- حقول إلزامية فارغة قبل الترحيل

## أفضل الممارسات

:::tip[راجع الرصيد بعد قبل الترحيل]
تحقق من الرصيد الحالي والرصيد بعد والمبلغ المستلم عند التحويل بين عملات مختلفة.
:::

:::warning[الترحيل إغلاق للحركة النقدية]
بعد الترحيل لا تعدّل التحويل. صحّح بتحويل عكسي جديد حسب سياسة المالية.
:::
