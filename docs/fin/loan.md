# القروض

**القرض (Loan)** سلفة/قرض موظف بنفس نمط [العهد](/docs/fin/custody): مبلغ، موظف، مصدر دفع، **نشر**، ثم تسويات وديون معدومة على المتبقي.

## ماذا يفعل القرض لأعمالك

- يسجّل قرض موظف بمبلغ وعملة وتاريخ
- يربط الدفع ببنك أو خزينة
- يتتبع المسدَّد والديون المعدومة والمتبقي بعد النشر

**المسار:** القائمة الجانبية ← المالية ← القروض  
**الصفحات:** `/Entities/FIN/Loan` · `/new` · `/{رقم}`

## قائمة القروض

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الموظف، المبلغ، المتبقي، بنك/خزينة، التاريخ، الحالة، الإجراءات |
| **الفلاتر** | بحث، الحالة، الموظف، التاريخ |

## إنشاء قرض ونشره

1. أنشئ قرضًا جديدًا
2. عيّن **المبلغ** والعملة و**التاريخ** و**الموظف**
3. اختر **مصدر الدفع** ثم الحساب البنكي أو الخزينة
4. احفظ ثم **انشر** قبل أي تسوية

### الحقول الأساسية

| الحقل | ملاحظات |
|---|---|
| **المبلغ + العملة** | إلزامي |
| **التاريخ** | إلزامي |
| **الموظف** | إلزامي |
| **مصدر الدفع** | خزينة أو بنك ثم الحساب/الخزينة |
| **تاريخ الاستحقاق / الوصف** | اختياري |

### التبويبات

**التفاصيل** | **التسويات** | **المرفقات**

## التسويات والديون المعدومة

نفس قواعد العهد: انشر أولًا؛ المبلغ > 0 ولا يتجاوز المتبقي؛ أنواع **تسوية** و**ديون معدومة**.

:::danger[انشر قبل التسوية]
لا تسوية على مسودة. القرض المسدَّد أو بلا متبقي يرفض تسويات جديدة.
:::

## أفضل الممارسات

:::tip[ميّز القرض عن العهدة في السياسة]
الواجهة متماثلة؛ استخدم التسمية والسياسة الداخلية للتمييز المحاسبي بين العهد والقرض.
:::
