# مراكز التكلفة والربح

**مركز التكلفة (CostCenter)** و**مركز الربح (ProfitCenter)** أبعاد محاسبية هرمية تُربط بقيود اليومية والحسابات عند اشتراط الأبعاد. الواجهة مشتركة: شجرة + قائمة + مساحة عمل للتفاصيل والمعاملات.

## ماذا تفعل المراكز لأعمالك

- تبني هيكل أبعاد للتكلفة أو الربح (أب / ترحيل)
- تضبط العملات المسموحة لكل مركز
- تعرض أرصدة ومعاملات القيود المرحَّلة المرتبطة بالمركز
- تُستخدم كأبعاد إلزامية عندما يشترط الحساب مراكز تكلفة/ربح

**المسار:** القائمة الجانبية ← المالية ← مراكز التكلفة / مراكز الربح  
**الصفحات:** `/Entities/FIN/CostCenter` · `/{رقم}` و `/Entities/FIN/ProfitCenter` · `/{رقم}`

## مساحة العمل

| العرض | الاستخدام |
|---|---|
| **شجرة** (افتراضي) | إضافة جذر/ابن، تعديل الهيكل، فتح مساحة العمل |
| **قائمة** | بحث جدولي بالاسم والنوع والحالة |

### مساحة السجل

تبويبان بعد الحفظ: **التفاصيل** | **المعاملات**. شريط أرصدة بالأساس وأسعار الصرف عند التوفر.

## إنشاء مركز أو تعديله

الطريقة المفضلة: من الشجرة **مركز جديد (جذر)** أو إضافة ابن تحت أب محدد.

| الحقل / الإعداد | ملاحظات |
|---|---|
| **الاسم** | إلزامي |
| **الاسم بالعربية** | مستحسن |
| **الوصف** (EN/AR) | اختياري |
| **أب** | عند الإنشاء تحت أب؛ يُقفل بعد الحفظ |
| **رمز المركز** | يُولَّد من النظام بعد الحفظ |
| **أب؟ / ترحيل؟** | مفاتيح الهيكل |
| **كل العملات؟** | وإلا يجب اختيار عملات واحدة على الأقل |

:::warning[أب + ترحيل معًا]
الجمع قد يظهر تحذيرًا. اتبع سياسة المحاسبة قبل الحفظ.
:::

:::danger[لا تحذف مركزًا له أبناء]
الحذف مرفوض عند وجود أبناء. احذف الأبناء أولًا أو أعد هيكلة الشجرة.
:::

## أفضل الممارسات

:::tip[ابنِ الأبعاد قبل القيود الكبيرة]
عند اشتراط الحساب لمراكز تكلفة/ربح، جهّز الشجرة والعملات قبل إدخال قيود يومية كثيرة.
:::
