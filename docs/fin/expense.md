# المصروفات

**المصروف (Expense)** سجل تشغيلي لمصروف بمبلغ وتاريخ ورقم، مع خزينة ومورد وحسابات اختيارية. يُثبَّت عبر **نشر (Publish)** من المسودة إلى مقدَّم/مقفل — وليس ترحيل دفتر أستاذ كامل مثل القيود.

## ماذا يفعل المصروف لأعمالك

- يسجّل مصروفًا برقم خارجي ومبلغ وعملة وتاريخ
- يربط اختياريًا بخزينة ومورد وحساب/حساب فرعي وضرائب
- ينشر المسودة لتقفل التعديل الحر حسب قواعد الحالة

**المسار:** القائمة الجانبية ← المالية ← المصروفات  
**الصفحات:** `/Entities/FIN/Expense` · `/new` · `/{رقم}`

## قائمة المصروفات

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | رقم المصروف، الفئة، المبلغ، التاريخ، الخزينة، المورد، الحالة، الإجراءات |
| **الفلاتر** | بحث، الحالة، الفئة، الخزينة، المورد، التاريخ |

## إنشاء مصروف ونشره

1. أنشئ مصروفًا جديدًا
2. عيّن **المبلغ** والعملة و**رقم المصروف** و**التاريخ**
3. أكمل السرية ونوع الكيان؛ أضف خزينة/مورد/حسابات/ضرائب عند الحاجة
4. **حفظ التغييرات** ثم **نشر** (متاح للمسودة)

### الحقول الأساسية

| الحقل | ملاحظات |
|---|---|
| **المبلغ + العملة** | إلزامي |
| **رقم المصروف** | إلزامي (مرجع خارجي) |
| **التاريخ** | إلزامي |
| **السرية / النوع** | إلزاميان في الترويسة |
| **الخزينة، الضرائب، الحساب، المورد** | اختيارية |

### التبويبات

**التفاصيل** | **المرفقات**

### دورة الحياة

| الخطوة | السلوك |
|---|---|
| مسودة | حفظ وتعديل ونشر |
| **Publish** | يحفظ ويغيّر الحالة ويقفل حسب حوار النشر |

:::warning[النشر ليس ترحيل قيد]
النشر يقفل مسار المصروف التشغيلي. ترحيل الأستاذ يتم عبر [القيود اليومية](/docs/fin/journal) عند الحاجة حسب سياسة المالية.
:::

## أفضل الممارسات

:::tip[أكمل الرقم والتاريخ قبل النشر]
تأكد من رقم المصروف والمبلغ والعملة قبل النشر حتى لا تُقفل بيانات ناقصة.
:::
