# العهد

**العهدة (Custody)** سلفة موظف بمبلغ وتاريخ ومصدر دفع (بنك أو خزينة). بعد **النشر** يمكن تسجيل تسويات وديون معدومة حتى يُصفَّر المتبقي.

## ماذا تفعل العهدة لأعمالك

- تصرف سلفة لموظف بمبلغ وعملة وتاريخ استحقاق اختياري
- تربط الدفع بحساب بنكي أو خزينة
- تتبع المسدَّد والديون المعدومة والمتبقي
- تقفل الإنشاء الحر عبر **نشر** قبل التسويات

**المسار:** القائمة الجانبية ← المالية ← العهد  
**الصفحات:** `/Entities/FIN/Custody` · `/new` · `/{رقم}`

## قائمة العهد

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الموظف، المبلغ، المتبقي، بنك/خزينة، التاريخ، الحالة، الإجراءات |
| **الفلاتر** | بحث، الحالة، الموظف، التاريخ |

## إنشاء عهدة ونشرها

1. أنشئ عهدة جديدة
2. عيّن **المبلغ** والعملة و**التاريخ** و**الموظف**
3. اختر **مصدر الدفع** (خزينة أو بنك) ثم الخزينة أو الحساب البنكي
4. أضف تاريخ الاستحقاق والوصف عند الحاجة، ثم احفظ و**انشر**

### الحقول الأساسية

| الحقل | ملاحظات |
|---|---|
| **المبلغ + العملة** | إلزامي |
| **التاريخ** | إلزامي (تاريخ الإصدار) |
| **الموظف** | إلزامي |
| **مصدر الدفع** | خزينة أو بنك، ثم الحساب/الخزينة المطابق |
| **تاريخ الاستحقاق / الوصف** | اختياري |

### التبويبات

**التفاصيل** | **التسويات** | **المرفقات**

ملخص: المبلغ / المسدَّد / الديون المعدومة / المتبقي.

## التسويات والديون المعدومة

متاحة بعد النشر وعند وجود متبقي:

| الإجراء | السلوك |
|---|---|
| **إضافة تسوية** | مبلغ (+ تعليق اختياري)؛ لا يتجاوز المتبقي |
| **ديون معدومة** | مبلغ مع تحذير شطب |

جدول التسويات: رقم التسوية، النوع (تسوية | ديون معدومة)، المبلغ، التاريخ، تعليق/ملاحظة.

:::danger[انشر قبل التسوية]
لا يمكن إضافة تسوية قبل نشر العهدة. العهدة المسدَّدة بالكامل أو بلا متبقي ترفض تسويات جديدة.
:::

## أفضل الممارسات

:::tip[اختر مصدر الدفع الصحيح أولًا]
حدد بنك أو خزينة قبل الحساب حتى تظهر الحسابات الصحيحة وتتجنب أخطاء الرصيد.
:::
