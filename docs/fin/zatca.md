# الفوترة الإلكترونية ZATCA

صفحة **Zatca** مساحة إعداد الفوترة الإلكترونية السعودية للمستأجر: تبويب **الإعداد** ثم **بدء الربط (Onboarding)** للجهاز ورمز OTP.

## ماذا تفعل الصفحة لأعمالك

- تحفظ بيانات التسجيل القانوني والعنوان وبيئة ZATCA وتفعيلها
- تبدأ ربط الجهاز بعد حفظ الإعداد (CSR ومراحل الحالة)
- تتطلب رمز OTP من ست أرقام من بوابة ZATCA

**المسار:** القائمة الجانبية ← المالية ← ZATCA / الفوترة الإلكترونية  
**الصفحة:** `/Entities/FIN/Zatca`

## تبويب الإعداد (Configuration)

### التسجيل

| الحقل | ملاحظات |
|---|---|
| **TenantId** | للقراءة فقط |
| **الرقم الضريبي (VAT)** | إلزامي — 15 رقمًا بالصيغة المعتمدة (يبدأ وينتهي بـ 3) |
| **الاسم القانوني** | إلزامي |
| **السجل التجاري / الفئة / الاسم القانوني AR** | اختيارية |

### العنوان

إلزامي: اسم الشارع، رقم المبنى، المدينة، الرمز البريدي، رمز الدولة. الحي اختياري.

### الإعدادات

| الحقل | ملاحظات |
|---|---|
| **البيئة** | Simulation أو Production — إلزامي |
| **مفعّل؟** | إلزامي |

احفظ الإعداد قبل الربط. بدون مستأجر تظهر رسالة نقص المستأجر.

## تبويب بدء الربط (Onboarding)

يتطلب إعدادًا محفوظًا أولًا.

### الجهاز

إلزامي: اسم الجهاز، الاسم الشائع (CN)، الرقم التسلسلي، الوحدة التنظيمية، نوع الفاتورة (`1100` / `1000` / `0100`)، الموقع، الصناعة.

### OTP

رمز من **6 أرقام** ثم **بدء الربط** مع تأكيد.

حالات شائعة: لم يبدأ، تم توليد CSR، قيد الانتظار، نجح، مُستلم، فشل — مع شريط اكتمال عند النجاح.

:::warning[الإعداد قبل الربط]
لا تبدأ Onboarding قبل حفظ الإعداد. اختر Simulation للتجربة قبل Production.
:::

## أفضل الممارسات

:::tip[جهّز الرقم الضريبي والعنوان القانوني بدقة]
أخطاء الـ VAT أو العنوان تمنع الربط. راجع الصيغة قبل الحفظ.
:::
