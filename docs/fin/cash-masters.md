# المراجع النقدية

**الخزينة (Treasury)** و**البنك (Bank)** و**الحساب البنكي (BankAccount)** مراجع رئيسية للنقد في المالية. تُدار من قوائم بدرج إنشاء/تعديل، وتُستخدم في التحويلات والعهد والقروض والمصروفات.

## الخزينة

مساحة نقدية داخلية (درج نقدي / صندوق).

**الصفحة:** `/Entities/FIN/Treasury`

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الاسم EN/AR، الوصف EN/AR، نشط؟، الإجراءات |
| **التصفية** | بحث بالاسم |
| **إلزامي في الدرج** | نوع الكيان، حالة الكيان |
| **اختياري** | الاسم EN/AR، الوصف EN/AR، الرصيد (≥ 0)، السرية |

## البنك

سجل بنك (مؤسسة مالية).

**الصفحة:** `/Entities/FIN/Bank`

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الاسم EN/AR، الدولة، الوصف EN/AR، نشط؟، الإجراءات |
| **التصفية** | بحث بالاسم |
| **الحقول** | الاسم EN/AR، الوصف EN/AR، الدولة (اختيارية في التحقق) |

مفتاح **نشط؟** يُحفظ عبر التعديل. الحذف يطلب تأكيدًا ولا يمكن التراجع عنه.

## الحساب البنكي

حساب مرتبط ببنك مع عملة وIBAN ورصيد.

**الصفحة:** `/Entities/FIN/BankAccount`

| المنطقة | المحتوى |
|---|---|
| **الأعمدة** | الاسم EN/AR، البنك، العملة، IBAN، الرصيد، الوصف، نشط؟، الإجراءات |
| **التصفية** | بحث بالاسم |
| **إلزامي في الدرج** | نوع الكيان، حالة الكيان |
| **اختياري** | الأسماء والأوصاف، البنك، العملة، العميل، المورد، أمر شراء، IBAN، الرصيد |

## كيف تُستخدم في العمليات

| العملية | الاستخدام |
|---|---|
| [التحويلات](/docs/fin/transfer) | من/إلى بنك أو خزينة حسب نوع التحويل |
| [العهد](/docs/fin/custody) / [القروض](/docs/fin/loan) | مصدر الدفع: بنك أو خزينة ثم الحساب/الخزينة |
| [المصروفات](/docs/fin/expense) | خزينة اختيارية على المصروف |

## أفضل الممارسات

:::tip[أنشئ البنوك والحسابات قبل التحويلات]
جهّز الخزائن والحسابات البنكية والعملات قبل تسجيل تحويلات أو عهد كبيرة.
:::

:::note[واجهات درج]
الخزينة والبنك والحساب البنكي قوائم + درج؛ لا توجد صفحة تفاصيل متعددة التبويبات مثل القيود.
:::
