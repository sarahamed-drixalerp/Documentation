# الحضور والانصراف

شاشة **الحضور** لتسجيل دخولك وخروجك اليومي ومتابعة سجل أيامك. الساعة تعمل لحظيًا، والزر الدائري يسجّل العملية التالية (حضور أو انصراف) حسب حالتك الحالية.

**المسار:** `/app/Attendance`

## ماذا تفعل هذه الشاشة

- تعرض الوقت والتاريخ الحاليين
- تسجّل الحضور أو الانصراف مع محاولة إرفاق موقع الجهاز إن سُمح به
- تلخّص وقت الحضور والانصراف وإجمالي ساعات اليوم
- تعرض جدول سجلات الحضور السابقة مع حالتها

## أقسام الشاشة

### اليسار — الساعة والتسجيل

1. الوقت الحالي (`HH:mm:ss`) والتاريخ
2. زر دائري كبير يعرض الحالة التالية: **Check In** أو **Check Out**
3. ثلاث بطاقات ملخص: وقت الحضور، وقت الانصراف، إجمالي الساعات

### اليمين — السجلات

- عنوان **سجلات الحضور** مع عدد السجلات وزر تحديث
- جدول قابل للترتيب والتصفح الصفحي عند تجاوز 10 صفوف

| العمود | المحتوى |
|---|---|
| التاريخ | تاريخ السجل واسم اليوم |
| الحضور | وقت Check In |
| الانصراف | وقت Check Out |
| إجمالي الساعات | الساعات المحسوبة |
| الحالة | **مكتمل** إن وُجد انصراف صالح، وإلا **قيد التنفيذ** |

## كيف تسجّل حضورًا أو انصرافًا

1. افتح `/app/Attendance`
2. انتظر تحميل الحالة الحالية والسجلات
3. اضغط الزر الدائري
4. إن طُلب إذن الموقع من المتصفح يمكنك السماح أو الرفض؛ عند التعذّر يُرسل التسجيل بدون إحداثيات
5. عند النجاح تظهر رسالة نجاح وتُحدَّث الملخصات والجدول
6. انتظر بضع ثوانٍ قبل المحاولة التالية (حماية من التسجيل المكرر)

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| نوع العملية | يُستنتج من حالة الخادم: إن كانت الحالة تشير إلى Check Out تُرسل `checkOut`، وإلا `checkIn` |
| الموقع | اختياري من المتصفح (مهلة حوالي 5 ثوانٍ)؛ الفشل لا يمنع المحاولة |
| فترة الانتظار | حوالي 5.5 ثانية بعد نجاح العملية؛ المحاولة أثناء الانتظار تظهر تحذيرًا |
| التكرار | إن تجاهل الخادم ضغطة مكررة تظهر رسالة انتظار ويُحدَّث العرض |
| الأخطاء الأخرى | رسالة فشل مع تفاصيل الخادم إن وُجدت |

:::note[تتبع الميدان]
مسارات `/app/Attendance/Tracking` تُحوَّل إلى تتبع GPS تحت `/Entities/GPS/Tracking` لخرائط الجولات الميدانية، وهي شاشة منفصلة عن زر الحضور اليومي.
:::

## أفضل الممارسات

:::tip[سجّل الحضور عند بدء العمل والانصراف عند الانتهاء]
لا تعتمد على التذكر لاحقًا. الزر يعكس العملية التالية تلقائيًا حسب حالتك.
:::

:::warning[لا تضغط الزر بسرعة متتالية]
النظام يحمي من البصمات المكررة. انتظر رسالة النجاح ثم اكمل عملك.
:::
