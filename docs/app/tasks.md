# المهام

لوحة **مهامي** تجمع عناصر العمل الشخصية في عرض كانبان حسب الحالة. منها تنشئ المهام والقصص والأخطاء والملاحظات والمكالمات والاجتماعات والزيارات، وتحدّث الحالة بالسحب أو من نافذة التفاصيل.

**المسار:** `/app/Tasks`

## ماذا تفعل هذه الشاشة

- تعرض عناصر العمل (Work Items) في أعمدة حسب الحالة
- تلخّص العدد الإجمالي، وعدد قيد التنفيذ، وعدد المكتمل
- تتيح التصفية بالاسم والنوع والمُسند إليه وتواريخ البداية والنهاية
- تفتح إنشاءً سريعًا أو تعديلًا عبر نوافذ مخصّصة

## أقسام الشاشة

1. **الترويسة** — العنوان، عدّاد العناصر، شارات قيد التنفيذ / مكتمل، زر تحديث، قائمة إضافة
2. **شريط التصفية** — بحث ونوع ومُسند إليه وتواريخ
3. **أعمدة الكانبان** — عمود لكل حالة عمل (تُستبعد حالات تحتوي كلمة «concern»)
4. **النوافذ** — إنشاء نشاط، قصة/خطأ، أو تعديل بطاقة موجودة

## التصفية

| عامل التصفية | الاستخدام |
|---|---|
| **بحث** | اسم عنصر العمل |
| **النوع** | اختيار متعدد لأنواع العناصر |
| **المُسند إليه** | اختيار متعدد للمستخدمين |
| **تاريخ البداية / النهاية** | نطاق زمني |

تغيير أي عامل يعيد تحميل اللوحة فورًا.

## بطاقة المهمة

كل بطاقة تعرض عادةً:

- شارة النوع ورمز/رقم العنصر
- الأولوية والاسم ونسبة التقدم
- تاريخ الاستحقاق أو البداية (مع تنبيه التأخير عند الاقتضاء)
- المُسند إليهم أو «غير مسند»
- عدد التعليقات والمرفقات إن وُجدت

## إنشاء عنصر جديد

1. اضغط **إضافة مهمة**
2. اختر النوع من القائمة:
   - **مهمة** (الافتراضي)
   - **قصة**
   - **خطأ**
   - **ملاحظة**
   - **مكالمة**
   - **اجتماع**
   - **زيارة**
3. أكمل الحقول في النافذة ثم احفظ

### إنشاء مهمة / ملاحظة / مكالمة / اجتماع / زيارة

نافذة الأنشطة تطلب عادةً: الاسم، النوع، الأولوية، المُسند إليه، الحالة. الحالة الافتراضية عند الإنشاء من هذه الصفحة: **Assigned**. تاريخ الاستحقاق يجب أن يكون بعد أو يساوي تاريخ البداية.

### إنشاء قصة أو خطأ

نافذة منفصلة تطلب: الاسم، الحالة، المُسند إليه، وتاريخ النهاية (إلزامي). الوصف اختياري. الحالة الافتراضية تفضّل Planned / Open / Assigned / New عند توفرها.

## تعديل عنصر موجود

1. اضغط البطاقة
2. **قصة أو خطأ** تفتح نافذة القصة/الخطأ
3. بقية الأنواع تفتح نافذة تعديل البطاقة
4. حدّث الحقول أو أضف تعليقًا/مرفقًا ثم احفظ

في نافذة التعديل: الاسم والنوع والحالة والمُسند إليه وتواريخ البداية والنهاية مطلوبة. للأنواع الزمنية (مكالمة، اجتماع، زيارة، ملاحظة) يُطلب الوقت أيضًا. الوصف بحد أقصى 1000 حرف. التقدم من 0 إلى 100.

## نقل الحالة بالسحب

اسحب البطاقة إلى عمود حالة آخر. النظام يحفظ الحالة الجديدة؛ وعند الفشل تُعاد البطاقة إلى مكانها السابق.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| إكمال بدون 100% | إن كانت الحالة مكتملة والتقدم أقل من 100% يُمنع الحفظ مع تحذير |
| مهام الاعتماد | إن أشارت رسالة الخادم إلى مهمة اعتماد، استخدم [صندوق الوارد](/docs/app/inbox) |
| نوع البطاقة عند التعديل | نوع العنصر الموجود يكون مقفلاً في نافذة التعديل الشخصية |
| تعليقات | إضافة تعليق بحد أقصى 500 حرف (يدعم Ctrl+Enter) |

## أفضل الممارسات

:::tip[حدّث الحالة بالتقدم الحقيقي]
لا تنقل البطاقة إلى مكتمل قبل رفع نسبة الإنجاز إلى 100% إن كان الحقل مستخدمًا.
:::

:::note[التحديث وإعادة التحميل]
استخدم **تحديث** بعد عمل جماعي أو عند الشك في أن اللوحة قديمة.
:::
