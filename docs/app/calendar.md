# التقويم

يعرض **التقويم** مهامك وإجازاتك في شبكة شهرية واحدة. يمكنك التصفية والتنقل بين الأشهر وفتح تفاصيل يوم أو حدث.

**المسار:** `/app/calendar`  
(المسار القديم `/app/calender` يُحوَّل تلقائيًا إلى التقويم الحالي.)

## ماذا تفعل هذه الشاشة

- تجمع عناصر العمل (المهام) وطلبات الإجازة (HR Vacation) في شهر واحد
- تميّز المهام عن الإجازات بلون/شارة في وسيلة الإيضاح
- تفتح تفاصيل المهمة للتعديل، وتفاصيل الإجازة للعرض فقط

## أقسام الشاشة

1. **الترويسة** — العنوان، «مهامي وإجازاتي»، وسيلة الإيضاح، أزرار التصفية (الكل / مهمة / إجازة)
2. **شريط الشهر** — السابق، اسم الشهر، التالي، **هذا الشهر**، مؤشر التحميل
3. **شبكة الأيام** — 7×6 (من الأحد إلى السبت)
4. **نافذة اليوم** — قائمة كل عناصر ذلك اليوم
5. **نافذة المهمة** — نفس محرر بطاقة المهام
6. **نافذة الإجازة** — عرض فقط مع زر إغلاق

## قراءة الشبكة

- كل خلية تُظهر رقم اليوم وحتى 3 شرائح أحداث، ثم `+N` إن وُجد المزيد
- الأيام خارج الشهر الحالي تظهر باهتة؛ اليوم الحالي مميّز
- الشريحة الزرقاء/المهمة للمهام، وشريحة الإجازة للإجازات

## التصفية والتنقل

1. اختر **الكل** أو **مهمة** أو **إجازة**
2. انتقل شهرًا ب الأسهم أو اضغط **هذا الشهر** للعودة للشهر الحالي
3. اضغط يومًا لفتح قائمة أحداثه
4. اضغط حدثًا (من الشبكة أو من قائمة اليوم) لفتح تفاصيله

## تفاصيل الإجازة (عرض فقط)

| الحقل | المعنى |
|---|---|
| الشخص | اسم طالب الإجازة وصورته إن وُجدت |
| الحالة | حالة الطلب مع لونها إن توفر |
| من / إلى | فترة الإجازة |
| المدة | عدد الأيام |
| البديل | اسم الموظف البديل إن وُجد |
| رقم الطلب | رقم الطلب إن وُجد |
| ملاحظة | وصف الإجازة (إن لم يكن مجرد رقم طلب) |

## تفاصيل المهمة

تفتح نافذة تعديل المهمة المشتركة مع [المهام](/docs/app/tasks). بعد الحفظ يُعاد تحميل أحداث التقويم.

## قواعد مهمة

| القاعدة | التفصيل |
|---|---|
| مصدر البيانات | حتى 500 مهمة و500 إجازة لكل تحميل |
| نطاق العرض | إن وُجدت عناصر مسندة إليك تُضيَّق القائمة لها؛ وإلا تُعرض نتيجة الواجهة كما هي |
| بدون تاريخ صالح | العناصر بلا تاريخ بداية قابل للقراءة لا تظهر |
| لا إنشاء من التقويم | التقويم لا ينشئ أحداثًا جديدة؛ أنشئ من المهام أو من طلبات الخدمة |

## أفضل الممارسات

:::tip[استخدم تصفية الإجازة قبل التخطيط]
قبل ترتيب أسبوع مزدحم، صفِّ على **إجازة** لترى تغطية الفريق ثم ارجع إلى **الكل**.
:::

:::note[الإجازة للقراءة فقط هنا]
تعديل طلب الإجازة يتم من مسار الطلب/الخدمة وليس من نافذة التقويم.
:::
