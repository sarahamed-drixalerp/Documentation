# تطبيقاتي

**تطبيقاتي** هي مساحة العمل الشخصية في Drixal ERP: مهامك، تقويمك، ساعاتك، الخدمات والطلبات، الوارد، البلاغات، والحضور، إضافة إلى الملف الشخصي وكلمة المرور وسياسة الخصوصية.

## أين تجده

من شريط التطبيقات في أعلى الصفحة، أو من قائمة المستخدم، أو من الشريط الجانبي (حسب العنصر):

| الصفحة | المسار |
|---|---|
| المهام | `/app/Tasks` |
| التقويم | `/app/calendar` |
| سجل الدوام | `/app/Timesheet` |
| الخدمات | `/app/ServiceCatalogue` |
| طلباتي | `/app/MyRequests` |
| صندوق الوارد | `/app/Inbox` |
| البلاغات | `/app/incidents` |
| الحضور والانصراف | `/app/Attendance` |
| الملف الشخصي | `/profile` |
| تغيير كلمة المرور | `/changepassword` |
| سياسة الخصوصية | `/privacyPolicy` |

## كيف يُنظَّم هذا الدليل

1. [المهام](/docs/app/tasks) — لوحة كانبان للعمل اليومي
2. [التقويم](/docs/app/calendar) — المهام والإجازات في شهر واحد
3. [سجل الدوام](/docs/app/timesheet) — تسجيل الساعات والتقدم أسبوعيًا
4. [الخدمات](/docs/app/services) — تصفح الخدمات وتقديم الطلبات
5. [طلباتي](/docs/app/my-requests) — متابعة طلباتك المقدَّمة
6. [صندوق الوارد](/docs/app/inbox) — اعتمادات ومهام معلّقة عليك
7. [البلاغات](/docs/app/incidents) — تسجيل وتتبع البلاغات
8. [الحضور والانصراف](/docs/app/attendance) — تسجيل الدخول والخروج اليومي
9. [الملف الشخصي](/docs/app/profile) — الصورة والتفضيلات والأمان
10. [تغيير كلمة المرور](/docs/app/change-password)
11. [سياسة الخصوصية](/docs/app/privacy-policy)

## أفضل الممارسات

:::tip[ابدأ من الوارد والمهام كل صباح]
راجع [صندوق الوارد](/docs/app/inbox) للاعتمادات العاجلة، ثم [المهام](/docs/app/tasks) للعمل اليومي، واملأ [سجل الدوام](/docs/app/timesheet) قبل نهاية الأسبوع.
:::

:::note[الصلاحيات والحالات من النظام]
ما تراه في القوائم والحالات والأزرار يعتمد على بياناتك وأدوارك في المؤسسة. إن اختفى زر أو ظهر «للقراءة فقط» فهذا غالبًا قيد حالة الطلب أو صلاحية وليس عطلًا.
:::
