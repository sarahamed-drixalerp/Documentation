# سياسة الخصوصية

صفحة **سياسة الخصوصية** تعرض نص سياسة التعامل مع البيانات الشخصية داخل المنصة. يمكنك التصفح عبر جدول المحتويات والانتقال السريع بين الأقسام.

**المسار:** `/privacyPolicy`

## ماذا تفعل هذه الشاشة

- تعرض مقدمة السياسة وأقسامها مع قائمة محتويات جانبية
- تُبرز إن كان المحتوى ما زال مسودة بانتظار اعتماد الإدارة
- تدعم التمرير المتزامن مع القسم النشط وزر العودة للأعلى

## أقسام الواجهة

1. **الترويسة** — العنوان، شارة المسودة إن وُجدت، العنوان الفرعي، وتاريخ آخر تحديث عند توفره
2. **إشعار المسودة** — يوضح أن النص الهيكلي لم يُعتمد رسميًا بعد (عند كون الوثيقة مسودة)
3. **في هذه الصفحة** — روابط الأقسام
4. **المحتوى** — المقدمة ثم بطاقات الأقسام
5. **ملاحظة التواصل** — مكان لبيانات الاستفسارات بعد اعتماد السياسة الرسمية
6. **العودة للأعلى** — يظهر بعد التمرير للأسفل

## الأقسام المتوقعة في الوثيقة

| المعرّف | الموضوع |
|---|---|
| collect | المعلومات التي نجمعها |
| use | كيف نستخدم معلوماتك |
| storage | تخزين البيانات وأمانها |
| sharing | مشاركة المعلومات |
| cookies | ملفات تعريف الارتباط والتتبع |
| rights | حقوق المستخدم وخصوصية البيانات |
| updates | تحديثات السياسة ومعلومات التواصل |

كل قسم قد يتضمن فقرات ونقاطًا، وقد يحمل ملاحظة «بانتظار الاعتماد» عندما تكون الوثيقة مسودة.

## كيف تتصفح الصفحة

1. افتح السياسة من قائمة المستخدم أو من رابط الأمان في [الملف الشخصي](/docs/app/profile)
2. اقرأ إشعار المسودة إن ظهر
3. استخدم قائمة **في هذه الصفحة** للانتقال إلى قسم
4. عند تعذّر التحميل استخدم **إعادة المحاولة**
5. استخدم **العودة للأعلى** بعد التمرير الطويل

## مصدر المحتوى وقواعده

| القاعدة | التفصيل |
|---|---|
| المسودة الحالية | في التطبيق الحالي تُبنى وثيقة مسودة من نصوص الواجهة؛ لا يوجد بعد واجهة اعتماد منشورة من نظام إدارة محتوى |
| شارة Draft | تظهر عندما `isDraft = true` |
| آخر تحديث | يظهر فقط عند توفر تاريخ |
| تغيير اللغة | إعادة بناء النص حسب لغة الواجهة |

:::warning[المسودة ليست سياسة قانونية نهائية]
إذا ظهرت شارة المسودة أو إشعار «بانتظار اعتماد الإدارة»، فلا تعتمد على النص كسياسة شركة معتمدة حتى يُنشر الإصدار الرسمي.
:::

## أفضل الممارسات

:::tip[راجع السياسة بعد كل اعتماد رسمي]
عند اختفاء شارة المسودة وظهور تاريخ تحديث، أعد قراءة الأقسام المتعلقة بحقوقك والتواصل.
:::
