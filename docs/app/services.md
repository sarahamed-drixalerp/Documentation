# الخدمات

**خدماتي (My Services)** في تطبيقاتي لاستعراض دليل الخدمات الداخلية وتقديم الطلبات — المسار التشغيلي اليومي بينما شاشة إدارة الكتالوج غير مستضافة.

![استعراض الخدمات](/img/app/services-browse.svg)

## ماذا تفعل الصفحة لأعمالك

- تعرض الخدمات حسب الفئة مع بحث بالاسم
- تفتح نموذج الطلب حسب نوع الخدمة (`ServName`)
- تحفظ مسودة ثم ترسل الطلب مع قفل بعد الإرسال

**المسار:** تطبيقاتي ← الخدمات  
**الصفحات:** `/app/ServiceCatalogue` · `/app/ServiceCatalogue/Submit?Service=…`

## الاستعراض

| العنصر | المحتوى |
|---|---|
| **العنوان** | خدماتي — استعراض وتقديم طلبات داخلية |
| **البحث** | ابحث عن خدمات… |
| **التبويبات** | تنظيمي، موارد بشرية، صلاحيات أنظمة، مستخدم نهائي، Active Directory، بريد، هويات، تصاريح دخول |

النقر على بطاقة يفتح الإرسال مع معامل `Service` (اسم الخدمة بدون مسافات زائدة).

## تقديم طلب

![تقديم طلب خدمة](/img/app/services-submit.svg)

1. اختر الخدمة من القائمة
2. عيّن **الطلب نيابة عن** (إلزامي)
3. أكمل حقول النموذج الخاصة بنوع الخدمة
4. **حفظ مسودة** ثم **إرسال الطلب** (مع تأكيد القفل)

### بعد الحفظ

| المنطقة | المحتوى |
|---|---|
| **التبويبات** | نظرة عامة؛ مرفقات (لبعض الخدمات مثل الإجازة)؛ مسار العمل؛ الموافقات |
| **EntityNavTabs** | أنشطة / مرفقات / سجلات / رؤى |
| **الخطوات** | مسودة → مقدَّم → قيد المراجعة → موافق عليه (عرض) |

بعد الإرسال يصبح السجل للقراءة فقط.

:::note[لوحة مسار العمل والموافقات]
تبويبا Workflow و Approvals قد يظهران فارغين حتى يُربط مسار عمل فعّال بالخدمة.
:::

## أفضل الممارسات

:::tip[أكمل «نيابة عن» قبل الإرسال]
الحقل إلزامي. راجع الشروط والمهل المعروضة في الشريط الجانبي للطلب.
:::
